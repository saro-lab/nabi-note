# 정렬

현재 문단과 선택 범위에 걸친 문단을 왼쪽, 가운데, 오른쪽으로 정렬합니다. 그림·영상·표처럼
문단에 들어가는 객체도 그 객체를 감싼 문단을 기준으로 정렬합니다.

정렬은 글자 서식이 아니라 문단 속성으로 저장됩니다. 코드 블록은 들여쓰기 자체가 의미를
가지므로 정렬 대상에서 제외됩니다.

표 셀 안에서는 커서가 있는 내부 문단이나 이미지를 정렬합니다. 여러 셀을 드래그해 선택하면
선택한 셀 안에서 정렬할 수 있는 모든 문단과 이미지에 적용합니다. 서로 다른 정렬이 섞인
선택에서는 특정 정렬 버튼을 선택 상태로 표시하지 않습니다.

표 자체를 정렬하려면 표의 속성 도구에서 **표 전체 선택**을 누르거나 표를 감싼 문단의 앞뒤에
커서를 두고 메인 툴바의 정렬 버튼을 사용합니다. 플로트 영역의 좌우 배치는 정렬 버튼 대신
해당 영역의 속성 도구에서 바꿉니다.

<WingDemo path="/wing/etc/align" />

```ts
const selected = wings().use('align').build()
```

현재 선택에 명령으로 적용할 때는 왼쪽 `l`, 가운데 `c`, 오른쪽 `r`을 사용합니다.

```ts
nabi.applyCommand('setAlign', { value: 'c' })
```
