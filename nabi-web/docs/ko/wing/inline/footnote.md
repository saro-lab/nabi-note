# 각주

본문의 번호와 문서 끝 목록으로 보충 설명을 연결합니다.

툴바의 각주 버튼으로 내용을 입력하면 커서 위치에 각주가 들어갑니다. 글자를 선택했다면 선택 끝에 넣고 선택한 글자는 유지합니다. 번호는 저장하지 않고 문서 순서에 따라 자동으로 매깁니다.

본문 번호를 누르면 속성 줄에서 내용을 수정할 수 있습니다. 삭제 도구로 지우거나, 각주 옆에서 Backspace 또는 Delete를 두 번 눌러 선택한 뒤 지울 수 있습니다. 하단 목록은 읽기 전용이며 각주가 없으면 사라집니다.

미리보기와 viewer를 연결한 게시 화면에서는 번호에 마우스를 올리거나 클릭·탭하면 내용을 볼 수 있습니다. 내용은 한 줄 일반 텍스트만 받으며, 본문 기본 크기의 0.875배인 산세리프로 표시합니다. HTML은 글자 그대로 표시됩니다.
