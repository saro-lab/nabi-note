# சீரமைப்பு

தற்போதைய பத்தியையும் தேர்ந்த வரம்பில் உள்ள பத்திகளையும் இடது, நடு அல்லது வலப்புறமாகச் சீரமைக்கிறது. படம், காணொளி, அட்டவணை போன்ற பத்திக்குள் இருக்கும் பொருள்களும் அவற்றைச் சுற்றிய பத்தியை அடிப்படையாகக் கொண்டு சீரமைக்கப்படுகின்றன.

சீரமைப்பு எழுத்து வடிவமைப்பாக அல்ல, பத்திப் பண்புக்கூறாகச் சேமிக்கப்படுகிறது. உள்தள்ளலே பொருள் கொண்டிருப்பதால் குறியீட்டுத் தொகுதிகள் சீரமைப்பிலிருந்து விலக்கப்படுகின்றன.

அட்டவணைக் கலத்தில் இடஞ்சுட்டி உள்ள உட்பத்தி அல்லது படத்திற்கு சீரமைப்பு பயன்படுத்தப்படும். இழுத்துப் பல கலங்களைத் தேர்ந்தெடுத்தால் அவற்றிலுள்ள சீரமைக்கக்கூடிய அனைத்துப் பத்திகளுக்கும் படங்களுக்கும் பயன்படுத்தப்படும். தேர்வில் வெவ்வேறு சீரமைப்புகள் இருந்தால் எந்தச் சீரமைப்புப் பொத்தானும் தேர்ந்தெடுத்ததாகக் காட்டப்படாது.

அட்டவணையையே சீரமைக்க அதன் சூழல் கருவிகளில் **முழு அட்டவணையையும் தேர்ந்தெடு** என்பதை அழுத்தவும், அல்லது அட்டவணையைச் சூழ்ந்த பத்தியில் அட்டவணைக்கு முன் அல்லது பின் இடஞ்சுட்டியை வைத்து முதன்மைக் கருவிப்பட்டையின் சீரமைப்புப் பொத்தான்களைப் பயன்படுத்தவும். மிதக்கும் பகுதியின் இடது அல்லது வலது அமைப்பைச் சீரமைப்புப் பொத்தான்களுக்குப் பதிலாக அந்தப் பகுதியின் சூழல் கருவிகளில் மாற்றவும்.
