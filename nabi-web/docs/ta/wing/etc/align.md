# சீரமைப்பு

தற்போதைய பத்தியையும் தேர்ந்த வரம்பில் உள்ள பத்திகளையும் இடது, நடு அல்லது வலப்புறமாகச் சீரமைக்கிறது. படம், காணொளி, அட்டவணை போன்ற பத்திக்குள் இருக்கும் பொருள்களும் அவற்றைச் சுற்றிய பத்தியை அடிப்படையாகக் கொண்டு சீரமைக்கப்படுகின்றன.

சீரமைப்பு எழுத்து வடிவமைப்பாக அல்ல, பத்திப் பண்புக்கூறாகச் சேமிக்கப்படுகிறது. உள்தள்ளலே பொருள் கொண்டிருப்பதால் குறியீட்டுத் தொகுதிகள் சீரமைப்பிலிருந்து விலக்கப்படுகின்றன.
