# பெரிய முதல் எழுத்து

பத்தியின் முதல் எழுத்தைப் பெரிதாக வைத்து, மீதமுள்ள வரிகள் அதன் பக்கத்தில் ஓடச் செய்கிறது. இது பத்தி அளவிலான வடிவமைப்பு என்பதால் எழுத்தின் ஒரு பகுதியை மட்டும் தேர்ந்தெடுத்து பயன்படுத்த முடியாது.

வெளியீட்டுப் பக்கமும் திருத்தப் பக்கமும் ஒரே தோற்றத்தை வைத்திருக்கும். திருத்தும்போது caret மற்றும் நீக்கும் இடம் தவறாமல் இருக்க முதல் எழுத்து உண்மையான கூறால் சுற்றப்படும்; இந்தக் கூறு சேமிக்கப்படும் ஆவண உள்ளடக்கத்தில் சேராது.

## CSS பாணிகள்

வெளியீட்டுப் பக்கத்திற்கும் திருத்தப் பக்கத்திற்கும் முதல் எழுத்தைக் குறிக்கும் தேர்வி மட்டுமே வேறுபடும். வெளியீட்டில் `[data-nabi-dropcap="1"]::first-letter`, திருத்தப் பக்கத்தில் உண்மையான `[data-nabi-dropcap-letter]` கூறு பயன்படுகிறது. நிறம், எழுத்துரு, அளவு போன்ற காட்சிமதிப்புகளை மாற்றும்போது திருத்தத்திலும் வெளியீட்டிலும் ஒரே தோற்றம் இருக்க இரு தேர்விகளையும் சேர்த்து எழுத வேண்டும்.

```css
.article-body:not(.nabi-editing) [data-nabi-dropcap="1"]::first-letter,
.nabi-content.nabi-editing [data-nabi-dropcap-letter] {
  color: var(--nabi-accent);
  font-family: var(--nabi-font-serif);
}
```

அளவு மற்றும் வரி உயரத்தையும் மாற்ற வேண்டுமெனில் அதே மதிப்புகளை இரு தேர்விகளுக்கும் பயன்படுத்தவும்.

```css
.article-body:not(.nabi-editing) [data-nabi-dropcap="1"]::first-letter,
.nabi-content.nabi-editing [data-nabi-dropcap-letter] {
  font-size: 5.5em;
  line-height: .85;
}
```

பெரிய முதல் எழுத்து அதைச் சுற்றிய வரிகளின் ஓட்டத்தைக் கணக்கிடுகிறது; ஒரு பக்கத்தை மட்டும் மாற்றினாலோ மதிப்பை அதிகமாகப் பெரிதாக்கினாலோ WYSIWYG தோற்றம் கெடலாம். திருத்தப் பக்கத்தில் புதிய `::first-letter` ஐச் சேர்ப்பதைத் தவிர்க்க வேண்டும். தொகுப்பியில் ஏற்கனவே உள்ள `[data-nabi-dropcap-letter]` ஐ மட்டுமே வடிவமைக்கவும்.
