# வடிவமைப்பை அழி

தேர்ந்த வரம்பிலுள்ள எழுத்து வடிவமைப்புகளை ஒரே நேரத்தில் அகற்றுகிறது. தடிமன், நிறம், எழுத்துரு போன்ற பதிவு செய்யப்பட்ட அடிப்படை mark-களும் தலைப்பு, சீரமைப்பு, drop cap பத்திப் பண்புகளும் இதன் இலக்கு. Esc ஐ விரைவாக இருமுறை அழுத்தியும் இதே செயல்பாட்டைச் செய்யலாம்.

பட்டியல், அட்டவணை, மேற்கோள், படம் போன்ற ஆவண அமைப்புகளை வெற்று உரையாக மாற்றாது. படம் மற்றும் காணொளியின் வெளிப்புறச் சீரமைப்பும் பதிவேற்றம் உருவாக்கிய இணைப்பும் அப்படியே இருக்கும்.

```ts
const selected = wings()

```

அகற்ற வேண்டிய வடிவமைப்பின் wing-ஐயும் சேர்த்துத் தேர்ந்தெடுத்தால்தான் அந்த வடிவமைப்பை அகற்ற முடியும்.
