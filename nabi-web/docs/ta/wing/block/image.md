# படம்

பட முகவரியைச் சேர்த்து அகலத்தையும் சீரமைப்பையும் மாற்றுகிறது. இயல்பாக `http:`, `https:` அல்லது அதே தளப் பாதைகள் மட்டுமே அனுமதிக்கப்படுகின்றன; புதிய படம் மையச் சீரமைப்பிலும் 60% அகலத்திலும் தொடங்கும்.

அகலம் நிர்ணயிக்கப்பட்ட நிலைகளில் மட்டுமே சேமிக்கப்படுகிறது; சீரமைப்பு படத்தைச் சுற்றியுள்ள பத்தியில் சேமிக்கப்படுகிறது. `blob:` மற்றும் `data:image/...` முன்னோட்டங்களைப் பயன்படுத்த, பட wing மற்றும் தொகுப்பி அமைப்பில் உள்ளூர் URL-களைத் தெளிவாக அனுமதிக்க வேண்டும். SVG data URL-கள் அனுமதிக்கப்படாது.

<WingDemo path="/wing/block/image" />

```ts
const selected = wings().use('img', {
  allowLocalUrls: false,
}).build()
```

இந்த wing முகவரியை ஆவணத்தில் சேர்ப்பதற்கானது; கோப்பைப் பரிமாறாது. கோப்பை சேவையகத்திற்கு அனுப்ப [பதிவேற்ற wing](/ta/wing/etc/upload) ஐ இணைக்கவும்.

## படத் தேர்வியை இணைத்தல்

படப் பொத்தானின் இயல்புநிலை URL உள்ளீட்டுச் சாளரத்துக்குப் பதிலாக உங்கள் சேவையின் படத் தேர்வியைப் பயன்படுத்த, `mountToolbar()` இல் `panels.img` கொடுக்கவும். விசைகள் கருவிப்பட்டை slot பெயர்களாகும்; குறிப்பிடாத கருவிகள் அவற்றின் இயல்புநிலைச் சாளரங்களையே பயன்படுத்தும்.

```ts
import { mountToolbar } from 'nabi-note'

const toolbar = mountToolbar({
  nabi,
  registry,
  root: toolbarRoot,
  surface: content,
  panels: {
    img: ({ root, signal, run }) =>
      mountMyImagePicker(root, {
        signal,
        onSelect: (url: string) => run('insertImage', { src: url }),
      }),
  },
})
```

`mountMyImagePicker` என்பது உங்கள் சேவையில் நீங்கள் உருவாக்கும் செயல்பாடு. இது கொடுக்கப்பட்ட `root`-க்குள் உங்கள் UI-ஐ ஒத்திசைவாக உருவாக்கி, சுத்தம் செய்யும் செயல்பாட்டைத் திருப்பித் தருகிறது. படப் பட்டியலைப் பெறுதல் அல்லது பதிவேற்றுதல் போன்ற ஒத்திசைவற்ற பணிகளுடன் `signal`-ஐ இணைத்து, தேர்ந்தெடுத்த படத்தின் URL-ஐ `onSelect`-க்கு அனுப்பவும். இந்த API கோப்புகளை அனுப்பாது; பட URL-களுக்கான தற்போதைய அனுமதி விதிகள் தொடர்ந்து பொருந்தும்.

சாளரத்தை மூடும்போது அல்லது கருவிப்பட்டையை அகற்றும்போது `signal` ரத்துசெய்யப்பட்டு, சுத்தம் செய்யும் செயல்பாடு அழைக்கப்படும். `run()` சாளரத்தை மூடி, திறந்தபோது பதிவு செய்த தேர்வில் கட்டளையை ஒருமுறை செயல்படுத்தும். சாளரம் ஏற்கெனவே மூடப்பட்டிருந்தாலோ, திறந்தபின் ஆவண உள்ளடக்கம் மாறியிருந்தாலோ கட்டளையைச் செயல்படுத்தாமல் `false` திருப்பித் தரும்.

## CSS பாணிகள்

படங்களை `.nabi-content img` மூலம் வடிவமைக்கலாம். சேமித்த அகலத்தையும் சீரமைப்பையும் அப்படியே வைத்துக்கொண்டு, எல்லை அல்லது நிழல் போன்ற தோற்றத்தை மட்டும் மாற்றுங்கள்.

```css
.article-body img {
  border-radius: 12px;
  box-shadow: 0 8px 24px rgb(0 0 0 / 12%);
}

.dark .article-body img { box-shadow: 0 8px 24px rgb(0 0 0 / 35%); }
```

`max-inline-size`, `block-size`, அகலம் மற்றும் சீரமைப்புக்கான அடிப்படை விதிகளைத் தக்கவையுங்கள். பட அளவு ஆவணத்தில் சேமிக்கப்படும் மதிப்பு என்பதால் CSS-ல் வலுக்கட்டாயமாக நிர்ணயித்தால் ஆசிரியர் தேர்ந்தெடுத்த அகலத்துடன் முரண்படலாம்.
