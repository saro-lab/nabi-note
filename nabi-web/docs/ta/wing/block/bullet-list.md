# புள்ளிப் பட்டியல்

பல உருப்படிகளை வரிசையின்றிப் பட்டியலிடும் பட்டியல் இது. வெற்றுப் பத்தியில் `-` க்குப் பிறகு Space ஐ அழுத்தவும் அல்லது கருவிப்பட்டையில் மாற்றவும். தேர்ந்தெடுத்த பத்திகளையும் ஒரே நேரத்தில் பட்டியலாக மாற்றலாம்.

பட்டியலில் Tab ஒரு நிலை உள்தள்ளும்; Shift+Tab வெளித்தள்ளும். Enter அடுத்த உருப்படியை உருவாக்கும்; வெற்று உருப்படியில் மீண்டும் Enter அழுத்தினால் பட்டியல் முடியும். Shift+Enter உருப்படியைப் பிரிக்காமல் அதற்குள் புதிய வரியை உருவாக்கும்.

அட்டவணைக் கலங்களிலுள்ள பட்டியல்களும் இதே உள்ளீட்டு விதிகளைப் பின்பற்றும். பட்டியலில் Tab அழுத்தினால் வேறு கலத்திற்குச் செல்லாமல் பட்டியலின் உள்தள்ளல் அதிகரிக்கும்.
