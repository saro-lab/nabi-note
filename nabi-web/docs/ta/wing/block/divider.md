# பிரிப்புக் கோடு

ஆவணத்தின் ஓட்டத்தைப் பிரிக்கும் கிடைமட்டக் கோடு இது. வெற்றுப் பத்தியில் மூன்று அல்லது அதற்கு மேற்பட்ட hyphen-களை உள்ளிட்டு Enter அழுத்தவும் அல்லது கருவிப்பட்டையில் சேர்க்கவும்.

பிரிப்புக் கோடு எழுத்தில்லாத தனித்த தொகுதி; ஆகவே தலைப்பு அல்லது நிறம் போன்ற வடிவமைப்புகளை கொண்டிருக்காது. முன் மற்றும் பின் பத்திகளைப் பிரிக்க மட்டுமே இதைப் பயன்படுத்தவும்.
