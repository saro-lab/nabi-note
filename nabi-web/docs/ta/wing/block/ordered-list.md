# எண்ணிடப்பட்ட பட்டியல்

வரிசை முக்கியமான உருப்படிகளை எண்ணிடப்பட்ட பட்டியலாக்குகிறது. வெற்றுப் பத்தியில் `1.` போன்று எண் மற்றும் முற்றுப்புள்ளியை உள்ளிட்டு Space அழுத்தவும்; அல்லது தேர்ந்தெடுத்த பத்திகளை கருவிப்பட்டையில் மாற்றவும்.

காட்டப்படும் எண் உருப்படியின் இடத்திலிருந்து கணக்கிடப்படுவதால், உருப்படிகளைச் சேர்த்தாலோ உள்தள்ளினாலோ தானாகத் தொடரும். விரும்பிய எண்ணிலிருந்து எண்ணத் தொடங்க, உள்ளிட்ட தொடக்க எண்ணைச் சேமிக்கும் வசதி இல்லை.
