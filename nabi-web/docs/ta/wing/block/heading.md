# தலைப்பு

பத்தியைத் தலைப்பாக மாற்றி அதன் நிலையை அமைக்கிறது. கருவிப்பட்டையில் தலைப்பை இயக்கி H1 முதல் H6 வரை தேர்ந்தெடுக்கவும்; அல்லது வெற்றுப் பத்தியில் `#` முதல் `######` வரை உள்ளிட்டு அதன் பின் Space ஐ அழுத்தவும்.

தலைப்பு தனி தொகுதி வகையல்ல; அது பத்தியில் சேமிக்கப்படும் ஒரு பண்புக்கூறு. தலைப்பை மீண்டும் அழுத்தினால் சாதாரணப் பத்தியாக மாறுவதால், உடல் அமைப்பை வைத்துக்கொண்டு நிலையை மட்டும் மாற்றலாம்.

சாதாரண கலங்களிலுள்ள பத்திகளைத் தலைப்புகளாக மாற்றலாம். தலைப்புக் கலங்களில் பத்தித் தலைப்பு வடிவம் பயன்படுத்தப்படாது; ஒரு கலத்தைத் தலைப்புக் கலமாக மாற்றும்போது ஏற்கெனவே உள்ள தலைப்பு வடிவமும் நீங்கும். பல பத்திகளைத் தேர்ந்தெடுக்கும்போது அனைத்தும் ஒரே தலைப்பு நிலையில் இருந்தால் மட்டுமே கருவிப்பட்டையில் ஒரே செயலில் உள்ள மதிப்பு காட்டப்படும்.
