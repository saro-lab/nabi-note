# முன்னிலைப்படுத்தல்

தேர்ந்தெடுத்த எழுத்துக்குப் பின்னால் முன்னிலைப்படுத்தல் நிறத்தைப் பயன்படுத்துகிறது. சேமித்த தரவில் விரும்பிய CSS நிற மதிப்புக்குப் பதில் அனுமதிக்கப்பட்ட நிறப் பெயர் மட்டுமே இருப்பதால், திரைப் பாணியையும் ஆவணத் தரவையும் பிரிக்கலாம்.

<WingDemo path="/wing/inline/highlight" />

```ts
const selected = wings().use('hl', {
  values: ['yellow', 'green', 'cyan'],
}).build()
```

`values` ஐ விடுத்தால் `yellow`, `green`, `cyan`, `pink`, `purple`, `orange` பயன்படுத்தப்படும். பட்டியலைக் குறைத்தால் பதிவு செய்யாத நிறங்கள் ஏற்றப்பட்ட ஆவணத்திலும் தக்கவைக்கப்படாது.

## CSS பாணிகள்

ஆவணத்தில் நிறப் பெயர் மட்டுமே சேமிக்கப்படும். தொகுப்பி மற்றும் வெளியீட்டுப் பக்க நிறங்களை CSS மாறிகளால் மாற்றவும்.

```css
.nabi-content { --nabi-hl-yellow: #fff0a6; }
```

பல நிறங்களை ஒன்றாக மாற்றினால் ஆவணத்தின் நிறப் பெயர்களை மாற்றாமல் சேவையின் தோற்றத்தை மட்டும் மாற்றலாம்.

```css
.article-body {
  --nabi-hl-yellow: #fff0a6;
  --nabi-hl-green: #c8f0d8;
  --nabi-hl-pink: #ffd6e5;
}
```
