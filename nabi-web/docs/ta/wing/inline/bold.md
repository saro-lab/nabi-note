# தடிமன்

தேர்ந்தெடுத்த எழுத்தைத் தடிமனாகக் காட்டுகிறது. அதே வரம்பில் மீண்டும் பயன்படுத்தினால் தடிமன் நீங்கும். சேமித்த ஆவணத்திலும் தடிமன் வடிவமைப்பு எழுத்துடன் தொடரும்.
