# அடித்தல் கோடு

தேர்ந்தெடுத்த உரையின் நடுவில் கோடு இடுகிறது. மாற்றிய சொற்றொடர்களையோ இனி பொருந்தாத உள்ளடக்கத்தையோ அழிக்காமல் காட்ட இதைப் பயன்படுத்தலாம். அதே பகுதியில் மீண்டும் பயன்படுத்தினால் வடிவமைப்பு நீங்கும்.
