# அடித்தல் கோடு

தேர்ந்தெடுத்த எழுத்தின் நடுவே கோடு இடுகிறது. மாறிய சொற்றொடர் அல்லது இனி செல்லுபடியாகாத உள்ளடக்கத்தை அழிக்காமல் வைத்திருக்கலாம்; அதே வரம்பில் மீண்டும் பயன்படுத்தினால் நீங்கும்.
