# சாய்வு

தேர்ந்தெடுத்த எழுத்தைச் சாய்வாகக் காட்டுகிறது. படைப்பின் பெயர் அல்லது வெளிமொழி போன்றவற்றை உடல் உரையிலிருந்து மெதுவாகப் பிரிக்க உதவும்; ஏற்கனவே சாய்வு கொண்ட வரம்பில் மீண்டும் அழுத்தினால் நீங்கும்.
