# சாய்வு

தேர்ந்தெடுத்த உரையைச் சாய்வாகக் காட்டுகிறது. படைப்புகளின் தலைப்புகள் அல்லது பிறமொழிச் சொற்களை முதன்மை உரையிலிருந்து சிறிது வேறுபடுத்த இது உதவும். ஏற்கெனவே சாய்வாக உள்ள பகுதியில் மீண்டும் அழுத்தினால் வடிவமைப்பு நீங்கும்.
