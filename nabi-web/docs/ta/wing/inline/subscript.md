# கீழ்க்குறி

தேர்ந்தெடுத்த உரையை அடிக்கோட்டுக்குக் கீழே சிறிய அளவில் காட்டுகிறது. `H₂O` போன்ற வேதியியல் வாய்ப்பாடுகளில் கீழெழுத்து தேவைப்படும் இடங்களுக்கு ஏற்றது. இந்த வடிவமைப்பு வாய்ப்பாடுகளைக் கணக்கிடும் வசதியைச் சேர்க்காது; எழுதப்பட்ட வடிவத்தைப் பாதுகாக்கப் பயன்படுத்தவும்.
