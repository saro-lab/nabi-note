# கீழ்க்குறி

தேர்ந்தெடுத்த எழுத்தை அடிக்கோட்டுக்குக் கீழே சிறியதாகக் காட்டுகிறது. வேதியியல் வாய்ப்பாட்டின் `H₂O` போன்ற கீழ்க்குறி தேவைப்படும் குறியீடுகளுக்கு ஏற்றது. இது கணிதக் கணக்கீட்டு அம்சத்தைச் சேர்க்கும் வடிவமைப்பு அல்ல; வெளிப்பாட்டையே பாதுகாக்க வேண்டியபோது பயன்படுத்தவும்.
