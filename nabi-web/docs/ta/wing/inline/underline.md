# அடிக்கோடு

தேர்ந்தெடுத்த உரைக்கு அடிக்கோடு இடுகிறது. இணைப்புப் போலத் தோன்றலாம்; ஆனால் இது உரை வடிவமைப்பு மட்டுமே. முகவரியையோ வேறிடத்திற்குச் செல்லும் செயலையோ சேர்க்காது.
