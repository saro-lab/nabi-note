# அடிக்குறிப்பு

உரையிலுள்ள எண்களையும் ஆவணத்தின் இறுதியிலுள்ள பட்டியலையும் கொண்டு கூடுதல் விளக்கங்களை இணைக்கவும்.

கருவிப்பட்டியின் அடிக்குறிப்பு பொத்தானில் உரையை உள்ளிட்டால், சுட்டி இருக்கும் இடத்தில் அடிக்குறிப்பு சேரும். உரை தேர்ந்தெடுக்கப்பட்டிருந்தால், அதை மாற்றாமல் தேர்வின் இறுதியில் சேர்க்கப்படும். எண்கள் சேமிக்கப்படுவதில்லை; ஆவண வரிசைப்படி தானாக வழங்கப்படும்.

பண்புகள் வரிசையில் உள்ளடக்கத்தைத் திருத்த, உரையிலுள்ள எண்ணைக் கிளிக் செய்யவும். நீக்கும் கருவியைப் பயன்படுத்தவும் அல்லது அடிக்குறிப்பின் அருகே Backspace அல்லது Delete விசையை இருமுறை அழுத்தி முதலில் தேர்ந்தெடுத்து, பின்னர் நீக்கவும். கீழேயுள்ள பட்டியல் படிக்க மட்டுமே; அடிக்குறிப்புகள் இல்லாவிட்டால் அது மறையும்.

முன்னோட்டத்திலும் viewer இணைக்கப்பட்ட வெளியிடப்பட்ட பக்கங்களிலும் எண்ணின் மீது சுட்டியை வைத்தோ, கிளிக் செய்தோ, தொட்டோ உள்ளடக்கத்தைப் படிக்கலாம். ஒரு வரி சாதாரண உரை மட்டுமே ஏற்கப்படும்; அது முதன்மை உரையின் அடிப்படை அளவில் 0.875 மடங்கு அளவுள்ள சான்ஸ் செரிஃப் எழுத்துருவில் காட்டப்படும். HTML அப்படியே உரையாகக் காட்டப்படும்.
