# மேற்குறி

தேர்ந்தெடுத்த உரையை அடிக்கோட்டுக்கு மேலே சிறிய அளவில் காட்டுகிறது. அடுக்குகள் அல்லது அடிக்குறிப்பு அடையாளங்களுக்குப் பயன்படுத்தலாம். தேர்ந்தெடுத்த பகுதிக்கு மட்டுமே பொருந்தும்.
