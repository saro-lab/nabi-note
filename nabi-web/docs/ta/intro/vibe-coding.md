# AI வைபு கோடிங்

NABI NOTE, AI மற்றும் தானியக்கக் கருவிகளுக்காக [`llms.txt`](/ta/llms.txt)-ஐ வழங்குகிறது. முழு நூலகத்தையும் ஊகிக்குமாறு agent-ஐக் கேட்பதற்குப் பதிலாக, முதலில் அந்த index-இல் இருந்து தொடங்கி பணிக்குத் தேவையான ஆவணங்களை மட்டும் படிக்கச் செய்யுங்கள்.

## தொடங்குவதற்கான prompt

தேவையான framework மற்றும் அம்சங்களை நிரப்புங்கள்.

```text
NABI NOTE (nabi-note)-ஐப் பயன்படுத்தி ஒரு திருத்தியை உருவாக்குங்கள்.
முதலில் https://nabi.saro.me/llms.txt-ஐப் படியுங்கள்; பின்னர் இந்தப் பணிக்குத் தேவையான ஆவணங்களை மட்டும் படியுங்கள்.

சூழல்: Vue 3 + TypeScript
அம்சங்கள்: அடிப்படை வடிவமைப்பு, அட்டவணைகள், படங்கள் மற்றும் பதிவேற்றங்கள்
சேமித்த மூலவடிவம்: NABI TREE JSON
வெளியிடுதல்: சேமித்த JSON-ஐச் சேவையகத்தில் HTML-ஆக render செய்தல்

நிறுவப்பட்ட வகைகளில் உள்ள பொது export-களையும் API-களையும் மட்டும் பயன்படுத்துங்கள்.
செயல்படுத்திய பின் type checking மற்றும் build-ஐ இயக்கி, மாற்றிய கோப்புகளையும் சரிபார்ப்பு முடிவுகளையும் தெரிவியுங்கள்.
```

agent URL-களைத் திறக்க முடியாவிட்டால், `llms.txt` மற்றும் தொடர்புடைய இணைக்கப்பட்ட ஆவணங்களை உரையாடலில் சேர்க்கவும்.

## தேவையானவற்றுக்கு மட்டும் வழிகாட்டுங்கள்

`llms.txt` ஒரு சுருக்கமான index. எல்லா ஆவணங்களையும் ஒரே நேரத்தில் அனுப்புவதை விட, தொடர்புடைய பக்கங்களை மட்டும் agent-க்கு வழங்குவது பொதுவாகப் பயனுள்ளதாகும்.

- npm மூலம் அமைக்க: [`quickstart-npm.md`](https://nabi.saro.me/llms/quickstart-npm.md)
- CDN அமைப்பு: [`quickstart-cdn.md`](https://nabi.saro.me/llms/quickstart-cdn.md)
- wing தேர்வு: [`wings.md`](https://nabi.saro.me/llms/wings.md)

- HTML இறக்குமதி, paste மற்றும் பதிவேற்ற எல்லைகள்: [`io-security.md`](https://nabi.saro.me/llms/io-security.md)
- custom wing மற்றும் சேவையக rendering: [`custom-wing.md`](https://nabi.saro.me/llms/custom-wing.md), [`ssr.md`](https://nabi.saro.me/llms/ssr.md)

## தயாரிப்பு தேவைகளைச் சேர்க்கவும்

திருத்தும் திரையை மட்டும் பார்த்து சேமிப்பு, பாதுகாப்புக் கொள்கை அல்லது பதிவேற்ற நடத்தையை agent ஊகிக்க முடியாது. உண்மையான framework, சேர்க்கப்படும் மற்றும் விலக்கப்படும் wing-கள், JSON மற்றும் HTML சேமிக்கப்படுமா, upload endpoint-இன் request மற்றும் response contract, கோப்பு வரம்புகள், வெளியிடப்பட்ட பக்கங்களுக்கு SSR, viewer நடத்தை அல்லது diff தேவையா என்பதைக் கூறுங்கள்.

இன்னும் முடிவு செய்யப்படாத எதற்கும், தேர்வு செய்வதற்கு முன் விருப்பங்களையும் அவற்றின் தாக்கத்தையும் விளக்குமாறு agent-ஐக் கேளுங்கள்.

## முடிவை மதிப்பாய்வு செய்யுங்கள்

உருவாக்கப்பட்ட code-ஐ மற்ற code போலவே மதிப்பாய்வு செய்யுங்கள். குறிப்பாக, கீழ்கண்டவற்றைச் சரிபார்க்கவும்:

- திருத்தலுக்கும் வெளியிடப்பட்ட உள்ளடக்கத்திற்கும் `nabi-note/nabi.css`-ஐ ஏற்றுகிறதா;
- தேர்ந்த wing-களுக்கும் ஒவ்வொரு mount-க்கும் ஒரே `registry`-ஐப் பயன்படுத்துகிறதா;
- `getJson()`-ஐச் சேமிக்கிறதா, `getEditorHtml()`-ஐ ஒருபோதும் சேமிப்பதில்லையா;
- திருத்தப்படும் `.nabi-content` element-இன் `innerHTML`-க்கு நேரடியாக எழுதவில்லையா;
- திரை மூடப்படும்போது ஒவ்வொரு mount-ஐயும் unmount செய்கிறதா;
- upload server MIME வகை, அளவு, அனுமதி மற்றும் சேமிப்பு இடத்தைச் சரிபார்க்கிறதா;
- சேவையகத்திலும் உலாவியிலும் பொருந்தும் wing வரிசையையும் HTML-ஐப் பாதிக்கும் விருப்பங்களையும் பயன்படுத்துகிறதா;
- type checking, test மற்றும் build மூலம் உண்மையான export பெயர்களை உறுதிப்படுத்துகிறதா.

பக்கம் ஒருமுறை இயங்குவது போல் தோன்றினாலும், IME மற்றும் caret நடத்தை, சேமித்து ஏற்றும் பாதைகள் உண்மையான சரிபார்ப்பைப் பெற வேண்டும். மொபைலில் composition input-ஐயும் சேமித்த ஆவண மீட்டெடுப்பையும் சோதிக்கவும்.

## நிறுவப்பட்ட பதிப்புக்கு முன்னுரிமை அளியுங்கள்

ஒரு திட்டத்தில் ஏற்கனவே `nabi-note` நிறுவப்பட்டிருந்தால், வேறு release-க்காக உருவாக்கப்பட்ட இணையதளத்தை விட அதன் `package.json` export-களும் type declaration-களும் நேரடியாகப் பொருந்தும். code எழுதுவதற்கு முன் அந்தப் பதிப்பு வேறுபாட்டைச் சரிபார்க்குமாறு agent-ஐக் கேளுங்கள்.
