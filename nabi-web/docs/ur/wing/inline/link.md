# لنک

## تفصیل

`linkWing` (id `a`) `<a href>` کی مالک ہے۔ بٹن دبانے سے کیریٹ کی جگہ کے قریب
پتہ درج کرنے کی تہہ کھلتی ہے، اور صرف `http`/`https` سے شروع ہونے والا پتہ
تصدیق کا بٹن فعال کرتا ہے — یہی whitelist جانچ دراصل XSS سے بچاؤ ہے
(`javascript:` جیسی scheme سرے سے نہیں گزرتی)۔ جو `href` جانچ میں پاس نہ ہو وہ
محفوظ نہیں ہوتا، اور تب `<a>` ٹیگ کے بغیر سادہ متن نکلتا ہے۔

تہہ میں دو خانے ہیں — پتہ اور نظر آنے والا متن۔ متن کا خانہ خالی چھوڑ دیں تو
پتہ ہی متن بن جاتا ہے، اور صرف کیریٹ ہو، کوئی متن منتخب نہ ہو تو کیریٹ جس لنک
mark میں ہے وہ پورا نشانہ بنتا ہے (ہائی لائٹ اور متن کے رنگ جیسا ہی قاعدہ)۔

## پہلے سے موجود لنک سیاق سطر سے بدلا جاتا ہے

کیریٹ لنک کے اندر کھڑا ہو تو سیاق سطر پر **دو متن کے خانے** نکلتے ہیں — panel
کھولنے والے بٹن نہیں بلکہ سیدھا اسی سطر میں کھڑا ان پٹ خانہ (`kind: 'text'`)۔
ابھی کی قدر بھری ہوئی نظر آتی ہے، اور Enter دبانے یا کہیں اور دبانے سے قدر لگ
جاتی ہے۔ قدر ویسی ہی رہے تو کچھ نہیں ہوتا۔

| خانہ | کام |
|---|---|
| پتہ | صرف پتہ بدلتا ہے۔ نظر آنے والا متن ویسا ہی رہتا ہے۔ |
| نام دکھانا | صرف نظر آنے والا متن بدلتا ہے۔ پتہ اور attachment کا نشان ویسا ہی رہتا ہے۔ |

**attachment (فائل لنک) پر پتے کا خانہ نہیں نکلتا** — کیونکہ وہ پتہ اپ لوڈ نے
طے کیا ہے، ہاتھ سے بدلنے والی قدر نہیں۔ نام کا خانہ عام لنک اور attachment
دونوں پر یکساں نکلتا ہے۔ خالی نام قبول نہیں ہوتا — بغیر نام کا لنک بنانا نام
بدلنا نہیں بلکہ مٹانا ہے۔

## attachment سکرین پر ایک ٹکڑا ہے

attachment کو مکمل ٹکڑے کی طرح برتا جاتا ہے۔ کلک کرنے سے کیریٹ اس کے اندر نہیں
بیٹھتا بلکہ **پورا لنک نشانہ بنتا ہے**، اور بالکل ساتھ backspace یا delete
دبانے سے **پورا لنک غائب ہو جاتا ہے۔** بدلنے کا کام کیریٹ کا نہیں بلکہ سیاق
سطر کا ہے۔

یہ کام wing خود `attach` سے تھامتی ہے اور `mountSurface` ساتھ لگا دیتا ہے —
**الگ سے کوئی mount نہیں چاہیے۔**

## attachment کا نشان

اپ لوڈ سے آیا لنک `data-nabi-file` نشان لگاتا ہے (قدر extension ہے) — یہی نشان
سٹائل شیٹ کو خط کے بجائے clip والا ڈبہ کھینچنے پر مجبور کرتا ہے۔ نام یا پتہ
بدلیں تو بھی یہ نشان ساتھ رہتا ہے۔ فارمیٹنگ صاف کرنا بھی صرف attachment کا
خول نہیں اتارتا — کیونکہ خول اترنے سے attachment مرا ہوا سادہ متن بن جاتا ہے۔

`linkWing` **کانسٹنٹ ہے** — قوس لگا کر نہیں بلایا جاتا، کوئی آپشن نہیں دیا
جاتا۔

::: warning `allowLocalUrls` لنک تک نہیں پہنچتا
`blob:`·`data:` پتے کھولنے والا سوئچ **صرف تصویر پر** چلتا ہے۔ باہر جانے کی
جگہ ہمیشہ سخت ہے، اس لیے `getHtml()` جس دروازے سے پتہ چھانتا ہے (`ctx.url`) وہ
میزبان نے کچھ بھی آن کیا ہو، whitelist کو ویسے ہی دیکھتا ہے۔

اسی لیے `blob:` پتہ رکھنے والا attachment لنک **باہر جاتے ہی سادہ متن بن جاتا
ہے۔** یہی وجہ ہے کہ اپ لوڈ کو عارضی پتہ ویسے ہی نہیں چھوڑنا چاہیے — چڑھنے کے
بعد ملے اصلی پتے سے بدلنا لازم ہے تاکہ دستاویز میں رہے۔
:::

## استعمال کی مثال

```ts
import { createNabiWith, mountSurface, mountToolbar, mountContextToolbar, linkWing } from 'nabi-note'
import 'nabi-note/nabi.css'

const surface = document.querySelector<HTMLElement>('#editor')!

// wing کی فہرست ایک ساتھ اصناف کی معرفت، command اور جوڑنے والا بناتی ہے — یہی `registry` ہے
const { nabi, registry } = createNabiWith([linkWing])

mountSurface({ nabi, registry, root: surface })
mountToolbar({ nabi, registry, surface, root: document.querySelector<HTMLElement>('#toolbar')! })
mountContextToolbar({ nabi, registry, surface, root: document.querySelector<HTMLElement>('#context')! })

// nabi.onChange(() => user_callback(nabi.getHtml()))
```
