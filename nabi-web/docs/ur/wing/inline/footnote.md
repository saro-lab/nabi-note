# حاشیہ

متن میں نمبروں اور دستاویز کے آخر میں فہرست کے ذریعے اضافی وضاحت شامل کریں۔

ٹول بار کے حاشیہ بٹن سے متن درج کریں تو کرسر کی جگہ حاشیہ شامل ہوتا ہے۔ اگر متن منتخب ہو تو اسے بدلے بغیر انتخاب کے آخر میں حاشیہ لگتا ہے۔ نمبر محفوظ نہیں ہوتے بلکہ دستاویز کی ترتیب کے مطابق خود بخود لگتے ہیں۔

متن میں نمبر پر کلک کرکے خصوصیات کی قطار میں مواد بدلیں۔ حذف کرنے کا ٹول استعمال کریں یا حاشیے کے پاس Backspace یا Delete دو بار دبائیں تاکہ پہلے منتخب ہو اور پھر حذف ہو۔ نیچے کی فہرست صرف پڑھنے کے لیے ہے اور حاشیے نہ ہوں تو غائب ہو جاتی ہے۔

پیش منظر اور viewer سے منسلک شائع شدہ صفحات میں نمبر پر ماؤس لے جانے، کلک یا ٹیپ کرنے سے مواد دکھائی دیتا ہے۔ صرف ایک سطر کا سادہ متن قبول ہوتا ہے، جو مرکزی متن کے بنیادی سائز کے 0.875 گنا سائز میں سانس سیرف فونٹ میں دکھتا ہے۔ HTML لفظی متن کے طور پر دکھائی دیتا ہے۔
