# جدول

## تفصیل

`tableWings` (نام `table`، شارٹ کٹ `T`) `table > tr > td` کے ڈھانچے کی مالک ہے۔

قطار (`tr`) اور خانہ (`td`) الگ سے رجسٹر نہیں ہوتے — جدول کی wing انہیں `parts`
سے ساتھ لاتی ہے، اس لیے جدول ہٹائیں تو قطار اور خانہ بھی ساتھ ہٹ جاتے ہیں۔

```ts
parts: {
  tr: { holds: 'blocks' },
  td: { holds: 'blocks', singleParagraph: true, boolAttrs: ['th'] },
}
```

خانے کا `singleParagraph` ہونا grid کی حفاظت کرتا ہے — خانے کے اندر
<kbd>Enter</kbd> دبانے سے پیراگراف دو حصوں میں نہیں بٹتا، اور دو خانوں پر
پھیلا انتخاب مٹانے سے خانے آپس میں نہیں ملتے۔

بٹن دبانے سے toggle نہیں بلکہ قطار×کالم کا سائز طے کرنے والا grid (زیادہ سے
زیادہ 8×8) نکلتا ہے، چنے گئے سائز کا جدول کیریٹ کی جگہ پر ڈل جاتا ہے اور کیریٹ
پہلے خانے میں چلا جاتا ہے۔

کیریٹ جدول کے اندر ہو تب ہی سیاق سطر پر command نکلتے ہیں۔

| قسم | خانے |
|---|---|
| قطار | اوپر قطار جوڑنا · نیچے قطار جوڑنا · قطار مٹانا |
| کالم | بائیں کالم جوڑنا · دائیں کالم جوڑنا · کالم مٹانا |
| ملانا | ملانا (ایک ہی toggle) |
| سرخی | یہ قطار سرخی بنانا · یہ کالم سرخی بنانا (`<th>` میں بدل جاتا ہے) |
| ترتیب | ترتیب کا toggle آن/آف (پڑھنے والی طرف کالم سیدھے کرتا ہے) |
| مٹانا | جدول مٹانا |

**ملانا ایک ہی toggle ہے** — سمت کے حساب سے الگ بٹن نہیں۔ کئی خانے چن کر دبائیں
تو ایک بن جاتے ہیں، اور ملے ہوئے خانے پر کیریٹ رکھ کر دوبارہ دبائیں تو الگ ہو
جاتے ہیں۔

**جدول کے ڈبے کو بائیں، درمیان، دائیں رکھنے کا خانہ اس سطر میں نہیں ہے۔** جدول
کی جگہ خود جدول نہیں بلکہ اسے تھامنے والا wrapper پیراگراف رکھتا ہے، اس لیے یہ
کام ٹول بار کا سیدھ کا بٹن کرتا ہے۔

::: warning ترتیب کا نشان اور ملانا
ترتیب صرف **ایک نشان** ہے۔ ایڈیٹر یہ نشان ملے ہوئے جدول پر بھی لگا دیتا ہے، اور
ملانے سے لگا نشان اترتا بھی نہیں۔

مگر **پڑھنے والی طرف انکار کر دیتی ہے** — `attachTableSort` ایسے جدول سے سرے سے
نہیں چپکتی جس میں ملے ہوئے خانے نظر آ رہے ہوں۔ کیونکہ ملی ہوئی قطاریں جڑی ہوتی
ہیں، اور دوبارہ ترتیب دینا grid کو توڑ دیتا ہے۔ اس لیے ملے ہوئے جدول میں نشان
ہونے کے باوجود کچھ نہیں ہوتا۔
:::

## چوڑائی مواد طے کرتا ہے

جدول میں چوڑائی کی کوئی سیٹنگ نہیں۔ جدول **صرف مواد جتنا** چوڑا ہوتا ہے، اور
جگہ سے زیادہ چوڑا ہو تو وہیں **افقی سکرول** ہو جاتا ہے — صفحہ نہیں دھکیلا جاتا۔
لپیٹنے والا `<div>` بھی نہیں ہے۔ محفوظ قدر میں صرف `<table>` نکلتا ہے، اور صرف
سیدھ (`data-nabi-align`) اور ترتیب کا نشان لگتے ہیں۔

## چلنا اور انتخاب

`Tab`/`Shift+Tab` سے خانوں کے درمیان چلا جاتا ہے (جدول کے آخر میں وہیں رک جاتا
ہے)۔ خانہ صرف inline مواد رکھتا ہے، اس لیے Enter خانے کو نہیں توڑتا بلکہ **اسی
خانے کے اندر سطر بدل دیتا ہے** — توڑنے کے لیے وہ بلاک بنانا پڑے گا جو grid سما
نہیں سکتا۔ تیر کی کلیدیں سکرین کے بجائے grid کے مطابق چلتی ہیں۔

ماؤس سے کئی خانوں پر پھیلا کر چنا جا سکتا ہے۔ یہ گھسیٹ کر چننا بھی wing خود
`attach` سے اٹھائے ہوتی ہے، اس لیے **الگ سے کوئی mount نہیں چاہیے** —
`mountSurface` ساتھ لگا دیتا ہے۔

## استعمال کی مثال

```ts
import { createNabiWith, mountSurface, mountToolbar, mountContextToolbar, tableWings } from 'nabi-note'
import 'nabi-note/nabi.css'

const surface = document.querySelector<HTMLElement>('#editor')!

// wing کی فہرست ایک ساتھ اصناف کی معرفت، command اور جوڑنے والا بناتی ہے — یہی `registry` ہے
const { nabi, registry } = createNabiWith([...tableWings])

mountSurface({ nabi, registry, root: surface })
mountToolbar({ nabi, registry, surface, root: document.querySelector<HTMLElement>('#toolbar')! })
mountContextToolbar({ nabi, registry, surface, root: document.querySelector<HTMLElement>('#context')! })

// nabi.onChange(() => user_callback(nabi.getHtml()))
```
