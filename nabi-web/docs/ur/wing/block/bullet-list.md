# بلٹ فہرست

## تفصیل

`bulletListWing` (نام `ul`، شارٹ کٹ `L`) `<ul>` کی مالک ہے۔ item کو `parts` سے
ساتھ لایا جاتا ہے، اس لیے `li` الگ سے رجسٹر نہیں ہوتی — یہ صف نہیں بلکہ record
ہے۔

```ts
parts: { li: { holds: 'blocks' } }
```

بٹن دبانے سے کیریٹ جس بلاک میں ہے (یا انتخاب میں آنے والے بلاکس) کو فہرست میں
لپیٹ دیتا ہے، دوبارہ دبائیں تو کھل کر پیراگراف بن جاتی ہے۔ کسی اور فہرست کا
بٹن دبائیں تو وہی صنف لگ جاتا ہے۔

سطر کے شروع میں ایک hyphen لکھ کر space دبائیں (`- `) تو بھی وہی نتیجہ ملتا
ہے۔ **سطر کا خالی ہونا ضروری نہیں** — صرف کیریٹ کے آگے کی سطر کا شروع دیکھا
جاتا ہے، اس لیے `- کے بعد متن` میں space دبائیں تب بھی پکڑا جاتا ہے اور بعد کا
متن item کے اندر ویسے ہی رہتا ہے۔ مگر یہ صرف پیراگراف کی **پہلی سطر** پر
پکڑا جاتا ہے۔

- `Tab` بالکل اوپر والے بہن بھائی item کے نیچے ایک درجہ اندر کرتا ہے۔ پہلے
  item کے لیے اندر جانے کی جگہ نہیں، اس لیے کچھ نہیں ہوتا — فہرست کے اندر
  `Tab` space نہیں ڈالتا۔
- `Shift+Tab` باپ کے اگلے بہن بھائی کی جگہ باہر نکالتا ہے — سب سے اوپر سے
  باہر نکالیں تو فہرست سے نکل کر پیراگراف بن جاتا ہے۔ کئی item پر انتخاب پھیلا
  ہو تو سب ایک ساتھ حرکت کرتے ہیں۔
- **خالی item پر Enter دبانا باہر نکالنا ہے** — سب سے اوپر ہو تو فہرست وہیں
  ختم ہو جاتی ہے اور کیریٹ اس کے نیچے نئے پیراگراف میں کھڑا ہوتا ہے۔ فہرست
  ختم کرنے کا راستہ یہی ہے۔
- **item کے شروع میں Backspace دبانے سے پچھلے item میں مل جاتا ہے۔** ملانے کو
  پچھلا item نہ ہو تو باہر نکل جاتا ہے۔ item کے آخر میں Delete اس کے برعکس
  اگلے item کو کھینچ لاتا ہے۔
- item کے اندر بلاک ہے، اس لیے ایک پیراگراف اندر جاتا ہے۔ mark (جلی وغیرہ)
  اور دوسری inline wing اس پیراگراف کے اندر ویسے ہی استعمال ہو سکتی ہیں۔
- ٹیگ کی پہلے سے موجود `type` جیسی خاصیت نہیں بچتی۔ فہرست میں کوئی غیر-item
  چیز آ جائے تو اسے پھینکا نہیں جاتا بلکہ ایک item میں لپیٹ دیا جاتا ہے۔
- چیک لسٹ اور یہ ٹیگ (`<ul>`) بانٹتے ہیں مگر الگ الگ wing ہیں — نشان کی
  خاصیت سے پہچانا جاتا ہے (`data-nabi-list="task"` ہو تو چیک لسٹ)۔

## اندر دوسری فہرست ہونا اصلی مارک اپ ہے

ڈھانچہ محفوظ قدر میں ویسا ہی رہتا ہے۔ مگر **item متن نہیں بلکہ بلاک تھامتا
ہے**، اس لیے متن ایک پیراگراف پہنتا ہے اور اندر کی فہرست wrapper پیراگراف کے
اندر کھڑی ہوتی ہے۔

```html
<li><p>الف</p><div data-nabi-p><ul><li><p>ب</p></li></ul></div></li>
```

## استعمال کی مثال

```ts
import { createNabiWith, mountSurface, mountToolbar, bulletListWing } from 'nabi-note'
import 'nabi-note/nabi.css'

const surface = document.querySelector<HTMLElement>('#editor')!

// wing کی فہرست ایک ساتھ اصناف کی معرفت، command اور جوڑنے والا بناتی ہے — یہی `registry` ہے
const { nabi, registry } = createNabiWith([bulletListWing])

mountSurface({ nabi, registry, root: surface })
mountToolbar({ nabi, registry, surface, root: document.querySelector<HTMLElement>('#toolbar')! })

// nabi.onChange(() => user_callback(nabi.getHtml()))
```

`li` خود بخود `parts` سے ساتھ آتی ہے، اس لیے صف میں سیدھا نہیں رکھا جاتا۔
