# سیدھ

موجودہ پیراگراف، یا منتخب حد کے پیراگراف کو بائیں، درمیان یا دائیں سیدھ دیں۔ تصاویر، ویڈیوز اور جدول جیسے آبجیکٹ جو پیراگراف کے اندر ہوتے ہیں، انہیں سمیٹنے والے پیراگراف کے ذریعے سیدھ دی جاتی ہے۔

سیدھ متن کی فارمیٹنگ کے بجائے پیراگراف کے وصف کے طور پر محفوظ ہوتی ہے۔ کوڈ بلاک سیدھ سے خارج ہیں کیونکہ وہاں انڈینٹیشن خود معنی رکھتی ہے۔

خانے کے اندر سیدھ کرسر والے اندرونی پیراگراف یا تصویر پر لاگو ہوتی ہے۔ گھسیٹ کر کئی خانے منتخب کرنے پر ان کے تمام قابلِ سیدھ پیراگراف اور تصاویر پر اطلاق ہوتا ہے۔ اگر انتخاب میں مختلف سیدھیں ہوں تو کوئی سیدھ کا بٹن منتخب ظاہر نہیں ہوتا۔

خود جدول کی سیدھ بدلنے کے لیے اس کے سیاقی ٹولز میں **پورا جدول منتخب کریں** دبائیں، یا جدول کو گھیرنے والے پیراگراف میں اس سے پہلے یا بعد کرسر رکھ کر مرکزی ٹول بار کے سیدھ والے بٹن استعمال کریں۔ تیرتے حصے کا بائیں یا دائیں مقام سیدھ کے بٹنوں کے بجائے اسی حصے کے سیاقی ٹولز سے بدلیں۔

```ts
const selected = wings().use('align').build()
```

موجودہ انتخاب پر کمانڈ لاگو کرتے وقت بائیں کے لیے `l`، درمیان کے لیے `c` اور دائیں کے لیے `r` استعمال کریں۔

```ts
nabi.applyCommand('setAlign', { value: 'c' })
```
