# AI وائب کوڈنگ

**`llms.txt`** ایک ضابطہ ہے جسے ویب سائٹس اپنا مواد AI ایجنٹس (LLM) کو دینے کے لیے استعمال
کرتی ہیں۔ HTML کے بجائے یہ پروجیکٹ کی ساخت اور استعمال کا طریقہ ایسے مارک ڈاؤن میں رکھتا ہے
جسے ایجنٹ سیدھا پڑھ سکے۔ مکمل ضابطہ [llmstxt.org](https://llmstxt.org/) پر ہے۔

اس سائٹ نے بھی یہ دروازہ کھول رکھا ہے۔ پتہ یاد رکھنے کی ضرورت نہیں — نیچے دی گئی مثالوں کی
طرح **ایجنٹ کو صرف پتہ دے دیں** اور باقی کام وہ خود کر لے گا۔

```
https://nabi.saro.me/llms.txt
```

Cursor، Claude Code، OpenAI Codex، Windsurf وغیرہ llms.txt معیار کو سپورٹ کرتے ہیں۔

## پہلی بار شامل کرتے وقت

جس سائٹ پر ابھی nabi-note استعمال نہیں ہو رہا، وہاں پہلی بار لاتے وقت ایک ہی بار میں بتا
دیں کہ کیا کیا آن کرنا ہے، لائٹ/ڈارک موڈ ہے یا نہیں، اور کس طریقے سے چلائیں گے — باقی کام
ایجنٹ خود جوڑ لے گا۔ **صرف چلانے کا طریقہ بدلتا ہے، باقی جملہ ویسا ہی رہتا ہے** — نیچے
تین جگہوں پر یہی فرق ہے۔

### npm + سرور رینڈرنگ (SSR) — جب ہر درخواست پر سرور (Node) دستاویز بنا کر بھیجے

خود بنایا ہوا Node بیک اینڈ ہو یا Next.js·Nuxt·SvelteKit جیسا SSR فریم ورک — دونوں صورتوں
میں ہر درخواست پر Node پر دستاویز بن کر بھیجی جاتی ہے، یہ بات یکساں ہے۔

```
ہماری سائٹ پر nabi-note کو نئے ایڈیٹر کے طور پر شامل کرنا ہے۔ ہدایت نامہ
https://nabi.saro.me/llms.txt ہے۔ سائٹ پر لائٹ/ڈارک موڈ ہے، ایڈیٹر کو اسی کے
مطابق رکھیں۔ ڈیفالٹ میں ملنے والے سب wings آن کر دیں۔

ہمارے یہاں Nuxt سے سرور رینڈرنگ ہوتی ہے، اور چاہتے ہیں کہ صفحہ کھلتے ہی متن پہلے
سے نظر آئے — سرور پر پہلے سے کھینچا ہوا۔ npm سے انسٹال کر کے SSR اور hydrate سے
جوڑ دیں۔
```

### npm + صرف براؤزر میں جوڑنا (CSR) — bundler موجود ہے مگر سرور رینڈرنگ کی ضرورت نہیں

```
ہماری سائٹ پر nabi-note کو نئے ایڈیٹر کے طور پر شامل کرنا ہے۔ ہدایت نامہ
https://nabi.saro.me/llms.txt ہے۔ سائٹ پر لائٹ/ڈارک موڈ ہے، ایڈیٹر کو اسی کے
مطابق رکھیں۔ ڈیفالٹ میں ملنے والے سب wings آن کر دیں۔

یہ Vite سے بنایا گیا فرنٹ اینڈ ہے، سرور رینڈرنگ کی ضرورت نہیں۔ npm سے انسٹال کر
کے صرف براؤزر میں جوڑ دیں۔
```

### CDN — بغیر بلڈ ٹول کے سادہ (static) صفحہ

```
ہماری سائٹ پر nabi-note کو نئے ایڈیٹر کے طور پر شامل کرنا ہے۔ ہدایت نامہ
https://nabi.saro.me/llms.txt ہے۔ سائٹ پر لائٹ/ڈارک موڈ ہے، ایڈیٹر کو اسی کے
مطابق رکھیں۔ ڈیفالٹ میں ملنے والے سب wings آن کر دیں۔

یہ صفحہ بغیر بلڈ ٹول کے سادہ HTML ہے۔ `<script>` ٹیگ سے جوڑ دیں۔
```

::: tip لائٹ اور ڈارک کے لیے الگ سے کچھ بتانے کی ضرورت نہیں
`nabi.css` میں لائٹ کی ڈیفالٹ قدریں، `.dark` اوور رائیڈ، اور واضح `.light` اوور رائیڈ —
تینوں پہلے سے شامل ہیں۔ صفحے کی `dark`/`light` کلاس ویسے ہی چھوڑ دیں تو ایڈیٹر خود اس کی
پیروی کرتا ہے۔ برانڈ کا رنگ بدلنا ہو تو `llms/styling.md` بھی ساتھ پڑھوا دیں۔
:::

تینوں مثالوں میں صرف آخری جملہ بدلتا ہے — ایجنٹ بالترتیب `llms/ssr.md`
(‏+ `llms/quickstart-npm.md`)، `llms/quickstart-npm.md`، اور `llms/quickstart-cdn.md`
تلاش کر کے پڑھتا ہے اور اسی طریقے سے جوڑتا ہے۔

## فیچر بدلنا، شامل کرنا یا ہٹانا

جہاں nabi-note پہلے سے لگا ہوا ہے، وہاں کچھ بدلنے یا شامل کرنے سے پہلے **سیدھا
عملدرآمد کے بجائے پہلے تحقیق کر کے منصوبہ بنوانا** زیادہ محفوظ ہے — خاص طور پر جو
فیچر بیک اینڈ تک جاتا ہو، وہاں کوڈ لکھنے سے پہلے یہ جاننا ضروری ہے کہ کیا تیار کرنا ہوگا۔

### مثال — پہلے تحقیق اور منصوبہ

```
فائل اپلوڈ کا فیچر شامل کرنا ہے۔ https://nabi.saro.me/llms/wings.md اور
https://nabi.saro.me/llms/api-reference.md دیکھ کر معلوم کریں کہ upload wing
آن کرنے کے لیے ہمارے بیک اینڈ میں کیا ہونا چاہیے (فائل وصول کرنے کا پتہ، کن
extensions اور سائز کی اجازت ہے، ناکامی پر جواب کی شکل کیا ہو)۔ ابھی کچھ نہ
بنائیں — صرف یہ بتا دیں کہ کیا تیار کرنا ہوگا، منصوبے کی شکل میں۔
```

ایجنٹ `llms/wings.md` میں دیکھے گا کہ `upload` ایک ٹول wing ہے جو `Uploader` لیتا
ہے، اور `llms/api-reference.md` میں `mountUpload`·`Uploader`·`allowLocalUrls`
کی اصل شکل معلوم کر کے، بیک اینڈ میں کیا کھولنا ہے اور فرنٹ اینڈ میں کیا طے ہوگا،
دونوں کو الگ الگ منصوبے میں لکھ دے گا۔ منصوبہ دیکھ کر منظوری دینے کے بعد ہی
عملدرآمد کا کام آگے بڑھائیں۔

### آسان مثال — سیدھا کہا جا سکتا ہے

جس تبدیلی کے لیے منصوبے کی ضرورت نہیں، وہ سیدھا کہی جا سکتی ہے۔

```
https://nabi.saro.me/llms/styling.md دیکھ کر صرف accent رنگ اور ڈارک تھیم کا
پس منظر ہمارے برانڈ کے رنگوں میں بدل دیں۔
```

::: tip معاہدہ توڑنے والا wing رجسٹر ہوتے ہی رد ہو جاتا ہے
نیا wing بنواتے وقت ایجنٹ سے [`llms/custom-wing.md`](https://nabi.saro.me/llms/custom-wing.md)
بھی پڑھوائیں۔ عام غلطیاں — کسی محفوظ لفظ کو نام کے طور پر استعمال کرنا، یا نوڈ
بنانے والے wing میں `toHtml` نہ ہونا — دیر سے ظاہر نہیں ہوتیں، بلکہ **رجسٹر ہوتے
ہی رد کر دی جاتی ہیں۔** اس دستاویز کے "رجسٹر ہوتے ہی وہیں رد" والے حصے میں بتایا
گیا ہے کہ کیا پکڑا جاتا ہے۔
:::

::: tip شامل کرنے کا کام مکمل ہو جائے تو ایک سطر چھوڑ دیں
ایک بار جوڑنے کے بعد، ہر بار دوبارہ پتہ بتانے کی ضرورت نہیں۔ پروجیکٹ کی قواعد
فائل (`CLAUDE.md`، `.cursorrules` وغیرہ) میں ایسی ایک سطر لکھ دیں تو "nabi-note
سے یہ کر دیں" کہنا کافی ہوگا، ایجنٹ خود پتہ ڈھونڈ لے گا۔

```md
یہ پروجیکٹ ایڈیٹر کے طور پر `nabi-note` استعمال کرتا ہے۔ اس سے متعلق کوئی بھی
کام کرنے سے پہلے https://nabi.saro.me/llms.txt ضرور دیکھ لیں۔
```
:::
