# संरेखण

## विवरण

`alignWing` (id `align`) **एक ही** wing बाएँ·बीच·दाएँ तीनों को साथ रखता है।
टूलबार में यह स्थिरांक है — एक साथ बाँधने वाली `align()` फ़ैक्ट्री नहीं है, हर
मान का अपना बटन अलग है। यह ब्लॉक पर `data-nabi-align` एट्रिब्यूट लगाता है।

- यह **ब्लॉक एट्रिब्यूट** है — टैग जस का तस रहता है और सिर्फ़ एट्रिब्यूट जुड़ता है।
  `<p data-nabi-align="center">` की तरह, पैराग्राफ़ ख़ुद नहीं बदलता।
- **यह पैराग्राफ़ और शीर्षक, दोनों पर लगता है।** `<h2 data-nabi-align="c">` भी
  चलता है — शीर्षक भी आख़िर एक पंक्ति ही है। पैराग्राफ़ के चार एट्रिब्यूट में से यह
  बात सिर्फ़ संरेखण पर लागू है; टेक्स्ट का आकार·फ़ॉन्ट·ड्रॉप कैप अब भी सिर्फ़
  पैराग्राफ़ के लिए हैं।
- एक बार में एक ही मान टिकता है — बाएँ संरेखित लगा हो और बीच में संरेखित दबाएँ तो
  बायाँ गिर जाता है और बीच वाला लग जाता है। जो मान पहले से लगा है उसे दोबारा दबाएँ
  तो एट्रिब्यूट पूरा का पूरा उतर जाता है (डिफ़ॉल्ट संरेखण पर वापसी)।
- **Enter संरेखण को दोनों तरफ़ ज्यों का त्यों सौंप देता है।** पैराग्राफ़ को दो
  में बाँटने पर दोनों पैराग्राफ़ एक-सा संरेखण लेकर निकलते हैं — शीर्षक (`h`) खाली
  तरफ़ से गिर जाता है और ड्रॉप कैप (`dc`) सिर्फ़ एक तरफ़ जाता है, इनसे अलग संरेखण
  में कोई अपवाद नहीं है।
- तीनों एक ही wing के **तीन बटन** हैं (`buttons`) — इन्हें अलग-अलग बंद-चालू नहीं
  किया जा सकता, wings ऐरे में सिर्फ़ `alignWing` एक ही डाला जाता है।
- **तालिका·छवि·YouTube की जगह भी यही wing तय करता है।** वस्तु अपने रैपर-पैराग्राफ़
  के भीतर रहती है, और संरेखण उसी पैराग्राफ़ पर लगता है, इसलिए "बीच में संरेखित
  छवि" का मतलब है "बीच-संरेखित पैराग्राफ़ के भीतर की छवि"। इसीलिए छवि·तालिका की
  कॉन्टेक्स्ट पंक्ति में संरेखण का कक्ष सिरे से नहीं है, और सिर्फ़ संरेखण ही
  ऐसा है जो वस्तु पर कर्सर हो तब भी टूलबार से नहीं छिपता।

## उपयोग

```ts
import { createNabiWith, mountSurface, mountToolbar, alignWing } from 'nabi-note'
import 'nabi-note/nabi.css'

const surface = document.querySelector<HTMLElement>('#editor')!

// wing की सूची श्रेणी-ज्ञान · कमांड · असेंबलर एक साथ बनाती है — वही `registry` है
const { nabi, registry } = createNabiWith([alignWing])

mountSurface({ nabi, registry, root: surface })
mountToolbar({ nabi, registry, surface, root: document.querySelector<HTMLElement>('#toolbar')! })

// nabi.onChange(() => user_callback(nabi.getHtml()))
```
