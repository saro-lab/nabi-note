# अक्षर-आकार

## विवरण

`fontSizeWing` (नाम `fs`) एक **इनलाइन मान-मार्क** है। यह अक्षर के ऊपर लगने
वाला फ़ॉर्मेट है, पैराग्राफ़ का गुण नहीं। बाहर जाते समय यह
`<span data-nabi-size="lg">` बनकर खिंचता है।

मान चार हैं — `xs`·`sm`·`lg`·`xl` — और डिफ़ॉल्ट आकार कोई पाँचवाँ मान नहीं,
बल्कि **सिरे से कोई attribute न होना** है।

- यह टाइपफ़ेस (`tf`) की जोड़ी है — एक ही wing सारे मान रखता है, और चुनने की
  जगह कॉन्टेक्स्ट पंक्ति है। बस टाइपफ़ेस चार कक्ष फैलाता है, और आकार एक ही
  स्केल इस्तेमाल करता है।
- **कॉन्टेक्स्ट पंक्ति एक स्केल (`range`) इस्तेमाल करती है।** आकार का क्रम
  होता है (छोटे से बड़े की ओर), इसलिए कक्ष फैलाने के बजाय एक ही हैंडल से
  खिसकाया जाता है। अभी लगा मान हैंडल की जगह से दिखता है, और साथ में उस मान का
  नाम लेबल के रूप में दिखता है।
- **स्केल का सबसे पहला कक्ष "डिफ़ॉल्ट" है।** यह बीच में नहीं बल्कि सबसे आगे
  होने की वजह यह है कि सूची छोटे से बड़े क्रम में है, और वही पहली जगह
  "कोई attribute न लगे होने" की जगह है। उस कक्ष पर जाएँ तो `base` जैसा कोई मान
  नहीं लिखा जाता, बल्कि **मार्क उतर जाता है।**
- **कक्ष का लेबल भाषा के हिसाब से बदलता है** — हिन्दी में "डिफ़ॉल्ट · बहुत
  छोटा · छोटा · बड़ा · बहुत बड़ा"।
- टूलबार बटन दबाने पर **`lg` (बड़ा)** लगता है। स्केल छोटे से शुरू होने के कारण
  यूँ ही छोड़ दें तो पहला कक्ष `xs` लग जाता, और आकार वाला बटन दबाकर कोई नहीं
  चाहता कि अक्षर छोटा हो जाए।
- **सिर्फ़ कर्सर हो तो पूरे पैराग्राफ़ पर** लगता है। सिर्फ़ एक शब्द बड़ा करना
  मुश्किल ही चाहा जाता है, इसलिए रेंज न चुनी हो तो यह पूरे पैराग्राफ़ को निशाना
  बनाता है (हाइलाइट और टेक्स्ट-रंग इसके उलट, सिर्फ़ अभी के मार्क के हिस्से को
  निशाना बनाते हैं)।
- जिस पैराग्राफ़ में एक भी अक्षर न हो वहाँ दबाएँ तो **आरक्षण** के रूप में बचा
  रहता है — अगला टाइप किया अक्षर उसी आकार में निकलता है।
- वही मान फिर लगाएँ तो हट जाता है।

## उपयोग का उदाहरण

```ts
import { createNabiWith, mountSurface, mountToolbar, mountContextToolbar, fontSizeWing } from 'nabi-note'
import 'nabi-note/nabi.css'

const surface = document.querySelector<HTMLElement>('#editor')!

// wing की सूची किस्म का ज्ञान·कमांड·बिल्डर एक साथ बनाती है — वही `registry` है
const { nabi, registry } = createNabiWith([fontSizeWing])

mountSurface({ nabi, registry, root: surface })
mountToolbar({ nabi, registry, surface, root: document.querySelector<HTMLElement>('#toolbar')! })
mountContextToolbar({ nabi, registry, surface, root: document.querySelector<HTMLElement>('#context')! })

// nabi.onChange(() => user_callback(nabi.getHtml()))
```
