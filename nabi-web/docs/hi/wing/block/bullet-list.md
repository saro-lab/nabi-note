# बुलेट सूची

## विवरण

`bulletListWing` (id `ul`, शॉर्टकट `L`) `<ul>` का स्वामी है। आइटम `parts` के ज़रिए
साथ आता है, इसलिए `li` को अलग से रजिस्टर नहीं करना पड़ता — यह ऐरे नहीं, रिकॉर्ड है।

```ts
parts: { li: { holds: 'blocks' } }
```

बटन दबाने पर, कर्सर जिस ब्लॉक में है उसे (या चुनाव में आए ब्लॉकों को) सूची में
लपेट दिया जाता है, और दोबारा दबाने पर लपेट खुलकर वह पैराग्राफ़ में लौट आता है।
दूसरा सूची बटन दबाने पर वह उस किस्म में बदल जाता है।

पंक्ति की शुरुआत में हाइफ़न लिखकर स्पेस दबाने पर (`- `) भी वही नतीजा है। **खाली
पंक्ति होना ज़रूरी नहीं** — सिर्फ़ कर्सर से पहले की पंक्ति-शुरुआत देखी जाती है,
इसलिए `- बाद का टेक्स्ट` में स्पेस दबाने पर भी यह लग जाता है और बाकी टेक्स्ट आइटम
के भीतर वैसा ही रहता है। पर यह सिर्फ़ पैराग्राफ़ की **पहली पंक्ति** पर ही लगता है।

- `Tab` ठीक ऊपर वाले भाई-आइटम के नीचे एक स्तर भीतर ले जाता है। पहले आइटम के लिए
  कोई जगह नहीं होती, इसलिए कुछ नहीं होता — सूची के भीतर `Tab` स्पेस नहीं डालता।
- `Shift+Tab` माता-पिता के अगले भाई के रूप में बाहर ले आता है — शीर्ष स्तर पर बाहर
  लाएँ तो वह सूची से निकलकर पैराग्राफ़ बन जाता है। कई आइटमों पर चुनाव फैला हो तो
  उसमें आए सारे आइटम साथ-साथ खिसकते हैं।
- **खाली आइटम पर Enter दबाने का मतलब बाहर लाना है** — शीर्ष स्तर पर हो तो सूची
  वहीं ख़त्म हो जाती है और कर्सर नीचे नए पैराग्राफ़ में जा बैठता है। सूची ख़त्म
  करने का यही रास्ता है।
- **आइटम की शुरुआत में Backspace दबाने पर वह पिछले आइटम में जुड़ जाता है।** जुड़ने
  को पिछला आइटम न हो तो बाहर आ जाता है। आइटम के अंत में Delete इसका उल्टा करता है
  — अगला आइटम खींच लाता है।
- आइटम के भीतर ब्लॉक होता है, इसलिए एक पैराग्राफ़ की परत चढ़ती है। मार्क (बोल्ड
  आदि) और दूसरे इनलाइन wing उस पैराग्राफ़ के भीतर वैसे ही चलते हैं।
- टैग पर जो `type` जैसे एट्रिब्यूट थे, वे नहीं बचते। सूची में आइटम न होने वाली
  चीज़ आए तो उसे फेंका नहीं जाता, एक आइटम में लपेट दिया जाता है।
- चेकलिस्ट के साथ टैग (`<ul>`) साझा होता है पर दोनों अलग wing हैं — वे चिह्न वाले
  एट्रिब्यूट से बँटते हैं (`data-nabi-list="task"` हो तो चेकलिस्ट)।

## नेस्टिंग असली मार्कअप है

ढाँचा सहेजे गए मान में वैसा ही रहता है। पर **आइटम टेक्स्ट नहीं, ब्लॉक रखता है**,
इसलिए टेक्स्ट पर एक पैराग्राफ़ की परत चढ़ती है और नेस्ट की गई सूची रैपर-पैराग्राफ़
के भीतर बैठती है।

```html
<li><p>क</p><div data-nabi-p><ul><li><p>ख</p></li></ul></div></li>
```

## उपयोग

```ts
import { createNabiWith, mountSurface, mountToolbar, bulletListWing } from 'nabi-note'
import 'nabi-note/nabi.css'

const surface = document.querySelector<HTMLElement>('#editor')!

// wing की सूची श्रेणी-ज्ञान · कमांड · असेंबलर एक साथ बनाती है — वही `registry` है
const { nabi, registry } = createNabiWith([bulletListWing])

mountSurface({ nabi, registry, root: surface })
mountToolbar({ nabi, registry, surface, root: document.querySelector<HTMLElement>('#toolbar')! })

// nabi.onChange(() => user_callback(nabi.getHtml()))
```

`li` `parts` के ज़रिए अपने आप साथ आ जाता है, इसलिए उसे सीधे ऐरे में नहीं डालते।
