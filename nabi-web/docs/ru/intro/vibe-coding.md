# AI-вайб-кодинг

**`llms.txt`** — это стандарт, по которому сайт передаёт своё содержимое AI-агентам (LLM).
Вместо HTML он раскладывает структуру проекта и способ его использования в markdown, который
агент читает прямо так. Полная спецификация — на [llmstxt.org](https://llmstxt.org/).

Этот сайт тоже открыл такую дверь. Адрес запоминать не нужно — как в примере ниже, **просто
дайте агенту этот адрес**, а дальше он сам разберётся.

```
https://nabi.saro.me/llms.txt
```

Cursor, Claude Code, OpenAI Codex, Windsurf и другие поддерживают стандарт llms.txt.

## При первом внедрении

Если на сайте ещё нет nabi-note, скажите агенту сразу и то, что нужно включить, и есть ли
светлая/тёмная тема, и каким способом вы его подключаете — остальное агент собирает сам.
**Меняется только последняя фраза в трёх случаях ниже, остальное можно оставить как есть.**

### npm + рендеринг на сервере (SSR) — когда документ рисуется на сервере (Node) при каждом запросе

Сюда относится и свой backend на Node, и SSR-фреймворк вроде Next.js, Nuxt или SvelteKit — в
обоих случаях документ рисуется на Node и отправляется при каждом запросе.

```
Хотим подключить nabi-note как новый редактор на нашем сайте. Инструкция —
https://nabi.saro.me/llms.txt. На сайте есть светлая/тёмная тема, подстрой
редактор под неё. Включи все крылья, которые идут по умолчанию.

У нас рендеринг на сервере через Nuxt, и мы хотим, чтобы текст был виден сразу
при заходе на страницу — заранее нарисованным на сервере. Установи через npm
и подключи через SSR и hydrate.
```

### npm + сборка только в браузере (CSR) — есть бандлер, но рендеринг на сервере не нужен

```
Хотим подключить nabi-note как новый редактор на нашем сайте. Инструкция —
https://nabi.saro.me/llms.txt. На сайте есть светлая/тёмная тема, подстрой
редактор под неё. Включи все крылья, которые идут по умолчанию.

Это фронтенд, собираем через Vite, рендеринг на сервере не нужен. Установи
через npm и собери всё только в браузере.
```

### CDN — статическая страница без инструментов сборки

```
Хотим подключить nabi-note как новый редактор на нашем сайте. Инструкция —
https://nabi.saro.me/llms.txt. На сайте есть светлая/тёмная тема, подстрой
редактор под неё. Включи все крылья, которые идут по умолчанию.

Эта страница — статический HTML без инструментов сборки. Подключи через тег
`<script>`.
```

::: tip Про светлую и тёмную тему объяснять отдельно не нужно
`nabi.css` уже несёт светлые значения по умолчанию, переопределение `.dark` и явное
переопределение `.light`. Просто оставьте классы `dark`/`light` страницы как есть — редактор
сам их подхватит. Если нужно поменять только цвет бренда, дайте агенту прочитать ещё
`llms/styling.md`.
:::

Все три примера различаются только последней фразой — агент находит и читает соответственно
`llms/ssr.md` (плюс `llms/quickstart-npm.md`), `llms/quickstart-npm.md` и
`llms/quickstart-cdn.md`, и подключает именно так.

## Когда меняете, добавляете или убираете функцию

Если nabi-note уже подключён, изменение или добавление чего-то безопаснее просить как
**сначала разведку и план, а не сразу реализацию** — особенно если это касается backend, где
сперва нужно понять, что готовить.

### Пример — сначала разведка и план

```
Хочу добавить загрузку файлов. Прочитай https://nabi.saro.me/llms/wings.md и
https://nabi.saro.me/llms/api-reference.md и выясни, что нужно подготовить на
нашем backend, чтобы включить крыло upload (адрес, принимающий файлы,
разрешённые расширения и ограничения по размеру, как должен выглядеть ответ
при ошибке). Пока не реализуй — просто покажи план, что нужно подготовить.
```

Агент найдёт в `llms/wings.md`, что `upload` — это крыло-инструмент, принимающее `Uploader`,
уточнит в `llms/api-reference.md` реальные сигнатуры `mountUpload`, `Uploader` и
`allowLocalUrls`, и составит план, разделив то, что должен открыть backend, и то, что решает
сам frontend. После того как план одобрен, можно просить реализацию.

### Более простой пример — можно просить прямо

Узкую правку, для которой план не нужен, можно попросить сразу.

```
Прочитай https://nabi.saro.me/llms/styling.md и поменяй только акцентный цвет
и фон тёмной темы на наши цвета бренда.
```

::: tip Крыло, нарушающее контракт, отбрасывается сразу при регистрации
Когда просите агента построить новое крыло, дайте ему прочитать ещё
[`llms/custom-wing.md`](https://nabi.saro.me/llms/custom-wing.md). Частые ошибки —
использовать зарезервированное слово как имя, или крыло, создающее узел, но без `toHtml` — не
всплывают потом: они **бросают исключение в момент регистрации**. В том документе раздел
«Здесь всё умирает сразу при регистрации» перечисляет, что проверяется.
:::

::: tip Когда всё подключено, оставьте одну строку
После первого подключения не нужно каждый раз повторять адрес. Одна такая строка в файле
правил проекта (`CLAUDE.md`, `.cursorrules` и так далее) — и просьбы вида «сделай то-то с
nabi-note» будет достаточно, агент сам найдёт адрес.

```md
Этот проект использует `nabi-note` как редактор. Перед любой связанной с
ним работой сначала проверьте https://nabi.saro.me/llms.txt.
```
:::
