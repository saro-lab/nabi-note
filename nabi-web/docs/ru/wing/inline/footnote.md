# Сноска

Связывайте дополнительные пояснения с номерами в тексте и списком в конце документа.

Введите текст с помощью кнопки сноски на панели инструментов, чтобы вставить сноску в позицию курсора. Если текст выделен, сноска добавляется в конце выделения, сохраняя сам текст. Номера не сохраняются, а автоматически назначаются по порядку в документе.

Нажмите номер в тексте, чтобы изменить содержимое в строке свойств. Используйте инструмент удаления или дважды нажмите Backspace либо Delete рядом со сноской, чтобы сначала выделить, а затем удалить её. Список внизу доступен только для чтения и исчезает, когда сносок нет.

В предпросмотре и на опубликованных страницах с подключённым viewer наведите указатель, щёлкните или коснитесь номера, чтобы прочитать содержимое. Допускается одна строка обычного текста, которая отображается шрифтом без засечек размером 0,875 от базового размера основного текста. HTML отображается буквально.
