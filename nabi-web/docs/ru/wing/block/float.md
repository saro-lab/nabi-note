# Плавающая область

Разместите короткое описание, изображение или небольшую таблицу слева или справа, чтобы основной текст обтекал их. Содержимое области можно редактировать непосредственно в том же редакторе. Пунктирная рамка появляется только при редактировании; в предпросмотре и опубликованном представлении остаются только содержимое и расположение.

Установите курсор внутри области в примере ниже и измените сторону и максимальную ширину с помощью инструментов свойств. В предпросмотре можно увидеть обтекание текста без пунктирной рамки.

<WingDemo path="/wing/block/float" />

```ts
const selected = wings().allBasic().build()
```

Плавающие области входят в базовые крылья. Если вы собираете только нужные крылья, используйте `wings().use('float')` или зарегистрируйте `floatWing` напрямую. Также зарегистрируйте крылья изображений, таблиц, списков и другого содержимого, используемого внутри области.

## Создание и размещение

Установите курсор в основном тексте и нажмите **Плавающая область**, чтобы создать пустую область. По умолчанию она располагается справа с максимальной шириной 40%. Если перед нажатием выбрать несколько абзацев, все абзацы, затронутые выделением, целиком объединяются в одну область. Нельзя повторно оборачивать существующую плавающую область или создавать другую плавающую область внутри неё.

```ts
nabi.applyCommand('insertFloat', { side: 'right', w: 40 })
```

Когда курсор находится внутри области, инструменты свойств позволяют выбрать левую или правую сторону и максимальную ширину. Доступны 20%, 30%, 40% и 50%. Ширина задаётся относительно основного текста, а не всего экрана; при коротком содержимом фактическая область может быть уже.

```ts
nabi.applyCommand('setFloatSide', { side: 'left' })
nabi.applyCommand('setFloatWidth', { w: 30 })
```

Вставка текста, изображений и таблиц, преобразование блоков и загрузки остаются внутри области. Удаление внутренней таблицы удаляет только эту таблицу. Если выделение одновременно охватывает содержимое внутри и снаружи области, вставка и преобразование внутренних блоков недоступны.

Кнопка **Убрать плавающую область** рядом со значением ширины возвращает содержимое в основной текст, не удаляя его. Создание, изменение расположения и снятие обёртки поддерживают отмену и повтор.

```ts
nabi.applyCommand('unwrapFloat')
```

## Как текст обтекает область

Следующие абзацы обтекают область, а после её окончания снова занимают всю ширину основного текста. Следующий заголовок, таблица, блок кода, разделитель или новая плавающая область начинается ниже предыдущей области.

При ширине основного текста меньше `36rem` область и текст располагаются в одну колонку. При печати также используется одна колонка, а сохранённые сторона и максимальная ширина остаются неизменными. Представление сравнения документов сохраняет сторону и максимальную ширину каждой области, но показывает следующий блок отдельно под ней, чтобы изменения было легче читать.

## Сохранение и загрузка

JSON сохраняет `a.side` и `a.w` узла `float` вместе с его внутренними блоками. В HTML атрибуты `data-nabi-float` и `data-nabi-float-width` задаются на `div` внутри обычного объектного абзаца.

```html
<div data-nabi-p>
  <div data-nabi-float="right" data-nabi-float-width="40">
    <p>Описание, расположенное рядом с основным текстом.</p>
  </div>
</div>
<p>Этот абзац продолжается рядом с областью.</p>
```

При экспорте в Markdown область сохраняется как HTML. Произвольные CSS-стили `float` не импортируются, поэтому для сохранения и восстановления используйте JSON или HTML, созданный NABI NOTE. Подключайте одинаковые крылья и CSS в редакторе, SSR, предпросмотре и опубликованном представлении, чтобы сохранить сторону и ширину.

## Стили CSS

Цвета и отступы внутри области можно настроить селектором `[data-nabi-float]`. Внешний абзац управляет расположением и максимальной шириной, поэтому не переопределяйте напрямую `float`, `display` или ширину.

```css
.brand-note .nabi-content [data-nabi-float] {
  background: var(--nabi-soft);
  border-radius: var(--nabi-radius);
  padding: .75rem;
}
```
