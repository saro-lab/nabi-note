# Изображение

Добавляет адрес изображения и позволяет настроить ширину и выравнивание. По умолчанию разрешены только адреса `http:`, `https:` и пути того же сайта; новое изображение создаётся с выравниванием по центру и шириной 60%.

Ширина сохраняется только как одна из заданных ступеней, а выравнивание — в абзаце, содержащем изображение. Чтобы использовать предварительный просмотр через `blob:` или `data:image/...`, явно разрешите локальные URL и в image wing, и при сборке редактора. SVG data URL не разрешены.

<WingDemo path="/wing/block/image" />

```ts
const selected = wings().use('img', {
  allowLocalUrls: false,
}).build()
```

Эта wing помещает адрес в документ, но не передаёт файл. Чтобы отправить файл на сервер, подключите [wing загрузки](/ru/wing/etc/upload).

## Подключение выбора изображения

С помощью `panels.img` в `mountToolbar()` можно заменить стандартное окно ввода URL кнопки изображения на окно выбора изображений вашего сервиса. Ключи — имена слотов панели инструментов; неуказанные инструменты сохраняют стандартные окна ввода.

`mode: 'modal'` открывает окно поверх полупрозрачного фона на всю страницу. `mode: 'inline'` открывает его рядом с кнопкой инструмента на компьютере и на весь экран на мобильном устройстве. Мобильный режим определяется шириной области просмотра и `--nabi-mobile-breakpoint`; при пересечении этого порога открытая панель `inline` закрывается.

Оба режима предоставляют только пустой `root`, без заголовка, полей ввода и кнопок. Добавьте свой HTML или интерфейс в `render`, свяжите кнопку закрытия с `close()`, а выбор изображения — с `insertImage(url, 'pointer')`. Существующие настройки в виде функции (`img: renderer`) сохраняют прежний способ отображения.

```ts
import { mountToolbar } from 'nabi-note'

const toolbar = mountToolbar({
  nabi,
  registry,
  root: toolbarRoot,
  surface: content,
  panels: {
    img: {
      mode: 'inline',
      render: ({ root, signal, close, insertImage }) =>
        mountMyImagePicker(root, {
          signal,
          onClose: close,
          onSelect: (url: string) => insertImage(url, 'pointer'),
        }),
    },
  },
})
```

`mountMyImagePicker` — функция, которую вы реализуете в своём сервисе. Она синхронно создаёт нужный интерфейс внутри переданного `root` и возвращает функцию очистки. Подключите `signal` к асинхронным операциям, например загрузке списка изображений или отправке файлов, и передайте URL выбранного изображения в `onSelect`. Этот API не передаёт файлы; существующие правила для URL изображений остаются в силе.

`insertImage(src, by?)` эквивалентен `run('insertImage', { src }, by)`, включая возвращаемое значение и правила восстановления выделения. Если `by` не указан, используется `'keyboard'`. Не объявляйте `render` как функцию `async`.

При закрытии окна или размонтировании панели инструментов `signal` прерывается и вызывается функция очистки. `run()` закрывает окно и однократно применяет команду к выделению, сохранённому при открытии. Если окно уже закрыто или содержимое документа изменилось после открытия, возвращается `false` без выполнения команды.

## CSS-стили

Изображение оформляется через `.nabi-content img`. Сохраняйте записанные ширину и выравнивание, изменяя только внешний вид — например, рамку или тень.

```css
.article-body img {
  border-radius: 12px;
  box-shadow: 0 8px 24px rgb(0 0 0 / 12%);
}

.dark .article-body img { box-shadow: 0 8px 24px rgb(0 0 0 / 35%); }
```

Не переопределяйте базовые правила `max-inline-size`, `block-size`, ширины и выравнивания. Размер изображения сохранён в документе, поэтому принудительное значение в CSS может противоречить ширине, выбранной автором.
