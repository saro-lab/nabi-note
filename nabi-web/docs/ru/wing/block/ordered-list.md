# Нумерованный список

## Описание

`orderedListWing` (id `ol`, сочетание `N`) владеет тегом `<ol>`. Пункт приходит
вместе с ним через `parts` — регистрировать `oli` отдельно не нужно, это не
массив, а запись.

```ts
parts: { oli: { holds: 'blocks' } }
```

По нажатию кнопки блок, в котором стоит каретка (или все блоки, задетые
выделением), оборачивается в нумерованный список, а по повторному нажатию —
разворачивается обратно. Нажатие другой кнопки списка переодевает блок в тот
вид.

Тот же результат даёт набранная в начале строки последовательность «цифры +
точка + пробел» (`1. ` и тому подобное). **Начальным числом признаётся любое, но
самих цифр не больше девяти** (`1234567890. ` не сработает), а если после точки
есть что-то ещё, как в `1.2 ` — тоже не сработает. Строка не обязана быть
пустой — учитывается только начало строки перед кареткой, и срабатывает это
только в первой строке абзаца.

- Отступы по `Tab`/`Shift+Tab`, завершение списка через Enter в пустом пункте и
  слияние по Backspace в начале пункта — всё это работает так же, как в
  [маркированном списке](./bullet-list).
- Номер не попадает в сохранённое значение — его рисует `<ol>`, так что при
  вставке или удалении пункта браузер сам пересчитывает нумерацию.
- Вложенность тоже остаётся в сохранённом значении настоящей разметкой. Пункт
  содержит блоки, поэтому текст надевает один слой абзаца, а вложенный список
  стоит внутри абзаца-обёртки.
- Атрибуты вроде `start`·`type` не сохраняются. Поэтому список, пришедший с
  `start="5"`, тоже будет считаться заново с единицы.

## Пример использования

```ts
import { createNabiWith, mountSurface, mountToolbar, orderedListWing } from 'nabi-note'
import 'nabi-note/nabi.css'

const surface = document.querySelector<HTMLElement>('#editor')!

// список крыльев вместе строит знание о видах, команды и сборщики — это и есть `registry`
const { nabi, registry } = createNabiWith([orderedListWing])

mountSurface({ nabi, registry, root: surface })
mountToolbar({ nabi, registry, surface, root: document.querySelector<HTMLElement>('#toolbar')! })

// nabi.onChange(() => user_callback(nabi.getHtml()))
```
