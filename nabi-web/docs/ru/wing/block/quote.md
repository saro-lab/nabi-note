# Цитата

## Описание

`quoteWing` (id `quote`) владеет блоком цитаты (`<blockquote>`). Это
`place: 'container'` и `holds: 'blocks'` — внутри живут блоки. Как и любой другой
объект, сама цитата надевает абзац-обёртку и стоит на верхнем уровне.

**`allows` не выставлен.** Внутри цитаты действуют те же правила, что и на
верхнем уровне, поэтому таблица или изображение тоже могут надеть
абзац-обёртку и встать внутри неё — такой HTML, если его вставить или
загрузить, останется как есть.

```json
[{"w":"p","ch":[{"w":"quote","ch":[
  {"w":"p","ch":["текст"]},
  {"w":"p","ch":[{"w":"table","ch":[]}]}
]}]}]
```

Но **кнопка вставки внутрь цитаты не заходит.** Всё, что встаёт через
`insertLump` — изображение, таблица, разделитель, — всегда занимает место на
**верхнем уровне**, поэтому даже если каретка стоит внутри цитаты, новый объект
окажется **после** неё. Чтобы поместить что-то внутрь цитаты, нужно вставить это
через буфер обмена.

По нажатию кнопки все верхнеуровневые блоки, задетые выделением, оборачиваются в
цитату. Разворачивается цитата обратно, только если задетое **целиком уже
цитата** — если состав смешанный, всё ещё раз оборачивается целиком.

Наберите в начале строки один `>` и нажмите пробел — строка тоже станет
цитатой; здесь автозамену **запускает пробел** (а не Enter), потому что писать
вы продолжаете на той же строке.

## Пример использования

```ts
import { createNabiWith, mountSurface, mountToolbar, quoteWing } from 'nabi-note'
import 'nabi-note/nabi.css'

const surface = document.querySelector<HTMLElement>('#editor')!

// список крыльев вместе строит знание о видах, команды и сборщики — это и есть `registry`
const { nabi, registry } = createNabiWith([quoteWing])

mountSurface({ nabi, registry, root: surface })
mountToolbar({ nabi, registry, surface, root: document.querySelector<HTMLElement>('#toolbar')! })

// nabi.onChange(() => user_callback(nabi.getHtml()))
```
