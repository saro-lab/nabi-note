# Маркированный список

## Описание

`bulletListWing` (id `ul`, сочетание `L`) владеет тегом `<ul>`. Пункт приходит
вместе с ним через `parts` — регистрировать `li` отдельно не нужно, это не
массив, а запись.

```ts
parts: { li: { holds: 'blocks' } }
```

По нажатию кнопки блок, в котором стоит каретка (или все блоки, задетые
выделением), оборачивается в список, а по повторному нажатию — разворачивается
обратно в абзацы. Нажатие другой кнопки списка переодевает блок в тот вид.

Тот же результат даёт дефис с пробелом (`- `), набранный в начале строки.
**Строка не обязана быть пустой** — учитывается только начало строки перед
кареткой, так что пробел сработает и в `- текст после`, а сам текст останется
внутри пункта. Срабатывает это только в **первой строке** абзаца.

- `Tab` уводит пункт на уровень ниже, делая его вложенным в предыдущего соседа.
  У первого пункта соседа нет, поэтому ничего не происходит — внутри списка `Tab`
  не вставляет пробел.
- `Shift+Tab` выносит его следующим соседом родителя — вынесенный с верхнего
  уровня пункт становится абзацем. Если выделено несколько пунктов, они
  перемещаются все вместе.
- **Enter в пустом пункте выносит его наружу** — если пункт был на верхнем
  уровне, список на этом заканчивается, а каретка встаёт в новый абзац под ним.
  Это и есть способ завершить список.
- **Backspace в самом начале пункта сливает его с предыдущим.** Если сливать не
  с чем, пункт выносится наружу. Delete в конце пункта, наоборот, притягивает
  следующий пункт.
- Внутри пункта — блок, поэтому в нём всегда лежит один слой абзаца. Метки
  (полужирный и прочие) и другие строчные крылья работают там как везде.
- Атрибуты, которые были на теге, — например `type`, — не сохраняются. Если
  внутрь списка попадает не пункт, он не отбрасывается, а оборачивается в пункт.
- Со списком задач они делят один тег (`<ul>`), но это разные крылья — их
  различает атрибут-пометка (`data-nabi-list="task"` означает список задач).

## Вложенность — это настоящая разметка

Структура так и остаётся в сохранённом значении. Но **пункт содержит блоки, а не
текст**, поэтому текст надевает один слой абзаца, а вложенный список стоит внутри
абзаца-обёртки.

```html
<li><p>а</p><div data-nabi-p><ul><li><p>б</li></ul></div></li>
```

## Пример использования

```ts
import { createNabiWith, mountSurface, mountToolbar, bulletListWing } from 'nabi-note'
import 'nabi-note/nabi.css'

const surface = document.querySelector<HTMLElement>('#editor')!

// список крыльев вместе строит знание о видах, команды и сборщики — это и есть `registry`
const { nabi, registry } = createNabiWith([bulletListWing])

mountSurface({ nabi, registry, root: surface })
mountToolbar({ nabi, registry, surface, root: document.querySelector<HTMLElement>('#toolbar')! })

// nabi.onChange(() => user_callback(nabi.getHtml()))
```

`li` приходит сам через `parts`, поэтому вписывать его в массив не нужно.
