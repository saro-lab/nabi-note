# Список задач

## Описание

`taskListWing` (id `tl`, сочетание `K`) делит тег (`<ul>`) с маркированным
списком, но реализован отдельно — на выходе `data-nabi-list="task"` говорит,
что это список задач, а `data-nabi-checked` у каждого пункта — его состояние.

Пункт приходит вместе с ним через `parts` — это не массив, а запись.

```ts
parts: { tli: { holds: 'blocks', boolAttrs: ['ck'] } }
```

В сохранённом значении отметка — это `ck`, и единственное её значение — `1`;
выключенное состояние — не `0`, а **полное отсутствие этого поля**. В выходном
HTML это разворачивается в `data-nabi-checked="true"`/`"false"`.

По нажатию кнопки блок, в котором стоит каретка (или все блоки, задетые
выделением), оборачивается в список задач. Тот же результат даёт набранное в
начале строки `[ ] ` или `[x] ` (регистр неважен), причём от того, что именно
вы набрали, зависит, начнётся ли пункт сразу отмеченным. Строка не обязана быть
пустой, и срабатывает это только в первой строке абзаца.

Флажок — это не `<input>`, а знак, нарисованный средствами CSS: настоящий input
внутри `contenteditable` путает каретку. Включённый флажок — это белый крестик
на плашке акцентного цвета, а сама строка тускнеет и перечёркивается.

**Переключается именно эта плашка** — нужно нажать на узкую полосу перед
текстом пункта (шириной примерно в один символ); нажатие на сам текст просто
ставит туда каретку. В текстах, написанных справа налево, эта полоса стоит с
противоположной стороны. Эту работу крыло объявляет через `attach`, поэтому
**отдельно монтировать ничего не нужно.**

Отступы по `Tab`/`Shift+Tab` и завершение списка через Enter в пустом пункте
работают так же, как в [маркированном списке](./bullet-list).

## Пример использования

```ts
import { createNabiWith, mountSurface, mountToolbar, taskListWing } from 'nabi-note'
import 'nabi-note/nabi.css'

const surface = document.querySelector<HTMLElement>('#editor')!

// список крыльев вместе строит знание о видах, команды и сборщики — это и есть `registry`
const { nabi, registry } = createNabiWith([taskListWing])

mountSurface({ nabi, registry, root: surface })
mountToolbar({ nabi, registry, surface, root: document.querySelector<HTMLElement>('#toolbar')! })

// nabi.onChange(() => user_callback(nabi.getHtml()))
```
