# Таблица

## Описание

`tableWings` (id `table`, сочетание `T`) владеет структурой `table > tr > td`.

Строку (`tr`) и ячейку (`td`) отдельно не регистрируют — крыло таблицы
приводит их с собой через `parts`, поэтому, убрав таблицу, вы уберёте и строку
с ячейкой.

```ts
parts: {
  tr: { holds: 'blocks' },
  td: { holds: 'blocks', singleParagraph: true, boolAttrs: ['th'] },
}
```

Именно `singleParagraph` у ячейки бережёт сетку — <kbd>Enter</kbd> внутри
ячейки не разбивает абзац надвое, а удаление выделения, протянутого через две
ячейки, не сливает их в одну.

Нажатие кнопки не переключает состояние, а открывает сетку размеров строк и
столбцов (до 8×8); таблица выбранного размера встаёт на место каретки, а сама
каретка переезжает в первую ячейку.

Команды появляются в контекстной строке только тогда, когда каретка стоит
внутри таблицы.

| Раздел | Поле |
|---|---|
| Строки | Вставить строку выше · Вставить строку ниже · Удалить строку |
| Столбцы | Вставить столбец слева · Вставить столбец справа · Удалить столбец |
| Объединение | Объединить (один переключатель) |
| Заголовки | Сделать строку заголовком · Сделать столбец заголовком (превращаются в `<th>`) |
| Сортировка | Включить/выключить сортировку (упорядочивание на стороне читателя) |
| Удаление | Удалить таблицу |

**Объединение — это один переключатель**, а не отдельные кнопки по
направлениям. Выберите несколько ячеек и нажмите — они сольются в одну;
поставьте каретку в объединённую ячейку и нажмите ещё раз — она разделится
обратно.

**Поля, ставящего блок таблицы слева · по центру · справа, в этой строке
нет.** Место таблицы определяет не сама таблица, а обёртывающий её абзац —
этим и занимается кнопка выравнивания на панели инструментов.

::: warning Пометка сортировки и объединение
Сортировка — это **всего одна пометка**. Редактор ставит её и на объединённую
таблицу, и объединение уже стоящую пометку не снимает.

Но **читающая сторона её отклоняет** — `attachTableSort` вовсе не подключается
к таблице, где видны объединённые ячейки. Строки, слитые вместе, связаны между
собой, а перестановка сломала бы сетку. Поэтому у объединённой таблицы пометка
может стоять, но ничего не происходит.
:::

## Ширину задаёт содержимое

У таблицы нет настройки ширины. Таблица занимает **ровно столько, сколько
нужно содержимому**, а если ей не хватает места, она **прокручивается вбок**
прямо на своём месте — страницу при этом не распирает. Обёртки `<div>` тоже
нет. В сохранённое значение выходит один `<table>`, и из атрибутов на нём
остаются только выравнивание (`data-nabi-align`) и пометка сортировки.

## Перемещение и выделение

Между ячейками переходят по `Tab`/`Shift+Tab` (на краю таблицы каретка
остаётся на месте). Ячейка вмещает только строчное содержимое, поэтому Enter
не разбивает её, а **переносит строку внутри ячейки** — чтобы разбить,
пришлось бы придумать блок, которого сетка вместить не может. Стрелки ведут
каретку не по экрану, а по сетке.

Мышью можно протянуть выделение через несколько ячеек. Это выделение
перетаскиванием тоже держит крыло через `attach`, поэтому **отдельно
монтировать ничего не нужно** — `mountSurface` подключает его сама.

## Пример использования

```ts
import { createNabiWith, mountSurface, mountToolbar, mountContextToolbar, tableWings } from 'nabi-note'
import 'nabi-note/nabi.css'

const surface = document.querySelector<HTMLElement>('#editor')!

// список крыльев вместе строит знание о видах, команды и сборщики — это и есть `registry`
const { nabi, registry } = createNabiWith([...tableWings])

mountSurface({ nabi, registry, root: surface })
mountToolbar({ nabi, registry, surface, root: document.querySelector<HTMLElement>('#toolbar')! })
mountContextToolbar({ nabi, registry, surface, root: document.querySelector<HTMLElement>('#context')! })

// nabi.onChange(() => user_callback(nabi.getHtml()))
```
