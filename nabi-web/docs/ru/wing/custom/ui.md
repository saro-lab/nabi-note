# UI и действия

Есть три места, где крыло предстаёт перед человеком.

| Поле | Где |
|---|---|
| `button` · `buttons` | **панель инструментов** сверху — место, которое видно всегда |
| `context` | **контекстная панель** — место, которое появляется только для того, чего касается каретка |
| `styles` | **CSS**, который несёт это крыло |

---

## Кнопки панели инструментов

```ts
button: {
  group: 'emphasis',                   // в каком кластере стоит — обязательно
  svg: '<path d="…"/>',                // содержимое на сетке 16×16. Без него стоит как текст
  label: { ru: 'Жирный', en: 'Bold' },
  shortcut: 'B',                       // эта буква в режиме подсказок
  accelerator: 'mod+b',                // сочетание Ctrl/⌘
  action: { kind: 'mark' },
}
```

Для нескольких кнопок пишите массив в `buttons` — так одно крыло выравнивания ставит слева,
по центру и справа. Тогда `name` различает их, а `value` называет значение, которое представляет
каждая.

### `group` — порядок определяет кластер

```
font · heading · emphasis · script · color · link ·
align · list · structure · media · container · clear · file
```

**Этот порядок зафиксирован.** Куда бы вы ни поместили крыло в массиве, его кнопка встанет на
место своего кластера. Порядок регистрации выстраивает вещи только **внутри** кластера.
Используете имя не из списка — в самом конце появляется новый кластер.

Когда кластер полностью пустеет (все его кнопки скрыты), этот кластер исчезает с экрана — пустой
разделитель не остаётся.

### `action` — что происходит при нажатии

| `kind` | Что делает | Что идёт вместе с этим |
|---|---|---|
| `'mark'` | идёт к переключателю марки ядра. **Писать команду не нужно** | — |
| `'command'` | запускает одну команду | `command` · `args?` |
| `'menu'` | открывает список значений как панель | `command` · `argKey` · `values` |
| `'grid'` | открывает сетку строк×столбцов (вставка таблицы) | `command` · `rowsKey` · `colsKey` · `max?` |
| `'prompt'` | поднимает поля ввода и передаёт полученное команде | `command` · `fields` |
| `'file'` | открывает выбор файла | `accept?` · `multiple?` |
| `'host'` | передаёт хосту (`onHost` у `mountToolbar`) | — |

Не укажете `action` — и нажатие кнопки не сделает вообще ничего.

### `shortcut` и `accelerator`

| | Форма | Правило |
|---|---|---|
| `shortcut` | `'B'` | **одна заглавная латинская буква или цифра** |
| `accelerator` | `'mod+b'` | `mod+`, за которым следует **одна строчная буква** |

Оба **умирают при регистрации, если сталкиваются два крыла.** Ни одно из них не перестаёт тихо
работать потом.

Напишите отдельный `accelerated`, и нажатие акселератора сделает что-то другое — например, кнопка
открывает панель, а <kbd>Ctrl</kbd>+клавиша сразу применяет значение по умолчанию.

## Как кнопка выглядит нажатой

Есть только одно основание закрасить кнопку как «сейчас включена».

| `place` | Что читает |
|---|---|
| `'mark'` | стоит ли эта марка на каретке |
| `'attr'` | `currentValue` абзаца, в котором стоит каретка |
| `'container'`·`'void'` | находится ли каретка внутри этого куска или на нём |
| `'tool'` | **всегда выключена** |

Крыло с несколькими значениями (выравнивание, заголовки) пишет `value` на каждой кнопке, и
закрашивается только та кнопка, что совпадает с тем, что ответил `currentValue` крыла.

```ts
currentValue: (node) => {
  const h = node.a?.['h']
  return typeof h === 'number' && h >= 1 && h <= 6 ? String(h) : undefined
}
```

**`currentValue` отвечает строкой** — даже числовое значение проходит обратно через `String()`.
`undefined` означает «этот узел не несёт моего значения».

## Кнопки сами скрываются там, где не могут стоять

| `place` | Когда скрывается |
|---|---|
| `'mark'` | в месте, где живёт только текст (например, внутри коробки кода), когда оно владеет этим местом |
| `'attr'` | когда каретка на абзаце-обёртке, держащем кусок. **Выравнивание (`a`) — единственное исключение** |
| `'void'`·`'container'` | в месте, где живёт только текст, или когда `allows` текущего контейнера его не примет |
| `'tool'` | никогда не скрывается |

Выравнивание — исключение по причине, которую вы видели раньше: выравнивание куска несёт не сам
кусок, а обёртывающий его абзац. Нужно иметь возможность нажать «по центру», стоя на картинке.

Напишите `allows`, и **панель инструментов сама подстроится.** Исчезновение кнопки таблицы внутри
коробки кода — не отдельно написанное правило, оно проистекает из одного этого поля.

## Контекстная панель

Строка, которая появляется только для того, чего сейчас касается каретка. Кликните по картинке —
и появится управление размером; поставьте каретку в ссылку — появится поле адреса.

```ts
context: {
  title: { ru: 'Заметка', en: 'Note' },
  controls: [
    {
      kind: 'select',
      name: 'tone',
      label: { ru: 'Тон', en: 'Tone' },
      command: 'setNoteTone',
      argKey: 'value',
      attr: 't',                                    // атрибутный слот, откуда читать текущее значение
      values: [
        { value: 'info', label: { ru: 'Инфо' } },
        { value: 'warn', label: { ru: 'Предупреждение' } },
      ],
    },
  ],
}
```

### Когда появляется

**Всё, чего касается каретка**, открывает свою собственную строку.

- контейнеры на пути каретки (сначала самый внутренний, затем внешние)
- нацеленный кусок (например, картинка, выбранная стоя на своём абзаце-обёртке)
- **марки** на каретке — в отличие от кнопок панели инструментов, марки тоже получают контекстную
  строку
- крыло **атрибута абзаца**, чьё значение держит абзац каретки

Поставьте каретку в ссылку внутри таблицы — и строка ссылки, и строка таблицы появятся вместе.

### Семь видов `ContextControl`

| `kind` | Что | Что идёт вместе с этим |
|---|---|---|
| `'button'` | одно нажатие, одна команда | `command` · `args?` |
| `'toggle'` | два состояния, вкл и выкл | `command` · `token` |
| `'select'` | один из списка | `command` · `argKey` · `values` · `attr?` |
| `'range'` | сдвиг по шкале (изменение размера) | `command` · `argKey` · `values` · `rest?` · `readout?` |
| `'text'` | одно текстовое поле (адрес ссылки) | `command` · `argKey` · `initial?` · `placeholder?` · `validate?` |
| `'prompt'` | несколько полей как панель | `command` · `fields` |
| `'lightbox'` | просмотр крупно | `src` · `alt?` |

Все семь разделяют `name` (обязательно) · `label?` · `svg?` · `tip?` · `visible?`.

`visible: (node) => boolean` — дверь для **скрытия элемента управления внутри одного и того же
крыла** — например, показывать «разъединить» только на уже объединённых ячейках.

Напишите `attr`, и текущее значение читается прямо из этого атрибутного слота для закраски.
`'toggle'` использует `token`, чтобы сравнить со строкой, которую ответил `currentValue`.

## `styles` — CSS, который несёт крыло

```ts
styles: `
.nabi-content aside[data-nabi-note] {
  border-inline-start: 3px solid var(--nabi-accent);
  padding: .6rem .9rem;
  background: color-mix(in srgb, var(--nabi-accent) 8%, transparent);
}
`
```

Четыре правила.

- **Сужайте всё до `.nabi-content`.** Оно не должно просачиваться в остальную часть хостовой
  страницы.
- **Пишите размеры шрифта в `rem` или `em`.**
- **Различайте тёмную тему только классом `.dark`.** Сделайте это через медиа-запрос — и редактор
  один потемнеет на хосте, выбравшем светлую тему.
- **Измеряйте широту и узость контейнерным запросом.** Мерилом служит ширина места, где стоит
  редактор, а не ширина экрана.

Если нужно только то, что вы зарегистрировали, соберите и внедрите таблицы стилей сами.

```ts
import { collectSheets, injectSheets } from 'nabi-note'

const detach = injectSheets(document, collectSheets(registry))
```

Таблица стилей с одинаковым текстом загружается **один раз** — несколько крыльев могут разделять
один и тот же CSS, и в документ попадёт лишь одна копия. Ответ — функция отключения, и она
убирает **только то, что добавил именно этот вызов**.

## Вопрос к человеку

```ts
const { nabi, registry } = createNabiWith(wings, {
  ask: {
    message: (text) => window.alert(text),
    confirm: (text) => window.confirm(text),
  },
})
```

`confirm` принимает `boolean` или `Promise<boolean>` — подключите собственный `confirm` браузера
или поднимите свою панель и ответьте позже.

::: warning Не зададите — ответ всегда «нет»
Не передадите `ask` — включится тихое значение по умолчанию. `message` никуда не идёт, а
`confirm` отвечает `false`. Логика в том, что **тихая неудача спросить-и-удалить** лучше, чем
тихое срабатывание этого действия. «Точно удалить?» локальной истории проходит через эту дверь.
:::

::: tip Команды не могут спрашивать
Команда — чистая функция; она ничего не знает ни об экране, ни о времени. Спрашивайте вне
команды и вызывайте команду **после того, как ответ получен**. Внутри крыла место для этого —
`attach`, где вы дотягиваетесь через `host.nabi.$ask`.
:::
