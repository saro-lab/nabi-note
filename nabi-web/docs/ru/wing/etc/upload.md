# Загрузить файл

## Описание

Загрузка состоит из трёх частей — от одной лишь регистрации крыла не происходит ничего.

1. **`uploadWing`** — вешает на панель инструментов кнопку выбора файла. Само это крыло не
   создаёт ни `img`, ни `a` — загруженный файл фиксируется в документе тем, что рисуют
   крылья изображения и ссылки, поэтому **вместе с ним нужно зарегистрировать `imageWing`
   или `linkWing`**, иначе результат в документе не останется. Если нет ни того, ни
   другого, **исключение будет брошено прямо при регистрации** (а не позже, где-то в
   рантайме).
2. **`mountUpload({ … })`** — та сторона, которая действительно принимает файлы и
   прогоняет их через `uploader`. Сюда стекается всё — перетаскивание, вставка, выбор
   через кнопку. **Без этого монтирования кнопка будет на месте, но не произойдёт ничего.**
3. **`mountUploadView({ … })`** — ставит на экран заполнитель хода загрузки. Без него
   загрузка всё равно работает, но пока файл идёт, экран об этом ничего не говорит.

`uploader` имеет вид `(task) => Promise<{ uri } | null>` — **если вернулся адрес, это
успех, если `null` — неудача**, и заполнитель убирается. О ходе загрузки сообщайте через
`task.onProgress(0–100)`, а когда `task.signal` прерывается — останавливайте загрузку.

Ограничений три — `extensions`·`maxFileSize`·`maxTotalSize`, и все они необязательны (`0`
или отсутствие значения означает «без ограничения»). Отсеянные файлы приходят через
`onReject`.

## Что остаётся после загрузки

Изображения фиксируются блоком `imageWing`, всё остальное — ссылкой-вложением `linkWing`.

- **Вложение называется не именем файла, а локализованной подписью** — по-русски
  «Вложение». Имена файлов обычно слишком длинны, чтобы оставлять их в документе, а
  главное — имя должно быть изменяемым. Поставьте каретку в эту ссылку и поменяйте имя в
  [поле имени в контекстной строке](../inline/link).
- **Расширение остаётся пометкой** — `data-nabi-file="pdf"`. Это значение берётся из
  настоящего имени файла, и таблица стилей рисует его значком. При переименовании ссылки
  пометка сохраняется.
- Адрес, который ссылка не приняла бы (например, `blob:`, пришедший без включённого
  `allowLocalUrls`), понижается до простого имени файла — белый список никогда не
  обходится.

## Что видно во время загрузки

Пока файл загружается, на его месте стоит временный блок — он существует только в DOM
редактора и его нет в nabi-tree, поэтому в сохранённом значении от него не остаётся ни
знака.

- **Изображение** сразу показывает предпросмотр из выбранного файла, а поверх ложится
  сетка. По мере роста прогресса ячейки убираются одна за другой, и картинка становится
  чётче. Порядок, в котором убираются ячейки, у каждого файла свой — при загрузке
  нескольких файлов сразу узор не повторяется.
- **Файл, который не является изображением**, получает блок без сетки — с 📎 и подписью
  «Вложение», а расширение рядом показывается заглавным значком (`PDF` и т. п.).
  Изображения, для которых не удаётся построить предпросмотр, тоже попадают сюда.
- Прогресс несётся на блоке как `data-nabi-per`, и таблица стилей рисует его сама. Пока
  файл грузится, на блоке стоит кнопка отмены (×), а пока идёт пакет — правка заблокирована.

## Пример использования

```ts
import {
  createNabiWith,
  mountSurface,
  mountToolbar,
  mountUpload,
  mountUploadView,
  imageWing,
  linkWing,
  uploadWing,
} from 'nabi-note'
import 'nabi-note/nabi.css'

const surface = document.querySelector<HTMLElement>('#editor')!

// без крыла изображения или ссылки загрузка не может оставить результат — тут же исключение
const { nabi, registry } = createNabiWith([imageWing, linkWing, uploadWing])

mountSurface({ nabi, registry, root: surface })

// сторона, которая ставит заполнитель хода загрузки — создаём заранее и передаём ниже
const view = mountUploadView({ nabi, surface, locale: 'ru' })

const upload = mountUpload({
  nabi,
  root: surface,
  locale: 'ru',
  extensions: ['jpg', 'jpeg', 'png', 'gif', 'webp', 'pdf'],
  maxFileSize: 10 * 1024 * 1024,
  uploader: async (task) => {
    // здесь настоящий код загрузки на сервер. адрес — успех, null — неудача
    // const uri = await user_callback(task.file, task.onProgress, task.signal)
    // return { uri }
    return null
  },
  onStart: (tasks) => view.start(tasks),
  onProgress: (id, percent) => view.progress(id, percent),
  onSettle: () => view.settle(),
  onDone: () => view.done(),
})

mountToolbar({
  nabi, registry, surface,
  root: document.querySelector<HTMLElement>('#toolbar')!,
  // сюда попадают файлы, выбранные кнопкой на панели инструментов
  onFiles: (files) => upload.take(files),
})
```

## Демо

На этом сайте нет сервера для загрузки, поэтому он только делает вид: возвращает адрес
`blob:`, созданный через `URL.createObjectURL()`. Результат остаётся только внутри этой
страницы.
