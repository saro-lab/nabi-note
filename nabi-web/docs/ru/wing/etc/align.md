# Выравнивание

Выравнивает текущий абзац и абзацы в выделенном диапазоне по левому краю, по центру или по правому краю. Объекты внутри абзаца, например изображения, видео и таблицы, также выравниваются по абзацу, который их содержит.

Выравнивание сохраняется как свойство абзаца, а не как форматирование символов. Блоки кода исключены из выравнивания, поскольку их отступ имеет собственный смысл.

В ячейке выравнивается внутренний абзац или изображение в позиции курсора. При выделении нескольких ячеек перетаскиванием выравнивание применяется ко всем подходящим абзацам и изображениям внутри них. Если выделение содержит разное выравнивание, ни одна кнопка выравнивания не отмечается как выбранная.

Чтобы выровнять саму таблицу, нажмите **Выбрать таблицу** в ее контекстных инструментах или поставьте курсор перед таблицей либо после нее в содержащем ее абзаце, затем используйте кнопки выравнивания основной панели. Положение плавающей области слева или справа меняется в ее контекстных инструментах, а не кнопками выравнивания.

Для применения команды к текущему выделению используйте `l` для выравнивания влево, `c` — по центру и `r` — вправо.

```ts
nabi.applyCommand('setAlign', { value: 'c' })
```
