# Выравнивание

## Описание

`alignWing` (id `align`) — это **единственное** крыло, которое держит все три
значения — слева, по центру, справа. На панели инструментов это константа — не
фабрика `align()`, объединяющая всё в одно, а у каждого значения своя кнопка.
Крыло ставит на блок атрибут `data-nabi-align`.

- Это **атрибут блока**: тег остаётся нетронутым, добавляется только атрибут —
  как в `<p data-nabi-align="center">`, где сам абзац не меняется.
- **Работает на абзацах и заголовках.** `<h2 data-nabi-align="c">` тоже
  допустим — заголовок такая же строка текста, как любая другая. Из четырёх
  атрибутов абзаца до заголовков дотягивается только выравнивание; размер
  текста, гарнитура и буквица остаются доступны лишь абзацам.
- Значение всегда одно: нажмите «по центру» на абзаце с выравниванием по левому
  краю — левое значение отпадёт, а центральное встанет. Нажмите уже стоящее
  значение — атрибут снимется целиком (возврат к выравниванию по умолчанию).
- **Enter передаёт выравнивание в обе стороны без изменений.** Разделите абзац
  — и оба получившихся абзаца выйдут с одним и тем же выравниванием: в отличие
  от заголовка (`h`), который отпадает у пустой стороны, и буквицы (`dc`),
  которая следует только за одной стороной, у выравнивания таких исключений
  нет.
- Все три значения — это **три кнопки** одного крыла (`buttons`) — по
  отдельности их включать и выключать нельзя, в массив wings кладут только
  сам `alignWing`.
- **Место таблицы, изображения и видео YouTube определяет тоже это крыло.**
  Такой объект живёт внутри своей абзаца-обёртки, и выравнивание несёт именно
  этот абзац — поэтому «картинка по центру» и означает «картинка внутри абзаца
  по центру». Вот почему в контекстной строке картинки или таблицы вообще нет
  поля выравнивания, и только оно одно не пропадает с панели инструментов,
  даже когда каретка стоит на самом объекте.

## Пример использования

```ts
import { createNabiWith, mountSurface, mountToolbar, alignWing } from 'nabi-note'
import 'nabi-note/nabi.css'

const surface = document.querySelector<HTMLElement>('#editor')!

// список крыльев вместе строит знание о видах, команды и сборщики — это и есть `registry`
const { nabi, registry } = createNabiWith([alignWing])

mountSurface({ nabi, registry, root: surface })
mountToolbar({ nabi, registry, surface, root: document.querySelector<HTMLElement>('#toolbar')! })

// nabi.onChange(() => user_callback(nabi.getHtml()))
```
