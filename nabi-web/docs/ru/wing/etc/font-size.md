# Размер шрифта

## Описание

`fontSizeWing` (имя `fs`) — это **инлайновая значимая марка**. Это форматирование, наложенное на
текст, а не атрибут абзаца. На выходе рисуется как `<span data-nabi-size="lg">`.

Значений четыре — `xs`, `sm`, `lg`, `xl`, — а размер по умолчанию не является пятым значением, это
**отсутствие атрибута**.

- Она парна со шрифтом (`tf`) — одно крыло держит все значения, и место выбора — контекстная
  панель. Но шрифт раскладывает четыре поля, а размер использует одну шкалу.
- **Элемент управления в контексте — шкала (`range`).** Размер — упорядоченное значение (маленький
  → большой), поэтому вместо раскладки полей даётся один ползунок. Действующее значение
  показывается положением ползунка, а его имя идёт рядом на подписи.
- **Первый слот шкалы — «По умолчанию»** — первый, а не средний, потому что список идёт от
  маленького к большому, и место перед ним — там, где принадлежит «ничего не применено». Сдвиньте
  ползунок туда, и это не запишет какое-то значение `base` — это **снимет марку**.
- **Подписи полей учитывают локаль** — по-русски это «По умолчанию · Очень маленький · Маленький ·
  Крупный · Очень крупный».
- Нажмите кнопку панели инструментов — и получите **`lg` (крупный)**. Шкала идёт от маленького к
  большому, поэтому, если оставить как есть, применился бы первый слот, `xs`, — а никто не нажимает
  кнопку размера, желая, чтобы текст стал мельче.
- **С одной лишь кареткой применяется ко всему абзацу.** Редко нужно изменить размер одного слова,
  поэтому без выделенного диапазона цель — абзац (маркер и цвет текста, напротив, нацелены на
  прогон марки, в котором вы стоите).
- Нажмите в абзаце, где вообще нет текста, и это остаётся **заряженным** — следующий набранный
  символ выйдет этого размера.
- Примените то же значение снова — и оно снимется.

## Пример использования

```ts
import { createNabiWith, mountSurface, mountToolbar, mountContextToolbar, fontSizeWing } from 'nabi-note'
import 'nabi-note/nabi.css'

const surface = document.querySelector<HTMLElement>('#editor')!

// Список крыльев строит вместе знание о видах, команды и сборщики — это и есть `registry`
const { nabi, registry } = createNabiWith([fontSizeWing])

mountSurface({ nabi, registry, root: surface })
mountToolbar({ nabi, registry, surface, root: document.querySelector<HTMLElement>('#toolbar')! })
mountContextToolbar({ nabi, registry, surface, root: document.querySelector<HTMLElement>('#context')! })

// nabi.onChange(() => user_callback(nabi.getHtml()))
```
