# Очистить форматирование

## Описание

`clearFormatWing` — это **готовая константа**. Просто добавьте её в массив — передавать опции не
нужно.

Поскольку у неё `place: 'tool'`, она не ставит в документ собственного узла. Всё, что есть, — одна
команда (`clearFormat`) и одна кнопка панели инструментов.

- **Список того, что снимается, зашит в ядре.** Одиннадцать инлайновых марок (`b`, `i`, `u`, `s`,
  `sub`, `sup`, `hl`, `tc`, `fs`, `tf`, `a`) и три атрибута абзаца (`h` заголовок, `a`
  выравнивание, `dc` буквица). Хосту не нужно вести никакой список, а марки крыльев, написанных
  вами самостоятельно, **здесь не снимаются**.
- **Выделите диапазон и нажмите** — и марки на этом отрезке вместе с атрибутами каждого абзаца, до
  которого он дотягивается, снимаются разом.
- **С одной лишь кареткой снимается по одному слою за раз** — начиная с **самой внутренней марки**
  на каретке, на протяжении того отрезка, где эта марка действует. Когда снимать марки больше
  нечего, тогда снимаются атрибуты абзаца.
- **Ссылки-вложения никогда не снимаются** — ссылка (`a`) с атрибутом `file` неприкосновенна
  везде, потому что снятие оболочки превратило бы вложение в мёртвую строку обычного текста.
- **Выравнивание сохраняется на абзаце, держащем кусок.** На абзаце-обёртке вокруг изображения или
  таблицы одно только выравнивание (`a`) не снимается — очистка форматирования не должна отправлять
  картинку обратно влево.
- Когда снимать нечего, команда отвечает `null`, так что точка отмены не накапливается.

## <kbd>Esc</kbd> дважды

Помимо кнопки на панели есть **ещё одна дорога через клавиатуру** — дважды подряд нажать
<kbd>Esc</kbd>. Ни однобуквенная подсказка, ни акселератор `⌘` не смогли нести этот жест, поэтому
он пошёл в объявление двойного нажатия (`doubleKeys`).

- **Делает ровно то же, что и нажатие кнопки.** С выделенным диапазоном — этот отрезок; **с одной
  лишь кареткой** — один слой на этом месте: команда уже знает, что снимать, поэтому клавиатурная
  сторона не разветвляется по состоянию каретки.
- **Срабатывает ровно на втором нажатии.** Четыре нажатия — всё равно одно срабатывание, а если
  между двумя нажатиями пройдёт больше 350 мс, счёт начинается заново. Повторы от удержания клавиши
  (`repeat`) и нажатия во время ввода через IME не считаются.
- **Приоритет самый низкий.** Клавиша принимается только после того, как пройдут все остальные
  дела, что <kbd>Esc</kbd> делал (снятие резерва, выход из марки) — нажмите <kbd>Esc</kbd> посреди
  подсветки, и первое нажатие ставит резерв выхода из марки, а второе всё равно доходит до очистки
  форматирования.
- **Есть только пять мест, где это не работает** — открытая панель, оверлей, полноэкранный режим,
  значки подсказок и блокировка загрузки.
- Об этом говорит подсказка кнопки — **«Очистить форматирование (Esc Esc)»**, тот же рисунок, что
  и у значков Shift.

## Пример использования

```ts
import { createNabiWith, mountSurface, mountToolbar, clearFormatWing } from 'nabi-note'
import 'nabi-note/nabi.css'

const surface = document.querySelector<HTMLElement>('#editor')!

// Список крыльев строит вместе знание о видах, команды и сборщики — это и есть `registry`
const { nabi, registry } = createNabiWith([clearFormatWing])

mountSurface({ nabi, registry, root: surface })
mountToolbar({ nabi, registry, surface, root: document.querySelector<HTMLElement>('#toolbar')! })

// nabi.onChange(() => user_callback(nabi.getHtml()))
```
