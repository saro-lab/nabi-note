# قائمة نقطية

## الوصف

`bulletListWing` (اسمه `ul`، اختصاره `L`) يملك `<ul>`. يُجلَب العنصر عبر
`parts` فلا يُسجَّل `li` على حدة — وهو سجل لا مصفوفة.

```ts
parts: { li: { holds: 'blocks' } }
```

الضغط على الزر يلفّ الكتلة التي يقف فيها المؤشر (أو الكتل التي يشملها
التحديد) بقائمة، والضغط ثانية يفكّها فتعود فقرات. الضغط على زر قائمة أخرى
يبدّل الصنف.

كتابة شرطة ومسافة في أول السطر (`- `) تعطي النتيجة نفسها. **لا حاجة لأن يكون
السطر فارغًا** — المقاس هو أول السطر قبل المؤشر فقط، فكتابة `- ثم نص` تُفعِّل
التحويل ويبقى النص بعدها داخل العنصر. لكنه يعمل فقط في **أول سطر** من الفقرة.

- `Tab` يُزيح العنصر درجة داخل الشقيق الذي فوقه مباشرة. العنصر الأول لا مكان
  له فلا يحدث شيء — `Tab` داخل القائمة لا يُدرج مسافة.
- `Shift+Tab` يُخرجه ليصير الشقيق التالي للأب — والإخراج من المستوى الأعلى
  يحوّله فقرة. إن كان التحديد يمتد على عناصر عدة تحرّكت كلها معًا.
- **الضغط على Enter في عنصر فارغ إخراج.** إن كان في المستوى الأعلى انتهت
  القائمة هناك ووقف المؤشر في فقرة جديدة أسفلها. هذا هو طريق إنهاء القائمة.
- **الضغط على Backspace في أول العنصر يدمجه بالعنصر السابق.** إن لم يوجد
  عنصر سابق سقط إلى إخراج. Delete في آخر العنصر يجذب العنصر التالي بالعكس.
- جوف العنصر كتلة، فتدخل فيه فقرة واحدة. العلامات (كالعريض) والأجنحة السطرية
  الأخرى تُستعمل داخل تلك الفقرة كما هي.
- السمات التي كان الوسم يحملها مثل `type` لا تنجو. ما ليس عنصرًا إن دخل
  القائمة لا يُطرَح، بل يُلَفّ في عنصر واحد.
- تتقاسم الوسم (`<ul>`) مع قائمة المهام لكنهما جناحان مختلفان — تفرّق بينهما
  سمة العلامة (فوجود `data-nabi-list="task"` يعني قائمة مهام).

## التعشيش ترميز حقيقي

يبقى الهيكل في القيمة المحفوظة كما هو. لكن بما أن **العنصر يحمل كتلًا لا
نصًّا**، يُلبَس النص فقرة واحدة وتقف القائمة المتعشِّشة داخل فقرة حاضنة.

```html
<li><p>أ</p><div data-nabi-p><ul><li><p>ب</p></li></ul></div></li>
```

## مثال الاستخدام

```ts
import { createNabiWith, mountSurface, mountToolbar, bulletListWing } from 'nabi-note'
import 'nabi-note/nabi.css'

const surface = document.querySelector<HTMLElement>('#editor')!

// قائمة الأجنحة تبني معًا معرفة الأصناف والأوامر والمُجمِّع — وهذا هو `registry`
const { nabi, registry } = createNabiWith([bulletListWing])

mountSurface({ nabi, registry, root: surface })
mountToolbar({ nabi, registry, surface, root: document.querySelector<HTMLElement>('#toolbar')! })

// nabi.onChange(() => user_callback(nabi.getHtml()))
```

`li` يتبع تلقائيًّا عبر `parts`، فلا يُوضَع في المصفوفة مباشرة.
