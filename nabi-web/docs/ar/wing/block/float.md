# المنطقة العائمة

ضع وصفًا قصيرًا أو صورة أو جدولًا صغيرًا على اليسار أو اليمين، ودع المتن ينساب بجانبه. يمكنك تعديل محتوى المنطقة مباشرة داخل المحرر نفسه. يظهر الإطار المتقطع أثناء التحرير فقط، ولا يبقى في المعاينة والعرض المنشور سوى المحتوى والتخطيط.

ضع المؤشر داخل المنطقة في المثال أدناه، واستخدم أدوات الخصائص لتغيير الجانب والحد الأقصى للعرض. في المعاينة، يمكنك رؤية انسياب المتن من دون الإطار المتقطع.

<WingDemo path="/wing/block/float" />

```ts
const selected = wings().allBasic().build()
```

المناطق العائمة ضمن الأجنحة الأساسية. إذا كنت تجمع الأجنحة المطلوبة فقط، فاستخدم `wings().use('float')` أو سجّل `floatWing` مباشرة. سجّل أيضًا أجنحة الصور والجداول والقوائم وأي محتوى آخر سيُستخدم داخل المنطقة.

## الإنشاء والتموضع

ضع المؤشر في المتن واضغط **منطقة عائمة** لإنشاء منطقة فارغة. الإعداد الافتراضي هو الجانب الأيمن بعرض أقصى قدره 40%. إذا حددت عدة فقرات قبل الضغط، تُغلّف جميع الفقرات التي يمسّها التحديد بالكامل في منطقة واحدة. لا يمكنك تغليف منطقة عائمة موجودة مرة أخرى أو إنشاء منطقة عائمة أخرى داخلها.

```ts
nabi.applyCommand('insertFloat', { side: 'right', w: 40 })
```

عندما يكون المؤشر داخل المنطقة، غيّر الجانب إلى اليسار أو اليمين والحد الأقصى للعرض باستخدام أدوات الخصائص. اختر 20% أو 30% أو 40% أو 50%. تُحسب النسبة من عرض المتن، لا من الشاشة كاملة؛ وإذا كان المحتوى قصيرًا فقد تكون المنطقة الفعلية أضيق.

```ts
nabi.applyCommand('setFloatSide', { side: 'left' })
nabi.applyCommand('setFloatWidth', { w: 30 })
```

يبقى لصق النص والصور والجداول وتحويل الكتل والرفع داخل المنطقة. عند حذف جدول داخلي، يختفي ذلك الجدول وحده. لا يتاح إدراج الكتل الداخلية أو تحويلها عندما يشمل التحديد داخل المنطقة وخارجها معًا.

يعيد زر **إلغاء المنطقة العائمة** بجانب قيمة العرض المحتوى إلى المتن من دون حذفه. يدعم الإنشاء وتغيير التخطيط وإزالة الغلاف جميعها التراجع والإعادة.

```ts
nabi.applyCommand('unwrapFloat')
```

## كيفية انسياب المتن بجانب المنطقة

تنساب الفقرات التالية بجانب المنطقة، ثم تعود إلى عرض المتن بالكامل عند نهايتها. يبدأ العنوان أو الجدول أو كتلة الشيفرة أو الفاصل أو المنطقة العائمة الجديدة التالية أسفل المنطقة السابقة.

إذا كان عرض المتن أقل من `36rem`، تُرتَّب المنطقة والمتن في عمود واحد. تستخدم الطباعة عمودًا واحدًا أيضًا، مع الاحتفاظ بالجانب والحد الأقصى للعرض المحفوظين. يحافظ عرض مقارنة المستندات على جانب كل منطقة وحد عرضها الأقصى، لكنه يعرض الكتلة التالية منفصلة أسفلها لتسهيل قراءة التغييرات.

## الحفظ والتحميل

يحفظ JSON الخاصيتين `a.side` و`a.w` للعقدة `float` مع الكتل الداخلية. ويستخدم HTML السمتين `data-nabi-float` و`data-nabi-float-width` على عنصر `div` داخل فقرة كائن عادية.

```html
<div data-nabi-p>
  <div data-nabi-float="right" data-nabi-float-width="40">
    <p>وصف يوضع بجانب المتن.</p>
  </div>
</div>
<p>تستمر هذه الفقرة بجانب المنطقة.</p>
```

يحافظ التصدير إلى Markdown على المنطقة بصيغة HTML. لا تُستورد أنماط CSS `float` الاعتباطية، لذا استخدم JSON أو HTML أنشأه NABI NOTE للحفظ والاستعادة. اربط الأجنحة وCSS نفسها في المحرر وSSR والمعاينة والعرض المنشور للحفاظ على الجانب والعرض.

## أنماط CSS

يمكنك تنسيق الألوان والمسافات داخل المنطقة باستخدام المحدد `[data-nabi-float]`. تدير الفقرة الخارجية التموضع والحد الأقصى للعرض، لذا لا تتجاوز `float` أو `display` أو العرض مباشرة.

```css
.brand-note .nabi-content [data-nabi-float] {
  background: var(--nabi-soft);
  border-radius: var(--nabi-radius);
  padding: .75rem;
}
```
