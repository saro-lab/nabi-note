# جدول

## الوصف

`tableWings` (الاسم `table`، الاختصار `T`) يملك البنية `table > tr > td`.

الصف (`tr`) والخلية (`td`) لا يُسجَّلان على حدة — يجرّهما جناح الجدول معه عبر
`parts`، فإن أُقصي الجدول أُقصيا معه.

```ts
parts: {
  tr: { holds: 'blocks' },
  td: { holds: 'blocks', singleParagraph: true, boolAttrs: ['th'] },
}
```

كون الخلية `singleParagraph` هو ما يحفظ الشبكة — الضغط على <kbd>Enter</kbd> داخل
خلية لا يشطر الفقرة إلى اثنتين، وحذف تحديد يمتد عبر خليتين لا يدمجهما معًا.

الضغط على الزر ليس تبديلًا، بل يُظهر شبكةً لاختيار المقاس صفوفًا × أعمدة (حتى 8×8)،
فيُدرَج جدول بالمقاس المختار في موضع المؤشر وينتقل المؤشر إلى أول خلية.

ولا تظهر الأوامر في الشريط السياقي إلا والمؤشر داخل الجدول.

| الفئة | الحقول |
|---|---|
| الصف | إدراج صف أعلى · إدراج صف أسفل · حذف الصف |
| العمود | إدراج عمود على اليسار · إدراج عمود على اليمين · حذف العمود |
| الدمج | الدمج (زر تبديل واحد) |
| الرأس | جعل هذا الصف رأسًا · جعل هذا العمود رأسًا (يتحوّلان إلى `<th>`) |
| الفرز | تشغيل الفرز أو إطفاؤه (يرتّب الأعمدة من جهة القارئ) |
| الحذف | حذف الجدول |

**الدمج زر تبديل واحد** — لا أزرار باتجاهات مختلفة. اختر عدة خلايا واضغطه فتندمج
واحدة، وضع المؤشر في خلية مدموجة واضغطه مجددًا فتنفصل.

**لا حقل هنا لوضع صندوق الجدول يسارًا أو وسطًا أو يمينًا.** موضع الجدول ليست
مسؤولية الجدول نفسه بل الفقرة الحاضنة له، فزر المحاذاة في شريط الأدوات هو من
يتولى ذلك.

::: warning علامة الفرز والدمج
الفرز **علامة واحدة فقط.** يضع المحرر هذه العلامة حتى على جدول مدموج، ولا تُنزَع
العلامة الموضوعة عند الدمج أيضًا.

لكن **جانب القراءة هو من يرفض** — لا يلتصق `attachTableSort` أصلًا بجدول تظهر فيه
خلايا مدموجة. فالصفوف المندمجة مترابطة، وإعادة ترتيبها تكسر الشبكة. لذلك في
الجدول المدموج لا يحدث شيء رغم وجود العلامة.
:::

## المحتوى هو الذي يحدّد العرض

لا إعداد للعرض في الجدول. فالجدول لا يتّسع إلا **بمقدار محتواه**، وإذا تجاوز
موضعه **انزلق أفقيًّا** في مكانه — فلا تُدفَع الصفحة. ولا يوجد `<div>` يلفّه.
والذي يخرج في القيمة المحفوظة هو `<table>` وحده، ولا يلتصق به إلا سمة المحاذاة
(`data-nabi-align`) وعلامة الفرز.

## التنقّل والتحديد

تتنقّل بين الخلايا بـ`Tab` و`Shift+Tab` (وعند طرف الجدول يبقى المؤشر مكانه).
والخلية لا تحوي إلا محتوى سطريًّا، فـEnter لا يشطرها بل **ينتقل سطرًا داخلها** —
لأن شطرها يستلزم توليد كتلة لا تستطيع الشبكة أن تحويها. وتتحرك مفاتيح الأسهم
بحسب الشبكة لا بحسب الشاشة.

ويمكنك السحب بالفأرة عبر عدة خلايا لتحديدها. وتحديد السحب هذا أيضًا يحمله الجناح
عبر `attach` **فلا حاجة لتركيب أي شيء على حدة** — يُلصِقه `mountSurface` معًا.

## مثال الاستخدام

```ts
import { createNabiWith, mountSurface, mountToolbar, mountContextToolbar, tableWings } from 'nabi-note'
import 'nabi-note/nabi.css'

const surface = document.querySelector<HTMLElement>('#editor')!

// قائمة الأجنحة تبني معًا معرفة الأصناف والأوامر والمُجمِّع — وذلك هو `registry`
const { nabi, registry } = createNabiWith([...tableWings])

mountSurface({ nabi, registry, root: surface })
mountToolbar({ nabi, registry, surface, root: document.querySelector<HTMLElement>('#toolbar')! })
mountContextToolbar({ nabi, registry, surface, root: document.querySelector<HTMLElement>('#context')! })

// nabi.onChange(() => user_callback(nabi.getHtml()))
```
