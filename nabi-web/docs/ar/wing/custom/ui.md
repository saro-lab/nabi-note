# الواجهة والسلوك

الأماكن التي يقف فيها الجناح أمام المستخدم ثلاثة.

| الخانة | أين |
|---|---|
| `button` · `buttons` | **شريط الأدوات** العلوي — مكان ظاهر دائمًا |
| `context` | **الشريط السياقي** — يظهر فقط لما يلمسه المؤشر الآن |
| `styles` | **CSS** الذي يحمله هذا الجناح |

---

## زر شريط الأدوات

```ts
button: {
  group: 'emphasis',                   // إلى أي مجموعة ينتمي — إلزامي
  svg: '<path d="…"/>',                // محتوى بإحداثيات 16×16. بدونه يقف الزر بحرف
  label: { ar: 'عريض' },
  shortcut: 'B',                       // الحرف الذي يظهر في وضع التلميح
  accelerator: 'mod+b',                // تركيبة Ctrl/⌘
  action: { kind: 'mark' },
}
```

إن كان للجناح أكثر من زر تُكتب في `buttons` كمصفوفة — كجناح المحاذاة الذي يقيم
ثلاثة أزرار: يسار ووسط ويمين. في هذه الحالة يُميَّز كل زر بـ`name` وتُكتب القيمة
التي يمثلها في `value`.

### `group` — الترتيب تحدده المجموعة

```
font · heading · emphasis · script · color · link ·
align · list · structure · media · container · clear · file
```

**هذا الترتيب مثبَّت.** أينما وُضع الجناح في المصفوفة يقف زره في مكان مجموعته.
داخل المجموعة الواحدة تصطف الأزرار بترتيب التسجيل فقط. اسم غير موجود في القائمة
يقيم مجموعة جديدة في آخر الصف.

حين تفرغ مجموعة كاملة (اختفت كل أزرارها) تختفي تلك المجموعة من الشاشة — لا يبقى
فاصل فارغ.

### `action` — ماذا يحدث عند الضغط

| `kind` | ماذا يفعل | يُكتب معه |
|---|---|---|
| `'mark'` | يذهب إلى تبديل العلامة في النواة مباشرة. **لا حاجة لأمر** | — |
| `'command'` | يشغّل أمرًا واحدًا | `command` · `args?` |
| `'menu'` | يفتح قائمة قيم كلوحة | `command` · `argKey` · `values` |
| `'grid'` | يفتح شبكة صفوف×أعمدة (إدراج جدول) | `command` · `rowsKey` · `colsKey` · `max?` |
| `'prompt'` | يعرض خانة إدخال ويمرر القيمة إلى الأمر | `command` · `fields` |
| `'file'` | يفتح نافذة اختيار ملف | `accept?` · `multiple?` |
| `'host'` | يُسلَّم إلى المضيف (`onHost` في `mountToolbar`) | — |

بدون `action` لا يفعل الضغط على الزر شيئًا.

### `shortcut` و`accelerator`

| | الشكل | القاعدة |
|---|---|---|
| `shortcut` | `'B'` | **حرف لاتيني كبير أو رقم واحد** |
| `accelerator` | `'mod+b'` | حرف صغير واحد بعد `mod+` |

كلاهما **يموت تسجيله إن تعارض مع جناح آخر.** لا يحدث لاحقًا أن يتوقف أحد الطرفين
عن العمل بصمت.

إن كُتب `accelerated` منفصلًا يعمل سلوك مختلف فقط عند الضغط بمفتاح التسريع —
كأن يفتح الزر لوحة عند النقر، بينما يطبّق <kbd>Ctrl</kbd>+المفتاح القيمة
الافتراضية مباشرة.

## كيف يبدو الزر "مضغوطًا"

السبب الذي يُلوَّن به الزر على أنه "مفعَّل الآن" واحد فقط.

| `place` | ما الذي يُنظَر إليه |
|---|---|
| `'mark'` | هل هذه العلامة موجودة في مكان المؤشر |
| `'attr'` | `currentValue` للفقرة التي يقف عليها المؤشر |
| `'container'`·`'void'` | هل المؤشر داخل ذلك الجسم أو عليه |
| `'tool'` | **مطفأ دائمًا** |

الجناح ذو القيم المتعددة (المحاذاة والعنوان) يكتب `value` لكل زر، ويُلوَّن فقط
الزر الذي تطابق قيمته ما يجيب به `currentValue` للجناح.

```ts
currentValue: (node) => {
  const h = node.a?.['h']
  return typeof h === 'number' && h >= 1 && h <= 6 ? String(h) : undefined
}
```

**يجيب `currentValue` بنص دائمًا** — حتى القيمة الرقمية تُحوَّل بـ`String()`
قبل الإجابة. و`undefined` تعني "لا قيمة لي في هذه العقدة".

---

## الأزرار تختفي تلقائيًّا من حيث لا يجوز أن تقف

| `place` | متى يختفي |
|---|---|
| `'mark'` | في مكان لا يعيش فيه إلا نص عادي (كصندوق الكود) حين يكون هو صاحب ذلك المكان |
| `'attr'` | حين يكون المؤشر على فقرة حاضنة تحمل جسمًا. **المحاذاة (`a`) وحدها استثناء** |
| `'void'`·`'container'` | في مكان لا يعيش فيه إلا نص عادي، أو حين لا تقبله `allows` الخاصة بالوعاء الحالي |
| `'tool'` | لا يختفي |

سبب استثناء المحاذاة كما رأينا سابقًا — محاذاة الجسم لا يحملها الجسم نفسه بل
الفقرة الحاضنة له. يجب أن يمكن الضغط على "توسيط" فوق صورة.

كتابة `allows` تجعل **شريط الأدوات يتبعها تلقائيًّا.** اختفاء زر الجدول داخل
صندوق الكود ليس قاعدة مكتوبة على حدة، بل نتيجة `allows` وحدها.

## الشريط السياقي

شريط يظهر فقط لما يلمسه المؤشر الآن. المكان الذي يظهر فيه ضبط الحجم عند الضغط
على صورة، وخانة العنوان عند وضع المؤشر على رابط.

```ts
context: {
  title: { ar: 'ملاحظة' },
  controls: [
    {
      kind: 'select',
      name: 'tone',
      label: { ar: 'النبرة' },
      command: 'setNoteTone',
      argKey: 'value',
      attr: 't',                                    // الخاصية التي تُقرَأ منها القيمة الحالية
      values: [
        { value: 'info', label: { ar: 'معلومة' } },
        { value: 'warn', label: { ar: 'تنبيه' } },
      ],
    },
  ],
}
```

### متى يظهر

**كل ما يلمسه** المؤشر في مكانه يفتح شريطه الخاص.

- الأوعية الواقعة على طريق المؤشر (الأقرب أولًا، الأبعد أخيرًا)
- الجسم المستهدَف (كصورة محددة فوق فقرة حاضنة)
- **العلامات** الملتصقة بمكان المؤشر — خلافًا لأزرار شريط الأدوات، للعلامات
  أيضًا شريطها السياقي
- جناح **خاصية الفقرة** التي تحمل الفقرة التي يقف عليها المؤشر قيمة لها

وضع المؤشر على رابط داخل جدول يفتح شريط الرابط وشريط الجدول معًا.

### `ContextControl` سبعة أصناف

| `kind` | ماذا | يُكتب معه |
|---|---|---|
| `'button'` | ضغطة واحدة تشغّل أمرًا | `command` · `args?` |
| `'toggle'` | حالتان: مفعَّل ومطفأ | `command` · `token` |
| `'select'` | اختيار واحد من قائمة | `command` · `argKey` · `values` · `attr?` |
| `'range'` | تحريك مؤشر (ضبط الحجم) | `command` · `argKey` · `values` · `rest?` · `readout?` |
| `'text'` | خانة نص واحدة (عنوان رابط) | `command` · `argKey` · `initial?` · `placeholder?` · `validate?` |
| `'prompt'` | عدة خانات في لوحة | `command` · `fields` |
| `'lightbox'` | عرض مكبَّر | `src` · `alt?` |

تشترك الأصناف السبعة في `name`(إلزامي) و`label?` و`svg?` و`tip?` و`visible?`.

`visible: (node) => boolean` باب **لإخفاء خانة داخل الجناح نفسه** — كإظهار
"فك الدمج" فقط في الخلايا المدموجة بالفعل.

كتابة `attr` تقرأ القيمة الحالية مباشرة من تلك الخاصية وتلوّن بها. أما
`'toggle'` فيقارن بـ`token` النص الذي يجيب به `currentValue`.

## `styles` — الـCSS الذي يحمله الجناح

```ts
styles: `
.nabi-content aside[data-nabi-note] {
  border-inline-start: 3px solid var(--nabi-accent);
  padding: .6rem .9rem;
  background: color-mix(in srgb, var(--nabi-accent) 8%, transparent);
}
`
```

أربع قواعد.

- **يُحصَر تحت `.nabi-content`.** يجب ألا يمتد إلى نص آخر في صفحة المضيف.
- **حجم الخط بـ`rem` أو `em`.**
- **الوضع المظلم بصنف `.dark` فقط.** الحصر بميديا كويري يُظلم المحرر وحده حتى
  في شاشة مضيء أضاءها المضيف.
- **العرض والضيق بـcontainer query.** المعيار عرض المكان الذي يقف فيه المحرر، لا
  عرض الشاشة.

من أراد تحميل ما هو مسجَّل فقط يجمعها بنفسه ويُلصقها.

```ts
import { collectSheets, injectSheets } from 'nabi-note'

const detach = injectSheets(document, collectSheets(registry))
```

تُحمَّل أنماط النص الواحد **مرة واحدة فقط** — حتى لو حمل عدة أجنحة نفس الـCSS
لا يُلصَق في المستند إلا نسخة واحدة. القيمة المُعادة دالة نزع، و**هذا الاستدعاء
تحديدًا** ينزع فقط ما ألصقه هو.

## سؤال المستخدم

```ts
const { nabi, registry } = createNabiWith(wings, {
  ask: {
    message: (text) => window.alert(text),
    confirm: (text) => window.confirm(text),
  },
})
```

يقبل `confirm` إما `boolean` أو `Promise<boolean>` — يمكن توصيل `confirm` من
المتصفح مباشرة، أو بناء لوحة خاصة وإرجاع الإجابة لاحقًا.

::: warning بدون توصيله الإجابة دائمًا "لا"
بدون توصيل `ask` يُستخدم افتراضي صامت. لا يذهب `message` إلى أي مكان ويجيب
`confirm` بـ`false`. الاختيار هنا أن **عدم حدوث السؤال والحذف بصمت** أفضل من أن
**يحدث الحذف بصمت من دون سؤال.** رسالة "هل تريد الحذف فعلًا؟" في السجل المحلي
تمر من هذا الباب.
:::

::: tip الأوامر لا تستطيع السؤال
الأمر دالة نقية لا تعرف الشاشة ولا الزمن. ما يحتاج سؤالًا يُسأل خارج الأمر
وتُستدعى **بعد ظهور الإجابة.** المكان المتاح لذلك داخل الجناح هو `attach`، ومنه
يُصَل إلى `host.nabi.$ask`.
:::
