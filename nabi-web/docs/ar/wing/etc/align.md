# المحاذاة

## الوصف

جناح **واحد** هو `alignWing` (المعرّف `align`) يحمل الثلاثة: يسار ووسط ويمين
معًا. وهو **ثابت** في شريط الأدوات — ليس مصنعًا واحدًا اسمه `align()` يجمعها،
بل لكل قيمة زرها الخاص. يُلصِق بالكتلة السمة `data-nabi-align`.

- إنها **سمة كتلة** تُضاف دون مساس بالوسم. فالفقرة نفسها لا تتغيّر، كما في
  `<p data-nabi-align="center">`.
- **وتُطبَّق على الفقرات والعناوين.** فـ`<h2 data-nabi-align="c">` جائز أيضًا —
  لأن العنوان سطر نص كسائر السطور. وهي وحدها من بين خصائص الفقرة الأربع كذلك،
  أما حجم الخط ونوع الخط والحرف الاستهلالي فتبقى للفقرات وحدها.
- والقيمة واحدة في كل مرة — فإن طبَّقت محاذاة لليسار ثم ضغطت التوسيط سقط
  اليسار والتصق الوسط. وإن ضغطت القيمة المطبَّقة ثانية سقطت السمة بأسرها
  (فترجع إلى المحاذاة الافتراضية).
- **Enter تنقل المحاذاة إلى الجانبين كما هي.** شطر الفقرة يُخرج الفقرتين كلتيهما
  بالمحاذاة نفسها — خلافًا للعنوان (`h`) الذي يسقط عن الجانب الفارغ وللحرف
  الاستهلالي (`dc`) الذي يتبع جانبًا واحدًا فقط، لا استثناء من هذا القبيل في
  المحاذاة.
- الثلاثة **أزرار** (`buttons`) لجناح واحد — لا يمكن تشغيل أحدها وحده، بل يوضع
  `alignWing` وحده في مصفوفة wings.
- **موضع الجدول والصورة واليوتيوب أيضًا من هذا الجناح.** يعيش الجسم داخل الفقرة
  الحاضنة له، وتلك الفقرة هي من تحمل المحاذاة، فـ"صورة موسَّطة" هي في الحقيقة
  "صورة داخل فقرة موسَّطة". ولهذا لا توجد خانة محاذاة في الشريط السياقي للصورة
  أو الجدول أصلًا، والمحاذاة وحدها لا تختفي من شريط الأدوات حتى لو كان المؤشر
  فوق الجسم.

## مثال الاستخدام

```ts
import { createNabiWith, mountSurface, mountToolbar, alignWing } from 'nabi-note'
import 'nabi-note/nabi.css'

const surface = document.querySelector<HTMLElement>('#editor')!

// قائمة الأجنحة تبني معًا معرفة الأصناف والأوامر والمُجمِّع — وهذا هو `registry`
const { nabi, registry } = createNabiWith([alignWing])

mountSurface({ nabi, registry, root: surface })
mountToolbar({ nabi, registry, surface, root: document.querySelector<HTMLElement>('#toolbar')! })

// nabi.onChange(() => user_callback(nabi.getHtml()))
```
