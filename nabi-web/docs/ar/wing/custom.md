# بناء جناح خاص بك

الجناح (wing) هو **كائن واحد**. لا وراثة صنف (class) ولا إجراء تسجيل منفصل — وضعه
في المصفوفة التي تُسلَّم إلى `createNabiWith` هو التسجيل نفسه.

حتى الغامق والجدول والرفع مبنية بملء الخانات المكتوبة هنا فقط. يعمل الجناح الذي
تبنيه بنفسك بـ**نفس الشروط** التي تعمل بها الأجنحة المدمجة — لا طريق مختصر منفصل.

---

## أقصر جناح

علامة سطرية واحدة تعرف `<kbd>`.

```ts
import { createNabiWith, mountSurface, simpleMark, type Wing } from 'nabi-note'
import 'nabi-note/nabi.css'

const kbdWing: Wing = {
  ...simpleMark({
    w: 'kbd',                                                   // اسم هذا الجناح — سيكون `w` في القيمة المحفوظة
    toHtml: (_node, children, ctx) => ctx.element('kbd', children()),   // الرسم الصادر
  }),
  // يرفع يده معلنًا ملكيته لـ `<kbd>` في الـ HTML الوارد
  claim: (el, inner) => (el.tag === 'kbd' ? [{ w: 'kbd', ch: inner(false) }] : null),
}

const surface = document.querySelector<HTMLElement>('#editor')!
const { nabi, registry } = createNabiWith([kbdWing])
mountSurface({ nabi, registry, root: surface })
```

الآن يبقى `<kbd>` في المستند. يبقى كما هو حتى بعد اللصق و`setHtml()` والحفظ
واستعادة التحميل.

```
مسجَّل      <p>اضغط: <kbd>Ctrl</kbd>+<kbd>S</kbd></p>   →   يبقى كما هو
غير مسجَّل  <p>اضغط: <kbd>Ctrl</kbd></p>                →   <p>اضغط: Ctrl</p>
```

**الخانتان تنظران لاتجاهين مختلفين.** `toHtml` طريق صادر و`claim` طريق وارد. إن لم
تكتب `claim` يعمل الرسم لكن **لا يمكن قراءته من جديد** — تُنزَع قشرته فور أن يُحفَظ
ويُستعاد.

`simpleMark` طريق مختصر للعلامة بلا خصائص. للعلامة الحاملة قيمة `valueMark`،
وللجسم `boxObject`، ولصنف القوائم `listFamily`، وفيما عدا ذلك تكتب كائن `Wing`
يدويًّا.

## الأجنحة ثوابت

**معظم الأجنحة ثوابت جاهزة بالفعل** — مثل `boldWing` و`headingWing`، ضعها في
المصفوفة وحسب. اثنان فقط يحتاجان خيارات فلهما دالة مصنع منفصلة.

```ts
makeImageWing({ allowLocalUrls: true })
makeUploadWing({ allowLocalUrls: true })
```

وإن أردت استبدال "عمل الالتصاق" فقط افرد الثابت — فهذا أبسط من بناء جناح جديد، إذ
هو تغيير خانة واحدة لا أكثر.

```ts
const wing = { ...codeWing, attach: makeCodeAttach({ highlight: myHighlighter }) }
```

## التسجيل والترتيب

```ts
const { nabi, registry } = createNabiWith([boldWing, italicWing, kbdWing])
```

**ترتيب المصفوفة هو ترتيب الفحص نفسه.** حين تُحسَم ملكية قطعة من الترميز (`claim`)
تسأل النواة بهذا الترتيب، ويأخذها أول جناح يجيب. إن لم يأخذها أحد تُنزَع قشرتها.

في شريط الأدوات **المجموعة (`button.group`) هي الأسبق.** ترتيب المجموعات ثابت،
وداخل المجموعة الواحدة فقط يسري ترتيب هذه المصفوفة.

### يموت في لحظة التسجيل نفسها

يرمي `createNabiWith` **فورًا** الجناح الذي يخالف العقد. لا ينفجر متأخرًا.

| ما يُضبَط | مثال |
|---|---|
| استعمال كلمة محجوزة اسمًا | `w: 'p'` · `w: 'br'` |
| تسجيل الاسم نفسه مرتين | `boldWing` مرتين |
| عقدة تُقام دون `toHtml` | `place: 'mark'` بلا طريقة للرسم |
| اسم أمر يخالف القاعدة | يجب أن يكون فعلًا+مفعولًا بصيغة camel (`insertTable`) |
| غياب الرفيق اللازم | يحتاج الرفع وجود `img` أو `a` معه (`requiresAnyOf`) |

## الأوامر — دوال صرفة

كل طريق يغيّر المستند يمر بأمر واحد. الأمر **لا يعرف DOM ولا الشاشة.**

```ts
import { boxObject, insertLump, type Command, type Wing } from 'nabi-note'

const insertStamp: Command = (doc, sel, args, env) => {
  // قيمة قادمة من الخارج فتُفحَص — إن لم تصح لا يحدث شيء
  if (typeof args['text'] !== 'string') return null
  const stamp = { w: 'stamp', a: { t: args['text'] }, ch: [] }
  const r = insertLump(doc, sel.focus, stamp, env)
  return { doc: r.doc, selection: { anchor: r.caret, focus: r.caret } }
}

export const stampWing: Wing = {
  ...boxObject({
    w: 'stamp',
    attrs: { t: (v) => (typeof v === 'string' ? v : null) },
    toHtml: (node, _children, ctx) =>
      ctx.element('span', ctx.escape(String(node.a?.['t'] ?? '')), { 'data-nabi-stamp': '' }),
  }),
  commands: { insertStamp },
  button: {
    group: 'insert',
    label: { ar: 'ختم' },
    action: { kind: 'command', command: 'insertStamp', args: { text: 'موافق' } },
  },
}
```

| الوسيط | ما هو |
|---|---|
| `doc` | المستند الآن (مصفوفة من الكتل). **لا تغيّره، بل أجب بمستند جديد** |
| `sel` | التحديد الآن |
| `args` | القيمة التي مرّرها زر أو الشريط السياقي. **قادمة من الخارج فيجب فحصها** |
| `env` | معرفة الأصناف — ما الذي يحمل ماذا، وما الذي يُعَدّ جسمًا |

الجواب إما `{ doc, selection }` أو **`null`**. **أجب بـ`null` إن لم يتغيّر شيء** —
عندها يجيب `applyCommand` بـ`false` ولا تتكدس نقطة تراجع. والمستند الذي تجيب به
يُرتَّبه `cocoon` مرة أخرى، فلا يستطيع أي أمر أن يترك خلفه مستندًا يخالف القواعد.

النداء دائمًا بالاسم.

```ts
nabi.applyCommand('insertStamp', { text: 'موافق' })   // boolean
```

## كل الخانات القابلة للملء

يملك `Wing` واحدًا وثلاثين خانة، **إلزامي منها اثنتان فقط** (`w` و`place`).

### ما هو

| الخانة | المعنى |
|---|---|
| `w` | اسم هذا الجناح. يصير `w` في القيمة المحفوظة. لا يجوز استعمال كلمة محجوزة (`p`·`br`) |
| `place` | `'mark'` فوق الحروف · `'void'` جسم بلا محتوى داخلي · `'container'` جسم يحمل نصًّا داخله · `'attr'` خاصية فقرة · `'tool'` أداة لا أثر لها في المستند |
| `basic` | **هل يدور كما هو بلا توصيل؟** إن لم تُكتَب فهي `false` — لا تُحمَل `wings().allBasic()` إلا الأجنحة الحاملة هذه العلامة، و**يُقاس الجناح المخصَّص بنفس المقياس**. لكن `allBasic()` يمشي على الكتالوج الرسمي وحده، فالجناح الذي يدخل مباشرة عبر `.use(كائن)` يُحمَّل بصرف النظر عن هذه القيمة |
| `holds` | كيف يحمل ما بداخله — `'blocks'` أو `'inline'` |
| `singleParagraph` | يُثبَّت الداخل على فقرة **واحدة** (خلية الجدول) |
| `boolAttrs` | أسماء خصائص بوليانية قيمتها `1` فقط |
| `allows` | أسماء الأجنحة المسموح دخولها هنا. إن لم تُكتَب فالكل مسموح |
| `noAlign` | **للأجسام فقط.** إن حملها الجناح **فلا تقبل الفقرة الحاضنة لهذا الجسم أي محاذاة** — تختفي أزرار المحاذاة من شريط الأدوات، ويرفض الأمر باعتباره بلا تغيير، وتُنزَع أي قيمة محاذاة مثبَّتة سابقًا في مستند محفوظ قديم أثناء مرورها بـ`cocoon`. صندوق الكود أول مستعمليها — يرث `pre` خاصية `text-align` فبدل أن يتحرك الصندوق **تنزلق أسطر الكود نفسها**. ضعها على علامة أو أداة أو خاصية فقرة **ويموت التسجيل** |
| `requiresAnyOf` | يجب تسجيل واحد من هذه معه |
| `parts` | بنى بلا أزرار يجرّها معه — صفوف الجدول وخلاياه، سطر ملخّص الكتلة القابلة للطي |

### القيمة

| الخانة | المعنى |
|---|---|
| `attrKey` · `attrValues` | اسم الخانة التي تستعملها خاصية الفقرة والقيم التي تقبلها |
| `currentValue` | هل هو مضغوط الآن — يلوّن شريط الأدوات والشريط السياقي الخانة بهذا الجواب |

### الطريق الوارد والصادر

| الخانة | المعنى |
|---|---|
| `toHtml` · `partHtml` | الرسم الصادر |
| `toMd` | الرسم الصادر إلى ماركداون. **اختياري — إن لم تُكتَب سقطت العقدة على `toHtml`** (التسطير وYouTube وDetails من هذا الصنف الذي لا مكان له في ماركداون، وهذا هو معنى "ماركداون مختلط بـ HTML" فعلًا) |
| `partMd` | حصة `parts` هذا الجناح في ماركداون |
| `ioFilter` | هذا الجناح **يجلب معه لصق وحفظ وفتح صيغته الخاصة** (ملف `.nabi` هو ذلك المكان). المرشح ليس جناحًا بل معرفة مُلحَقة بجناح، فما يوصّله المضيف عبر `ioFilters` يقف قبله — انظر [إلحاق مرشح IO](#إلحاق-مرشح-io) أدناه |
| `claim` | يحسم ملكية هذا الوسم في الـ HTML الوارد |
| `repair` · `partRepair` | يرتّب هذه العقدة عند مدخل JSON. إن أجاب بـ`null` تُنزَع قشرتها كلها |

### اليد والمفاتيح

| الخانة | المعنى |
|---|---|
| `commands` | الأوامر التي يضعها هذا الجناح |
| `onKey` | يعترض المفتاح أولًا حين يكون المؤشر داخل عقدة هذا الجناح |
| `escapeKeys` | مفاتيح تجعل الحرف التالي يخرج من هذه العلامة |
| `doubleKeys` | `{ اسم المفتاح: اسم الأمر }` — اضغط ذلك المفتاح **مرتين خلال 350ms** فيدور الأمر. تتشابه الكلمة مع `escapeKeys` لكن معناها مختلف: تلك "اخرج من العلامة وتابع الكتابة"، وهذه "أمر واحد من إيماءة واحدة". أولويتها **الأدنى**، فيأتي دورها بعد أن يمر كل عمل آخر على ذلك المفتاح. عند التسجيل **تُفحَص تصادمات المفاتيح ووجود الأمر فعلًا**، فتصادم جناحين على نفس المفتاح، أو اسم يشير إلى أمر غير موجود، يُميت التسجيل |
| `inputRules` | تحويلات تلقائية تحدث بمجرد الكتابة |
| `attach` | حين يحتاج لمس الشاشة — سحب خلايا الجدول، تلوين الكود هذا |

### الشكل

| الخانة | المعنى |
|---|---|
| `button` · `buttons` | زر واحد أو عدة أزرار في شريط الأدوات |
| `context` | تصريح الشريط السياقي |
| `styles` | CSS الذي يحمله هذا الجناح |

## إلحاق مرشح IO

**مرشح IO ليس جناحًا.** يقف فقط عند الأبواب التي يمر بها المستند — اللصق والحفظ
والفتح — يتولى صيغة واحدة، ولا يُقيم عقدته الخاصة في المستند. العقد كائن واحد هو
`IoFilter`.

| الخانة | المعنى |
|---|---|
| `id` · `label` | اسم المرشح، والاسم الظاهر في اللوحة. تصادم `id` **يميت التسجيل في لحظته نفسها** |
| `paste` | ينظر إلى الحافظة (`PasteData`) ويعرض مرشَّحًا. `null` إن لم يكن ملكه، و`build()` لا يُنفَّذ إلا بعد أن يختار المستخدم تلك الخانة |
| `save` | `{ extension, write, lossy?, mime? }` — يستقبل `write` كائن `DocSource` ويأخذ منه ما يحتاج من `json()` و`html()` و`md()`. `lossy` هو ما يضع "(لصيغة فقد)" على لوحة الحفظ |
| `read` | يستقبل اسمًا ونصًّا ويقرؤهما إلى شجرة نابي. **`null` إن لم يكن ملكه**، فتنتقل إلى المرشح التالي |

**الأبواب الثلاثة كلها اختيارية** — مرشح يعرف اللصق وحده، أو القراءة وحدها، لا
بأس به. مواضع الإلحاق هي `ioFilters` في `mountSurface` و`mountFile`، و
`createNabiWith(wings, { ioFilters })`، وخانة `ioFilter` في الجدول أعلاه،
و**من يقف أولًا يغلب** — بهذا الترتيب: mount، ثم المضيف، ثم الجناح، ثم المدمج
(`nabi`·`html`·`html-open`·`markdown`). قائمة الفتح تأتي من `readExtensions(filters)`، الذي
**لا يستطيع عدّ مرشح بلا خانة حفظ** (`.html` المدمج مكان كهذا، فيضيفه المخزن
الافتراضي يدويًّا ليصير أربعة).

الماركداون وحده لا يستطيع المرشح صنعه — الحروف التي تُكتَب بها عقدة معروفة
**للجناح** الحامل `toMd` و`partMd` أعلاه فقط. اتركهما ويسقط العقدة على `toHtml`
مختلطًا في الماركداون كـ HTML؛ وحتى مُحلِّل الماركداون لا يُقيم إلا **الصياغة
التي يقبلها جناح مسجَّل.**

## `w` — تسمية الجناح

`w` هو **الحرف المتكرر مع كل عقدة في القيمة المحفوظة.** كلما قصُر كان أفضل — لذلك
الأجنحة المدمجة قصيرة كـ`b` و`hl` و`tf`. لكن إن تطابق مع اسم غيرك مات التسجيل، فإن
كنت تبني جناحك بنفسك اختر اسمًا قد يطول قليلًا لكن لا يتطابق مع غيره.

لا حاجة أن يطابق اسم وسم HTML — `toHtml` هو من يحدد الوسم الصادر.

::: warning إن غيّرت الاسم لاحقًا
بما أن `w` في القيمة المحفوظة هو الاسم نفسه، فتغييره **يجعل المستندات المحفوظة
سابقًا غير قابلة للقراءة.** إن اضطررت لتغييره فاجعل `claim` يستقبل الاسم القديم
أيضًا خلال فترة انتقال.
:::
