# رابط

## الوصف

`linkWing` (اسمه `a`) يملك `<a href>`. الضغط على الزر يفتح طبقة إدخال عنوان
قرب موضع المؤشر، ولا يُفعَّل زر التأكيد إلا لعنوان يبدأ بـ`http` أو `https` —
وفحص القائمة البيضاء هذا هو بعينه دفاع XSS (فمخطط مثل `javascript:` لا يمر
أصلًا). أما `href` الذي لا يجتاز التحقق فلا يُحفَظ، ويخرج النص عندئذ عاريًا
بلا وسم `<a>`.

وفي الطبقة حقلان — العنوان والنص الظاهر. إن تركت حقل النص فارغًا صار العنوان
نفسه هو النص، وإن كان هناك مؤشر بلا تحديد صارت علامة الرابط التي يقف فيها
المؤشر كلها هي الهدف (وهي قاعدة التمييز ولون النص نفسها).

## الروابط الموجودة تُعدَّل من الشريط السياقي

إذا وقف المؤشر داخل رابط ظهر في الشريط السياقي **حقلا نص** — لا زرّان يفتحان
طبقة، بل حقلا إدخال يقفان في ذلك الشريط نفسه (`kind: 'text'`). يظهران معبَّأين
بالقيمة الحالية، ويُطبَّق ما فيهما عند ضغط Enter أو النقر خارجهما. وإن بقيت
القيمة كما هي فلا يحدث شيء.

| الحقل | وظيفته |
|---|---|
| عنوان الرابط | يغيّر العنوان وحده. ويبقى النص الظاهر كما هو. |
| نص الرابط | يغيّر النص الظاهر وحده. ويبقى العنوان وعلامة المرفق كما هما. |

**ولا يظهر حقل العنوان للمرفقات (روابط الملفات)** — لأن ذلك العنوان قرَّرته
عملية الرفع، وليس قيمة تُعدَّل باليد. أما حقل الاسم فيظهر للرابط العادي
والمرفق سواء. والاسم الفارغ غير مقبول — فصنع رابط بلا اسم ليس تغييرًا للاسم
بل حذفًا.

## المرفق كتلة واحدة على الشاشة

يُعامَل المرفق ككتلة واحدة. النقر عليه لا ينزل بالمؤشر داخله، بل **يستهدف
الرابط كله**، والضغط على Backspace أو Delete بجانبه مباشرة **يمحو الرابط
بأسره.** التعديل يتم من الشريط السياقي لا من المؤشر.

يحمل الجناح هذا العمل عبر `attach` ويربطه `mountSurface` تلقائيًّا —
**فلا حاجة لتركيب أي شيء بمفرده.**

## علامة المرفق

الرابط الوافد من الرفع يحمل علامة `data-nabi-file` (قيمتها الامتداد) — وهذه
العلامة هي ما يجعل صحيفة الأنماط ترسم صندوق مشبك بدل التسطير. وتتبع العلامةُ
الرابطَ سواء غيّرت اسمه أو عنوانه. وحتى مسح التنسيق لا يجرّد المرفق وحده —
لأن تجريد غلافه يحوّله إلى نص عادي ميت.

`linkWing` **ثابت** — لا يُنادى بأقواس، ولا خيارات تُمرَّر له.

::: warning `allowLocalUrls` لا تصل إلى الرابط
مفتاح فتح عناوين `blob:` و`data:` **يعمل مع الصورة فقط.** جهة الخروج دائمًا
صارمة، فالباب الذي يُصفّي به `getHtml()` العناوين (`ctx.url`) يرى القائمة
البيضاء كما هي مهما شغَّل المضيف.

ولهذا فالرابط المرفق الذي يحمل عنوان `blob:` **يسقط إلى نص عادي عند التصدير.**
وهذا هو سبب ألا يترك الرفع العنوان المؤقت كما هو — يجب استبداله بالعنوان
الحقيقي المستلم بعد الرفع ليبقى في المستند.
:::

## مثال الاستخدام

```ts
import { createNabiWith, mountSurface, mountToolbar, mountContextToolbar, linkWing } from 'nabi-note'
import 'nabi-note/nabi.css'

const surface = document.querySelector<HTMLElement>('#editor')!

// قائمة الأجنحة تبني معًا معرفة الأصناف والأوامر والمُجمِّع — وهذا هو `registry`
const { nabi, registry } = createNabiWith([linkWing])

mountSurface({ nabi, registry, root: surface })
mountToolbar({ nabi, registry, surface, root: document.querySelector<HTMLElement>('#toolbar')! })
mountContextToolbar({ nabi, registry, surface, root: document.querySelector<HTMLElement>('#context')! })

// nabi.onChange(() => user_callback(nabi.getHtml()))
```
