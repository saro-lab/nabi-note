# ما هو NABI NOTE؟

NABI NOTE هو **محرر WYSIWYG مفتوح المصدر** يعمل في المتصفح.


## شجرة نابي

معالجة HTML مباشرة تستحيل على خادم بلا DOM، فتُعالَج الأشياء عبر كائن جافاسكربت
اسمه **شجرة نابي**، يُسلسَل باتجاهين إلى JSON وHTML. وأثناء التحويل بين شجرة نابي
وHTML تُنزَع عناصر XSS.

> كل الأجنحة التي تدعمها نابي نوت تدعم منع XSS، أما **الجناح المخصَّص (إضافة
> خارجية)** فعليك التحقق من دعمه لمنع XSS من مطوّره.

## دعم SSR (من جهة الخادم) بلا DOM

يمكنك **قراءة** شجرة نابي المحفوظة كما هي **على الخادم (Node.js)** وتجميع الـ HTML
الذي سيُرسَل. ما يحتاج DOM هو **الإدخال** (`setHtml()`) ونداءات `mount*` التي
تلتصق بالشاشة فقط.

الصفحة التي تعرض فقط لا تحتاج إلى إقامة محرر — بوابة واحدة تكفي. تستقبل المحفوظة
و`registry` (قائمة الأجنحة المسجَّلة) اثنين، وتجيب بسلسلة HTML.

**على الخادم عَلِّق `nabi-note/ssr`** — مدخل لا يحمل إلا ما يلزم للرسم، فسطح
التحرير وأدوات الشاشة لا تُحمَل إطلاقًا.

```ts
import { makeRegistry, defaultWings, renderStoredHtml } from 'nabi-note/ssr'

// تُقام قائمة الأجنحة مرة واحدة عند قيام الخادم — يشترك فيها أي عدد من المحفوظات
const registry = makeRegistry(defaultWings)

const saved = [{ w: 'p', ch: ['سطر تعليق'] }]   // شجرة نابي مقروءة من قاعدة البيانات
renderStoredHtml(saved, registry)
// '<p>سطر تعليق</p>'
```

**تجيب بـ`null` إن لم تكن شجرة نابي** — قاعدة الرفض نفسها التي لـ`setJson()`. والقيمة
العابرة **لا تختلف بحرف واحد** عن `getHtml()` التي يصدرها المحرر — لأنها تمر
بالخطوات نفسها (التسوية ثم التجميع)، فموضع تصفية XSS نفسه أيضًا.

ولرسم المحرر مسبقًا على الخادم استعمل البوابة المقابلة — كل ما يُلصَق زيادةً هو
`data-key`.

```ts
import { renderStoredEditorHtml } from 'nabi-note/ssr'

renderStoredEditorHtml(saved, registry)
// '<p data-key="n0">سطر تعليق</p>'
```

تحصل الشجرة المحفوظة نفسها دائمًا على نفس `data-key`، فإن أرسلت هذا الـ HTML كما هو
واستقبله المتصفح بـ`mountSurface({ nabi, registry, root, hydrate: true })` لم
تُعِد الشاشة رسمه. **عرض هذا الموقع التوضيحي على صفحته الرئيسية يعمل هكذا فعلًا** —
مستند الشاشة الأولى رسمه الخادم، ويستيقظ المحرر فوقه.

### المداخل الثلاثة

| ما تعلّقه | ما الذي يحمله | متى |
|---|---|---|
| `nabi-note` | المحرر كله — التركيب والسطح وأدوات الشاشة | مكان **الكتابة** |
| `nabi-note/ssr` | رسم المحفوظ إلى HTML فقط | الخادم، أو صفحة للعرض فقط |
| `nabi-note/viewer` | سلوك جانب القراءة (فرز الجدول، تلوين الكود) | مكان **عرض** HTML منشور |

لا يحمل `nabi-note/ssr` **ملفًا واحدًا** من سطح التحرير (`surface`) وأدوات الشاشة
(`ui`) — تفرض الشبكة ذلك بمسح المصدر. فلا طريق يتسلل منه كود DOM إلى حزمة الخادم.

## كل تنسيق جناح

ما تسمّيه المحررات الأخرى "إضافة" نسمّيه **جناحًا (wing)**. ما تعرفه النواة مباشرة
هو الفقرة (`p`) والسطر (`br`) والنص الصرف فحسب، أما العناوين والقوائم والجداول
والخط الغامق فكلها أجنحة.

```ts
import { createNabiWith, parseNodes, boldWing } from 'nabi-note'

const bare = createNabiWith([], { parseHtml: parseNodes }).nabi
bare.setHtml('<p><b>غامق</b> <i>مائل</i></p>')
bare.getHtml()
// '<p>غامق مائل</p>'                       — لا جناح مُعلَن فيسقط نصًّا صرفًا.

const bold = createNabiWith([boldWing], { parseHtml: parseNodes }).nabi
bold.setHtml('<p><b>غامق</b> <i>مائل</i></p>')
bold.getHtml()
// '<p><b>غامق</b> مائل</p>'                — أُعلِن boldWing وحده فينجو وحده ويسقط الباقي نصًّا صرفًا.
```

الترميز غير المسجَّل **يتحول إلى نص صرف** — فما لم تُعلِنه من HTML يُستبعَد، وكل جناح
تدعمه نابي رسميًّا يُزيل السكربتات الخبيثة.


## الواجهة

لا يتبدّل المستند إلا عبر `applyCommand()`.

```ts
nabi.applyCommand('toggleMark', { w: 'b' })     // غامق
nabi.applyCommand('setHeading', { value: 2 })   // عنوان بمستوى 2
nabi.undo()
nabi.redo()
```
**يجيب الأمر بنجاحه على شكل `boolean`.** إن لم يتغيّر شيء يجيب بـ`false` ولا يترك
خلفه نقطة تراجع ولا تعديلًا.


## طبقات الكود

**لا يعني هذا أن القيمة تسري بهذا الترتيب.** إنه **اتجاه الاعتماد** المبني من
الأسفل إلى الأعلى، وقاعدته واحدة — **الطبقة السفلى لا تعرف العليا.** لذلك لا تلمس
الطبقات السفلى (`schema`·`doc`·`html`) الـ DOM، وهذا سبب عملها كما هي على الخادم.
مسار دخول القيمة وخروجها هو رسم شجرة نابي أعلاه.

هذا الاتجاه ليس وعدًا مكتوبًا بل **تفرضه الشبكة آليًّا** — أي استيراد يخالف الطبقات
يُسقِط الاختبار في مكانه.


## المصطلحات

| الكلمة | المعنى |
|---|---|
| **العلامة (mark)** | تنسيق النص، مثل `<b>` و`<i>` و`<a>` |
| **الكتلة (block)** | مثل الفقرة والعنوان والقائمة والجدول والصورة |
| **خاصية الفقرة (paragraph attribute)** | خاصية الفقرة، مثل المحاذاة والحرف الاستهلالي |
| **الفقرة الحاضنة** | فقرة تلفّ كائن فقرة واحدة كالجدول والقائمة والصورة |
| **الحيازة (claim)** | الحكم في أي جناح يملك ترميزًا معيَّنًا |
| **الأجزاء (parts)** | وظيفة داخل الجناح، مثل صفوف الجدول وخلاياه، وسطر ملخّص الطي |

### شاشة التحرير

| الكلمة | المعنى |
|---|---|
| **المؤشر (caret)** | مؤشر التحديد داخل المحرر |
| **الشريط السياقي (context row)** | شريط يتحكم في حالة ما يختاره المؤشر الآن، مثل أوامر صف الجدول وعموده، وحقل لغة الكود، وحقلي عنوان الرابط واسمه، وH1 إلى H6 للعنوان |

### النواة

| الكلمة | المعنى |
|---|---|
| **cocoon** | خطوة تسوية شجرة نابي. تعمل **بعد كل أمر** فلا يترك أي أمر خلفه مستندًا يخالف القاعدة |
| **الالتصاق (attach)** | خطّاف يصرّح به الجناح حين يحتاج لمس الشاشة، مثل سحب خلايا الجدول وتلوين الكود وتبديل صندوق الاختيار. يُلصِق `mountSurface` ما يخص الأجنحة المسجَّلة |
| **التحويل التلقائي (input rule)** | تحويل يحدث بمجرد الكتابة، مثل تحوّل الشرطة والمسافة إلى قائمة، و`#` والمسافة إلى عنوان |
