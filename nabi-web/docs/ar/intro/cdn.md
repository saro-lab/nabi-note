## ماذا فعلت للتو

يعمل الملف أعلاه دون أن تقرأ شيئًا مما يلي. انظر هنا فقط حين تريد تعديله.

### وسمان هما التثبيت كله

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/nabi-note@latest/dist/nabi.css">
<script src="https://cdn.jsdelivr.net/npm/nabi-note@latest"></script>
```

**كل** ما تصدّره الحزمة يتعلّق بمتغيّر عام واحد هو `NabiNote`. **أنت من يعلّق الصفحة
النمطية بنفسك** — لا تحقن نداءات mount أي CSS، فإن أسقطت `<link>` ظهر المحرر عاريًا.

### الهيكل

```html
<div id="app" class="nabi">                    <!-- الجذر الذي تعيش فيه الألوان والزوايا والخطوط -->
  <div id="chrome" class="nabi-toolbar">        <!-- شريط الأدوات والشريط السياقي يلتصقان كتلة واحدة -->
    <div class="nabi-toolbar-row">
      <span id="tools"></span>                 <!-- المعاينة وملء الشاشة (أقصى الطرف) -->
      <div id="toolbar"></div>
    </div>
    <div id="context"></div>                   <!-- يملأ نفسه بحسب ما يشير إليه المؤشر -->
  </div>
  <div id="editor" class="nabi-content" contenteditable="true"></div>
</div>
```

يمكن أن تحمل `id` أي اسم تشاء — ما تسلّمه إلى mount هو **العنصر** لا الاسم. أبقِ
الأصناف الأربعة (`nabi`·`nabi-toolbar`·`nabi-toolbar-row`·`nabi-content`) كما هي؛
فهي المقابض التي تمسك بها الصفحة النمطية. إن لم تكن ستستعمل المعاينة وملء الشاشة
فاحذف `<span id="tools">` وسطر `mountViewTools` معًا. يصلح أي وعاء لهذا الصندوق —
`mountViewTools` يقيم صندوقه الطافي إلى الطرف بنفسه، فتسليمه شريط الأدوات نفسه لا
يُخِلّ بصفّ الأزرار.

### اختيار الأجنحة

اختيار الأجنحة سطر بانٍ واحد. الملف أعلاه يستبعد الرفع من الأجنحة الرسمية
التسعة والعشرين، ويضيّق الخط إلى اثنين.

```js
var wings = N.wings().all().drop('upload').use('tf', { values: ['sans', 'serif'] })
```

- `all()` يبدأ من كل الأجنحة الرسمية. **بلا استدعائه تبدأ بيد فارغة** — لا يُحمَل
  إلا ما تحمله `use()`.
  
- `use('اسم', خيارات؟)` إضافة واحدة. إن نودِيَ على جناح موجود أصلًا أضاف الخيارات
  فقط — هذا ما يفعله `use('tf', { values: [...] })` أعلاه. وإن احتاج الجناح
  المطلوب جناحًا آخر ليقف عليه (فالرفع يحتاج صورة أو رابطًا حاضرَين) جُلِب معه
  بصمت.
- `drop('اسم')` حذف مما هو موجود. فإن حاولت حذف جناح يعتمد عليه جناح آخر رمى في
  مكانه وأخبرك بما يجب حذفه معه.
- الاسم مفتاح قصير يُكتَب في القيمة المحفوظة — مثل `b` (غامق) و`tf` (الخط) و
  `upload`. القائمة الكاملة تظهر بـ`console.log(N.wingNames())`.
- **الاستدعاء الخاطئ يرمي في سطره نفسه.** خطأ إملائي في الاسم، أو مفتاح خيار
  مجهول، أو قيمة خارج القائمة — كلها تفعل هذا، وتحمل رسالة الرمي طريقة الإصلاح —
  `use('bod')` تجيب "أتقصد 'b' (غامق)؟". لا مكان يُتجاهَل فيه الخطأ بصمت.

يستقبل `createNabiWith` البانيَ نفسه فلا حاجة لاستدعاء `build()` — لا يُخرِج
`build()` مصفوفة إلا حيث تلزم مصفوفة. عند اختيار قلة فالمصفوفة تظل الجواب.

```js
var wings = [N.boldWing, N.italicWing, N.headingWing, N.bulletListWing]
```

الجناح المصنوع بيدك يُوضَع ككائن — مثل `N.wings().all().use(customWing)`. يجب أن
يبدأ `w` الخاص بذلك الجناح بـ`ex` (مثل `exNote`) — فلو تقاطع مع اسم رسمي مستقبلًا
في القيمة المحفوظة قُرِئ مستند محفوظ سابقًا بمعنى آخر. طريقة الصنع في
[{{ t('menu_wing_custom') }}](../wing/custom).

الأجنحة واحدًا واحدًا في [{{ t('menu_wing') }}](../wing/inline/bold).

### طريق السؤال والتنبيه

وصَّل الملف أعلاه `ask` بحواري `alert`·`confirm` الخاصَّين بالمتصفح — فسؤال مثل
"لديك كتابة غير محفوظة. أتريد المتابعة رغم ذلك؟" يذهب إلى ذلك الصندوق. بلا توصيل
يكون جواب السؤال "لا"، والكلمة التي لا تحتاج جوابًا يعرضها وعاء toast الذي تحمله
النواة أسفل شريط الأدوات — لا حاجة لتوصيل شيء لتنبيه كخطأ الرفع. التفاصيل في
[{{ t('menu_intro_usage') }}](./usage).

### إخراج القيمة

| | |
|---|---|
| `nabi.getHtml()` | الـ HTML الذي تحفظه وتنشره |
| `nabi.getJson()` | شجرة نابي (JSON) |
| `nabi.setHtml(html)` · `nabi.setJson(json)` | إعادة إدخالها |
| `nabi.onChange(fn)` | في كل مرة تتغيّر فيها القيمة |
| `N.renderStoredHtml(json, registry)` | رسم المحفوظ إلى HTML بلا محرر (أدناه [جانب القراءة](#جانب-القراءة)) |

## العناوين

لتثبيت إصدار، أضف رقم الإصدار إلى العنوان. يعطيك unpkg الملف نفسه.

**لا تستعمل العنوان الخالي من رقم الإصدار (`/npm/nabi-note`)** — فـjsDelivr يخزّن ذلك
المكان مؤقتًا لمدة طويلة، وقد تختلط الحزمة والصفحة النمطية من إصدارين مختلفين.

| | العنوان |
|---|---|
| **الحزمة (الأحدث)** | `https://cdn.jsdelivr.net/npm/nabi-note@latest` |
| **الحزمة (مثبَّتة)** | <code>{{ CDN_BUNDLE }}</code> |
| **الصفحة النمطية (الأحدث)** | `https://cdn.jsdelivr.net/npm/nabi-note@latest/dist/nabi.css` |
| **الصفحة النمطية (مثبَّتة)** | <code>{{ CDN_SHEET }}</code> |
| **الحزمة** (unpkg) | `https://unpkg.com/nabi-note` |

تُشحَن الحزمة داخل إصدار npm نفسه، فـ**CDN ليس إصدارًا منفصلًا.**

## جانب القراءة

الصفحة التي **تعرض فقط** HTML محفوظًا لا تُقيم محررًا. علِّق الصفحة النمطية نفسها،
وضع القيمة داخل `.nabi-content`، فتخرج تمامًا كما بدت في المحرر.

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/nabi-note@latest/dist/nabi.css">

<div class="nabi-content">
  <!-- القيمة التي حفظتها بـ getHtml() -->
</div>
```

**إن كان المحفوظ شجرة نابي (JSON) لا HTML** فيُرسَم مباشرة بلا إقامة محرر. ما
يُستقبَل شيئان: المحفوظ وقائمة الأجنحة المسجَّلة.

```html
<script>
  var registry = N.makeRegistry(N.wings().all().build())

  var saved = [{ w: 'p', ch: ['سطر تعليق'] }]   // شجرة نابي مستقبلة من الخادم
  document.querySelector('.nabi-content').innerHTML = N.renderStoredHtml(saved, registry)
</script>
```

تجيب هذه البوابة بـ`null` إن لم تكن شجرة نابي، والقيمة العابرة لا تختلف بحرف واحد
عن `getHtml()` التي يصدرها المحرر — فموضع تصفية XSS نفسه أيضًا. لا تستعمل هذه
البوابة DOM فتعمل على الخادم (Node.js) كما هي، فينفتح بها **طريق تجميع HTML على
الخادم مسبقًا وإرساله جاهزًا**
(راجع [{{ t('menu_intro_ssr') }}](./ssr#رسم-المحفوظ-فقط-بلا-إقامة-محرر)).

الخادم الذي يعلّق الحزمة عبر npm يستعمل **`nabi-note/ssr`** لا الحزمة العامة — مدخل
لا يحمل إلا ما يلزم للرسم، فلا يُحمَل سطح التحرير ولا أدوات الشاشة.

يحمل ملف الصفحة النمطية الواحد **CSS كل الأجنحة** — فالملف لا يعرف أي الأجنحة
سجّلتها، فيحمل الكل.

يتكفّل بالمظهر كله الصفحة النمطية، لكن **فرز الجدول وتلوين الكود عمل جافاسكربت من
جهة القراءة** — فالضغط على عنوان عمود لإعادة ترتيب الصفوف، وتقطيع حروف الكود
لإلباسها لونًا، لا تقدر عليهما CSS. إن أردتهما فعلِّق وقت تشغيل جانب القراءة
ببوابة واحدة.

```html
<script type="module">
  import { attachViewer } from 'https://cdn.jsdelivr.net/npm/nabi-note@latest/dist/viewer/index.js'

  attachViewer(document.querySelector('.nabi-content'), { locale: 'ar' })
</script>
```

- بلا تعليقها يظل المستند مرئيًّا كما هو — فقط لا يعمل الجدول الذي فُعِّل فرزه،
  ويبقى الكود بلون واحد.
- لا يلتصق فرز الجدول إلا بالجدول الذي فُعِّل فرزه في المحرر (تبقى علامة
  `data-nabi-sortable`).
- يجيب المُجزِّئ المضمَّن على تلوين الكود فلا يحتاج اعتمادًا خارجيًّا. ولاستعمال
  مُلوِّن كـShiki أضِف `{ locale: 'ar', highlight }` كخطّاف — يتحمَّل وزنه الصفحة
  التي وصَّلته.
- لا وجود لهذه البوابة في حزمة `NabiNote` العامة — فحتى لا تحمل صفحة القراءة
  المحرر كله يقيم `nabi-note/viewer` وحده. المضيف الذي يعلّق الحزمة عبر npm يعلّق
  البوابة نفسها في المعاينة أيضًا كما في
  [{{ t('menu_intro_usage') }}](./usage#يُلصَق-وقت-تشغيل-جانب-القراءة-في-المعاينة).
