# برمجة الأجواء بالذكاء الاصطناعي

**`llms.txt`** معيار تستعمله المواقع لتسليم محتواها إلى وكلاء الذكاء الاصطناعي (LLM). بدل
HTML، يرتّب بنية المشروع وطريقة استعماله في مارك داون يقرؤه الوكيل مباشرة. المعيار كاملًا في
[llmstxt.org](https://llmstxt.org/).

هذا الموقع فتح هذا الباب أيضًا. لا حاجة لحفظ العنوان — كما في المثال أدناه، **سلِّم العنوان
للوكيل** وهو يتابع الباقي وحده.

```
https://nabi.saro.me/llms.txt
```

يدعم Cursor و Claude Code و OpenAI Codex و Windsurf وغيرها معيار llms.txt.

## عند التبنّي أول مرة

في موقع لا يستعمل nabi-note بعد، أخبر الوكيل دفعة واحدة بما تريد تفعيله، وهل عند الموقع
وضع فاتح/داكن، وما طريقة النشر — والباقي يجمعه الوكيل وحده. **الجملة الأخيرة فقط تختلف بين
الحالات الثلاث أدناه، وبقية الكلام يبقى كما هو.**

### npm + الرسم على الخادم (SSR) — عندما يرسم خادم (Node) المستند مع كل طلب

يشمل هذا خادم Node تديره أنت بنفسك، أو إطار SSR كـNext.js أو Nuxt أو SvelteKit — في الحالتين
يرسم Node المستند مع كل طلب قبل إرساله.

```
نريد إدخال nabi-note كمحرر جديد في موقعنا. الدليل هو
https://nabi.saro.me/llms.txt. عند الموقع وضع فاتح وداكن، فاجعل المحرر يتبعه.
فعِّل كل الأجنحة (wings) المفعّلة افتراضيًّا.

نرسم على الخادم باستعمال Nuxt، ونريد أن يكون النص ظاهرًا من لحظة وصول الزائر —
مرسومًا مسبقًا على الخادم. ثبّته بـnpm ووصّله بـSSR مع hydrate.
```

### npm + التجميع في المتصفح فقط (CSR) — يوجد باندلر لكن لا حاجة للرسم على الخادم

```
نريد إدخال nabi-note كمحرر جديد في موقعنا. الدليل هو
https://nabi.saro.me/llms.txt. عند الموقع وضع فاتح وداكن، فاجعل المحرر يتبعه.
فعِّل كل الأجنحة (wings) المفعّلة افتراضيًّا.

هذا واجهة أمامية نبنيها بـVite، ولا نحتاج رسمًا على الخادم. ثبّته بـnpm
وجمِّعه في المتصفح فقط.
```

### CDN — صفحة ثابتة بلا أداة بناء

```
نريد إدخال nabi-note كمحرر جديد في موقعنا. الدليل هو
https://nabi.saro.me/llms.txt. عند الموقع وضع فاتح وداكن، فاجعل المحرر يتبعه.
فعِّل كل الأجنحة (wings) المفعّلة افتراضيًّا.

هذه صفحة HTML ثابتة بلا أداة بناء. وصّله بوسم `<script>`.
```

::: tip لا شيء يُذكَر عن الفاتح والداكن
`nabi.css` يحمل مسبقًا القيم الفاتحة الافتراضية، وتخصيص `.dark`، وتخصيص `.light` الصريح.
اترك صنف `dark`/`light` في الصفحة كما هو، والمحرر يتبعه من نفسه. لتغيير لون الهوية فقط،
اجعل الوكيل يقرأ `llms/styling.md` أيضًا.
:::

الأمثلة الثلاثة لا تختلف إلا في تلك الجملة الأخيرة — يجد الوكيل ويقرأ على التوالي
`llms/ssr.md` (مع `llms/quickstart-npm.md`) و `llms/quickstart-npm.md` و
`llms/quickstart-cdn.md`، ويوصّله بحسب ذلك.

## عند تغيير ميزة أو إضافتها أو إزالتها

في تركيب قائم فعلًا، الأسلم أن تطلب **بحثًا وخطة أولًا لا التنفيذ مباشرة** — خصوصًا لميزة
تلامس الخادم الخلفي (backend)، حيث تحتاج أولًا أن تعرف ما ينبغي تجهيزه.

### مثال — بحث وخطة أولًا

```
نريد إضافة رفع الملفات. اقرأ https://nabi.saro.me/llms/wings.md و
https://nabi.saro.me/llms/api-reference.md، وابحث ما الذي يحتاجه خادمنا الخلفي
لتفعيل جناح upload (عنوان يستقبل الرفع، الامتدادات والحجم المسموح، شكل الرد
عند الفشل). لا تنفّذ شيئًا الآن — فقط أرِني خطة بما يجب تجهيزه.
```

سيجد الوكيل في `llms/wings.md` أن `upload` جناح أداة (tool) يأخذ `Uploader`، ويتحقق في
`llms/api-reference.md` من التوقيعات الحقيقية لـ`mountUpload` و`Uploader` و
`allowLocalUrls`، ثم يضع خطة تفصل ما يلزم الخادم الخلفي عن ما تقرره الواجهة الأمامية بنفسها.
بعد مراجعة الخطة والموافقة عليها، اطلب تنفيذها.

### مثال أبسط — يمكن طلبه مباشرة

تعديل ضيق لا يحتاج خطة يمكن طلبه مباشرة.

```
اقرأ https://nabi.saro.me/llms/styling.md وغيّر فقط لون التمييز وخلفية
الوضع الداكن إلى ألوان هويتنا.
```

::: tip جناح يخالف العقد يُرفض في لحظة تسجيله نفسها
عند تكليف الوكيل ببناء جناح جديد، اجعله يقرأ
[`llms/custom-wing.md`](https://nabi.saro.me/llms/custom-wing.md) أيضًا. الأخطاء الشائعة —
استعمال كلمة محجوزة كاسم، أو جناح يُنشئ عنصرًا بلا `toHtml` — لا تظهر متأخرة؛ إنما
**تُرفض في لحظة التسجيل نفسها.** قسم "يموت في لحظة التسجيل نفسها" في ذلك المستند يسرد ما
يُفحص.
:::

::: tip إذا انتهى التركيب، اترك سطرًا واحدًا فقط
بعد أول تركيب، لا حاجة لتكرار العنوان كل مرة. سطر كهذا في ملف قواعد المشروع
(`CLAUDE.md`، `.cursorrules`، إلخ) يكفي — بعده يكفي أن تقول "افعل كذا بـnabi-note"
ويجد الوكيل العنوان بنفسه.

```md
هذا المشروع يستعمل `nabi-note` كمحرره. راجع
https://nabi.saro.me/llms.txt قبل أي عمل متعلق به.
```
:::
