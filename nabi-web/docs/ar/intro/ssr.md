# دعم SSR

## رسم المحفوظ فقط — بلا إقامة محرر

الأماكن التي **تعرض فقط** كقائمة تعليقات لا تحتاج محررًا. كل ما يلزم لرسم المستند
هو قائمة الأجنحة المسجَّلة (`registry`)، فلها بوابة مستقلة لا تستقبل سواها.

```ts
import { makeRegistry, defaultWings, renderStoredHtml, renderStoredEditorHtml } from 'nabi-note/ssr'

// مرة واحدة عند قيام الخادم — يشترك فيها أي عدد من المحفوظات
const registry = makeRegistry(defaultWings)

const saved = [{ w: 'p', ch: ['سطر تعليق'] }]   // شجرة نابي مقروءة من قاعدة البيانات

renderStoredHtml(saved, registry)        // '<p>سطر تعليق</p>'
renderStoredEditorHtml(saved, registry)  // '<p data-key="n0">سطر تعليق</p>'
```

**`nabi-note/ssr` مدخل لا يحمل إلا ما يلزم للرسم.** لا يحمل ملفًّا واحدًا من سطح
التحرير (`surface`) وأدوات الشاشة (`ui`) — تفرض الشبكة ذلك — فلا يتسلل كود DOM إلى
حزمة الخادم. البوابة نفسها موجودة في `nabi-note` أيضًا، فالصفحة التي تحمل المحرر
أصلًا تستعملها كما هي.

| | |
|---|---|
| `renderStoredHtml(json, registry, options?)` | الـ HTML الذي تحفظه وتنشره — القيمة نفسها التي يصدرها `getHtml()` |
| `renderStoredEditorHtml(json, registry, options?)` | HTML المحرر — القيمة نفسها التي يصدرها `getEditorHtml()` (يحمل `data-key`) |

- **لا تستعمل الاثنتان DOM** — تعملان على الخادم كما هما.
- **تجيبان بـ`null` إن لم تكن شجرة نابي** — قاعدة الرفض نفسها التي لـ`setJson()`
  (يجب أن يكون المستند كله مصفوفة). لا تَرميان استثناءً.
- **لا تختلفان بحرف واحد** عمّا يصدره المحرر — تمرّان بالخطوتين نفسيهما (التسوية ثم
  التجميع)، فموضع تصفية XSS نفسه أيضًا — لا يقل تعقيم جانب العرض عن تعقيم المحرر.
- `options` واحد فقط، هو `{ allowLocalUrls }` — بنفس معنى ذلك الخيار في
  `createNabiWith`.

**تحصل الشجرة المحفوظة نفسها دائمًا على نفس `data-key`.** فحين يرسم الخادم المحرر
مسبقًا بـ`renderStoredEditorHtml` ويستقبله المتصفح بـ`hydrate` لا تُعاد الشاشة
رسمها.

```ts
mountSurface({ nabi, registry, root: surface, hydrate: true })
```

وإن اختلفا يُعاد الرسم في مكانه، فيكفي أن تتفق قائمتا أجنحة الخادم والعميل.

::: tip الصفحة الرئيسية لهذا الموقع هي ذلك المثال نفسه
مستند عرض الصفحة الرئيسية **رُسِم وقت البناء بـ`renderStoredEditorHtml`** وزُرِع في
الصفحة، ويستيقظ المحرر فوقه بـ`hydrate`. فيُقرَأ النص قبل وصول كود المحرر أصلًا —
بلا مساحة فارغة تُملأ فجأة.
:::

## يمكن رسم شريط الأدوات مسبقًا أيضًا

صف الأزرار **لا يرى المستند.** لا يعتمد إلا على قائمة الأجنحة المسجَّلة واللغة
وترتيب المجموعات، فالحروف الخارجة **ثابتة** — تُستدعى مرة عند قيام الخادم ويُستعمل
ذلك النص باستمرار. لا حاجة إلى إعادة استدعائها مع كل طلب.

```ts
import { makeRegistry, defaultWings, renderToolbarHtml } from 'nabi-note/ssr'

const registry = makeRegistry(defaultWings)

const toolbarHtml = renderToolbarHtml({ registry, locale: 'ar' })
// '<div class="nabi-group" data-group="font">…</div>'
```

أرسل هذا النص كما هو داخل وعاء شريط الأدوات، ففي المتصفح يرسمه `mountToolbar`
**بالدالة نفسها**. وإن كان الصف نفسه قائمًا أصلًا **لا يُعاد رسمه بل يُوصَّل السلك
فقط.**

```ts
mountToolbar({ nabi, registry, surface, root: toolbar })
```

::: warning اكتب `class="nabi-toolbar-row"` على الوعاء أيضًا
حين تُرسِل صفًّا مرسومًا مسبقًا يجب أن يحمل هذا الصنف **منذ أول رسمة.** فإن غاب
ألصقته النواة بنفسها عند mount، فيلتصق الهامشان حينها **فيتزحزح صف الأزرار جانبًا
مرة واحدة.** إن كتبه المضيف مسبقًا لا تلمسه النواة (تنزع فقط ما ألصقته هي).

```html
<div class="nabi-toolbar-row">صف مرسوم مسبقًا</div>
```
:::

- **لا ينكسر شيء عند الاختلاف** — إن اختلف الصف القائم عن قائمة الأجنحة الحالية
  يُعاد رسمه في مكانه. الخسارة الوحيدة هي القيمة المرسومة مسبقًا، والشاشة تبقى
  صحيحة دائمًا.
- **الصف المرسوم مسبقًا حالته "لا شيء مضغوط ولا شيء مخفي".** فالضغط
  (`aria-pressed`) والإخفاء يقررهما المؤشر، والخادم لا يعرفه. إن كان التركيب يخفي
  أزرارًا بحسب المؤشر فقد تختفي بعضها بعد mount ويُطوى الصف من جديد.
- **ضعه في مكان يُقام فيه محرر فقط.** الصفحة المخصَّصة للعرض لا شريط أدوات لديها
  فلا داعي لأن تستقبل هذا النص.

**زرّا المعاينة وملء الشاشة يسلكان الطريق نفسه.** ليسا جناحين بل جزءَي الغطاء
فلا يدخلان في نص شريط الأدوات أعلاه — يُرسَمان على حدة ويُوضَعان في الوعاء الذي
يقيمه `mountViewTools`.

```ts
import { renderViewToolsHtml } from 'nabi-note/ssr'

renderViewToolsHtml({ locale: 'ar' })
// '<span class="nabi-tools">…</span>'
```

::: tip الصفحة الرئيسية لهذا الموقع هي ذلك المثال نفسه
شريط أدوات عرض الصفحة الرئيسية **رُسِم وقت البناء بـ`renderToolbarHtml` و
`renderViewToolsHtml`** وزُرِع فيها، و`mountToolbar`·`mountViewTools` يتعرّفان على
ذلك الصف فيوصِّلان السلك فقط. فلا تظهر الأيقونات الخمس والثلاثون متأخرة.
:::
