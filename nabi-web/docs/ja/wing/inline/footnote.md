# 脚注

本文の番号と文末の一覧で補足説明を結び付けます。

ツールバーの脚注ボタンで内容を入力すると、カーソル位置に脚注が入ります。文字を選択している場合は、選択した文字を残して選択範囲の末尾に挿入します。番号は保存せず、文書内の順序に従って自動的に付けます。

本文の番号を押すと、プロパティ行で内容を編集できます。削除ツールを使うか、脚注の隣で Backspace または Delete を2回押して、選択してから削除します。下部の一覧は読み取り専用で、脚注がなくなると消えます。

プレビューと viewer を接続した公開ページでは、番号にマウスを重ねるか、クリック・タップすると内容を確認できます。内容は1行のプレーンテキストのみで、本文の基本サイズの0.875倍のサンセリフ体で表示します。HTML は文字としてそのまま表示します。
