# AIバイブコーディング

**`llms.txt`** はウェブサイトが AI エージェント（LLM）にプロジェクトの構造と使い方を
効率よく伝えるために作られた標準規格です。HTML マークアップの代わりに、AI が読みやすい
きれいな Markdown 文書でプロジェクトの仕様と API を提供します。詳しい規格は
[llmstxt.org](https://llmstxt.org/) を参照してください。

NABI NOTE の公式サイトも `llms.txt` を完全にサポートしています。複雑な文書をいちいち
コピーする必要はなく、**AI エージェントに下の URL だけ渡せば**、AI が自分で文書を
探索して作業を進めます。

```
https://nabi.saro.me/llms.txt
```

Cursor、Claude Code、OpenAI Codex、Windsurf など最新の AI コーディングツールが
llms.txt 標準をサポートしています。

## 最初に導入するとき

NABI NOTE をプロジェクトに初めて導入するときは、欲しい機能・ライト/ダークモードの
対応有無・配布環境（SSR/CSR/CDN）だけ伝えれば、AI エージェントが最適なコードを
書いてくれます。

### npm + サーバーレンダリング（SSR） — Next.js、Nuxt、SvelteKit など

```
私たちのサイトに nabi-note を新しいエディタとして導入したい。説明書は
https://nabi.saro.me/llms.txt を参考にして。サイトにライト/ダークモードが
あるからエディタのテーマも合わせて。翼(wing)は標準で提供されるものを全部
有効にして。

私たちのサービスは Nuxt でサーバーサイドレンダリングをしている。最初の
アクセス時に画面がちらつかないよう、サーバーであらかじめレンダリングして
渡せるように、npm パッケージのインストールと SSR + hydrate 方式で連携して。
```

### npm + クライアント専用（CSR） — Vite、CRA、SPA 環境

```
私たちのサイトに nabi-note を新しいエディタとして導入したい。説明書は
https://nabi.saro.me/llms.txt を参考にして。サイトにライト/ダークモードが
あるからエディタのテーマも合わせて。翼(wing)は標準で提供されるものを全部
有効にして。

Vite ベースのフロントエンド SPA 環境で、サーバーサイドレンダリングは
不要。npm パッケージでインストールして、ブラウザのクライアント側だけで
組み立てて。
```

### CDN — 静的 HTML 環境

```
私たちのサイトに nabi-note を新しいエディタとして導入したい。説明書は
https://nabi.saro.me/llms.txt を参考にして。サイトにライト/ダークモードが
あるからエディタのテーマも合わせて。翼(wing)は標準で提供されるものを全部
有効にして。

このページはビルドツールのない静的 HTML。`<script>` と `<link>` タグで
連携して。
```

::: tip テーマ（ライト/ダーク）は自動で対応します
`nabi.css` はデフォルトのライト・`.dark` クラス・明示的な `.light` クラスをすべて
内蔵しています。ページのルート要素にある `class="dark"` の切り替えに合わせて、
エディタのテーマも自動で切り替わります。ブランド固有の色にカスタムしたい場合は
`llms/styling.md` も一緒に参照させてください。
:::

## 機能を追加・カスタムするとき

すでに連携済みのエディタに新しい機能を追加・修正するときは、**まず調査と実装計画の
策定を依頼する**のが安全です。特にバックエンド API の連携を伴う機能（ファイル
アップロードなど）は、要件をはっきり整理しておく必要があります。

### 調査と計画策定のプロンプト例

```
ファイルアップロード機能を連携したい。https://nabi.saro.me/llms/wings.md と
https://nabi.saro.me/llms/api-reference.md を参考にして、upload 翼を
有効にするにはバックエンド API 仕様（エンドポイント、許可する拡張子・容量
制限、レスポンス JSON 形式など）とフロントエンドの連携コードがどう構成
されるべきか、まず調査して。すぐにコードを書かず、準備すべき要件と実装
計画を整理して見せて。
```

### 単純なスタイル変更のプロンプト例

```
https://nabi.saro.me/llms/styling.md を参考にして、エディタの強調色
（Accent）とダークテーマの背景色を私たちのブランドカラーに合わせて CSS
変数として再定義して。
```

::: tip 規格に違反した翼は登録時にすぐ例外が発生します
新しいカスタム翼を作らせるときは
[`llms/custom-wing.md`](https://nabi.saro.me/llms/custom-wing.md) も一緒に参照させて
ください。予約語の衝突、必須メソッドの欠落といったよくあるミスは実行時に遅れて
発覚するのではなく、**最初の登録時点で即座に例外として検出**されます。
:::

::: tip プロジェクトのルールファイルに登録しておきましょう
プロジェクトのガイド文書（`CLAUDE.md`、`.cursorrules`、`AGENT.md` など）に下の一文を
追加しておけば、以降は「エディタに〜機能を追加して」と頼むだけで AI が自分から
`llms.txt` を参照します。

```md
このプロジェクトは WYSIWYG エディタとして `nabi-note` を使用しています。
関連作業の際は先に https://nabi.saro.me/llms.txt 文書を確認してください。
```
:::
