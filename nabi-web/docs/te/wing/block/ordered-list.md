# సంఖ్యా జాబితా

క్రమం ముఖ్యమైన అంశాలను సంఖ్యా జాబితాగా చేస్తుంది. ఖాళీ పేరాలో `1.` వంటి సంఖ్య, బిందువు టైప్ చేసిన తర్వాత స్పేస్ కీ నొక్కి లేదా ఎంచుకున్న పేరాలను టూల్‌బార్‌లో మార్చవచ్చు.

కనిపించే సంఖ్యలు అంశం స్థానాన్ని బట్టి లెక్కించబడతాయి; అందువల్ల అంశాలను చేర్చినా లేదా లోపలికి జరిపినా అవి స్వయంగా కొనసాగుతాయి. మీరు ఇచ్చిన ప్రారంభ సంఖ్యను భద్రపరచి ఏదైనా సంఖ్య నుంచి లెక్కించే సదుపాయం లేదు.
