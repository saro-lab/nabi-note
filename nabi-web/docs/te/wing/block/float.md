# ఫ్లోట్ ప్రాంతం

చిన్న వివరణ, చిత్రం లేదా చిన్న పట్టికను ఎడమ లేదా కుడివైపు ఉంచి ప్రధాన పాఠ్యం దాని పక్కగా సాగేలా చేయండి. ప్రాంతంలోని విషయాన్ని అదే ఎడిటర్‌లో నేరుగా మార్చవచ్చు. గీతల సరిహద్దు సవరించేటప్పుడు మాత్రమే కనిపిస్తుంది; ప్రివ్యూ, ప్రచురిత వీక్షణలో విషయం, అమరిక మాత్రమే ఉంటాయి.

కింది ఉదాహరణలో ప్రాంతం లోపల కర్సర్ ఉంచి లక్షణ సాధనాలతో వైపు, గరిష్ఠ వెడల్పు మార్చండి. ప్రివ్యూలో గీతల సరిహద్దు లేకుండా ప్రధాన పాఠ్యం సాగే విధానం చూడవచ్చు.

<WingDemo path="/wing/block/float" />

```ts
const selected = wings().allBasic().build()
```

తేలియాడే ప్రాంతం ప్రాథమిక wing-లలో ఉంటుంది. అవసరమైన wing-లను మాత్రమే అమర్చితే `wings().use('float')` వాడండి లేదా `floatWing`ను నేరుగా నమోదు చేయండి. ప్రాంతంలో వాడే చిత్రాలు, పట్టికలు, జాబితాల వంటి వాటి wing-లను కూడా నమోదు చేయాలి.

## సృష్టించడం, అమర్చడం

ప్రధాన పాఠ్యంలో కర్సర్ ఉంచి **ఫ్లోట్ ప్రాంతం** బటన్ నొక్కితే ఖాళీ ప్రాంతం ఏర్పడుతుంది. డిఫాల్ట్‌గా కుడివైపు, గరిష్ఠ వెడల్పు 40% ఉంటుంది. అనేక పేరాలను ఎంచుకుని నొక్కితే ఎంపిక తాకిన మొత్తం పేరాలను ఒకే ప్రాంతంగా చుడుతుంది. ఉన్న తేలియాడే ప్రాంతాన్ని మళ్లీ చుట్టలేరు లేదా దాని లోపల మరో తేలియాడే ప్రాంతాన్ని సృష్టించలేరు.

```ts
nabi.applyCommand('insertFloat', { side: 'right', w: 40 })
```

ప్రాంతం లోపల కర్సర్ ఉన్నప్పుడు లక్షణ సాధనాల్లో ఎడమ లేదా కుడి వైపు, గరిష్ఠ వెడల్పు మార్చండి. గరిష్ఠ వెడల్పుగా 20%, 30%, 40%, 50%ల్లో ఒకటి ఎంచుకోండి. ఇది మొత్తం తెరకు కాకుండా ప్రధాన పాఠ్యం వెడల్పుకు అనుగుణం; విషయం తక్కువైతే ప్రాంతం మరింత సన్నగా ఉండవచ్చు.

```ts
nabi.applyCommand('setFloatSide', { side: 'left' })
nabi.applyCommand('setFloatWidth', { w: 30 })
```

వచనం, చిత్రాలు, పట్టికలు అతికించడం, బ్లాక్ మార్పు, అప్‌లోడ్ ప్రాంతం లోపలే ఉంటాయి. లోపలి పట్టిక తొలగిస్తే ఆ పట్టిక మాత్రమే పోతుంది. ప్రాంతం లోపల, బయట రెండింటినీ కవర్ చేసే ఎంపికలో అంతర్గత బ్లాక్ చేర్పు లేదా మార్పు అందుబాటులో ఉండదు.

వెడల్పు విలువ పక్కనున్న **ఫ్లోట్ ప్రాంతాన్ని విడదీయి** బటన్ లోపలి విషయాన్ని తొలగించకుండా ప్రధాన పాఠ్యంలోకి తిరిగి ఉంచుతుంది. సృష్టించడం, అమరిక మార్చడం, విప్పడం అన్నింటికీ అన్‌డూ, రీడూ మద్దతు ఉంది.

```ts
nabi.applyCommand('unwrapFloat')
```

## ప్రధాన పాఠ్యంతో కలిసి సాగే విధానం

తరువాతి పేరాలు ప్రాంతం పక్కగా సాగి, ప్రాంతం ముగిసినప్పుడు ప్రధాన పాఠ్యం పూర్తి వెడల్పుకు తిరుగుతాయి. తదుపరి శీర్షిక, పట్టిక, కోడ్, విభాజకం లేదా కొత్త తేలియాడే ప్రాంతం మునుపటి ప్రాంతం కింద మొదలవుతుంది.

ప్రధాన పాఠ్యం వెడల్పు `36rem` కంటే తక్కువైతే ప్రాంతం, ప్రధాన పాఠ్యం ఒకే నిలువు వరుసలో అమరుతాయి. ముద్రించేటప్పుడు కూడా ఒకే నిలువు వరుస ఉంటుంది; సేవ్ చేసిన వైపు, గరిష్ఠ వెడల్పు అలాగే నిలుస్తాయి. పత్ర పోలిక వీక్షణ ప్రతి ప్రాంతపు వైపు, గరిష్ఠ వెడల్పును ఉంచుతుంది; మార్పులు చదవడం సులభం కావడానికి తరువాతి బ్లాక్‌ను విడిగా దాని కింద చూపిస్తుంది.

## సేవ్ చేయడం, లోడ్ చేయడం

JSONలో `float` నోడ్ `a.side`, `a.w`తో పాటు లోపలి బ్లాక్‌లు నిల్వవుతాయి. HTMLలో సాధారణ వస్తువు పేరాలోని `div`పై `data-nabi-float`, `data-nabi-float-width` లక్షణాలు వాడతారు.

```html
<div data-nabi-p>
  <div data-nabi-float="right" data-nabi-float-width="40">
    <p>ప్రధాన పాఠ్యం పక్కన ఉంచే వివరణ.</p>
  </div>
</div>
<p>ఈ పేరా ప్రాంతం పక్కగా కొనసాగుతుంది.</p>
```

Markdown ఎగుమతి ప్రాంతాన్ని HTMLగా నిలుపుతుంది. ఇష్టానుసార CSS `float` శైలులు దిగుమతి కావు; కాబట్టి సేవ్ చేయడానికి, పునరుద్ధరించడానికి NABI NOTE రూపొందించిన JSON లేదా HTML వాడండి. వైపు, వెడల్పు అలాగే ఉండేందుకు ఎడిటర్, SSR, ప్రివ్యూ, ప్రచురిత వీక్షణలో అవే wing-లు, CSSను కలపండి.

## CSS శైలులు

ప్రాంతంలోని రంగులు, ఖాళీలకు `[data-nabi-float]` సెలెక్టర్‌తో శైలి ఇవ్వవచ్చు. బయటి పేరా అమరిక, గరిష్ఠ వెడల్పును నిర్వహిస్తుంది కాబట్టి `float`, `display` లేదా వెడల్పును నేరుగా మార్చవద్దు.

```css
.brand-note .nabi-content [data-nabi-float] {
  background: var(--nabi-soft);
  border-radius: var(--nabi-radius);
  padding: .75rem;
}
```
