# తనిఖీ జాబితా

పూర్తయిందా లేదా అనే స్థితి ఉన్న జాబితా ఇది. ఖాళీ పేరాలో `[ ]` లేదా `[x]` తర్వాత స్పేస్ కీ నొక్కి లేదా టూల్‌బార్‌లో సృష్టించి, చెక్‌బాక్స్‌ను నొక్కి స్థితిని మార్చవచ్చు.

చెక్ చేసిన స్థితి అంశ లక్షణంగా పత్రంలోనే భద్రపరచబడుతుంది. అంశాన్ని విభజించినప్పుడు చెక్ స్థితి ఖాళీగా మిగిలిన ముందు అంశాన్ని కాకుండా వచనం మిగిలిన అంశాన్ని అనుసరిస్తుంది; కాబట్టి పూర్తయిన పనిని రెండుగా విభజించినా స్థితి మారిపోదు.

Enter అంశాన్ని విడగొడుతుంది; Shift+Enter దాని లోపల కొత్త పంక్తిని మాత్రమే సృష్టిస్తుంది. Tab, Shift+Tab ఇండెంట్‌ను పెంచుతాయి, తగ్గిస్తాయి. పట్టిక గడుల్లోనూ అవే నియమాలు వర్తిస్తాయి; చెక్ చేసిన స్థితి కూడా నిల్వవుతుంది.
