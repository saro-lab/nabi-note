# విభాజకం

ఇది పత్ర ప్రవాహాన్ని విభజించే అడ్డ గీత. ఖాళీ పేరాలో మూడు లేదా అంతకంటే ఎక్కువ హైఫన్‌లు టైప్ చేసి ఎంటర్ కీ నొక్కి లేదా టూల్‌బార్‌లో చేర్చవచ్చు.

విభాజకం అక్షరాలు లేని స్వతంత్ర బ్లాక్ కాబట్టి శీర్షిక లేదా రంగు వంటి ఆకృతీకరణను కలిగి ఉండదు. ముందు, వెనుక పేరాలను విడదీయడానికి మాత్రమే దీన్ని వాడండి.
