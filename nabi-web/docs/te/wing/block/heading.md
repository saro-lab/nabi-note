# శీర్షిక

పేరాను శీర్షికగా మార్చి దాని స్థాయిని కూడా నిర్ణయిస్తుంది. టూల్‌బార్‌లో శీర్షికను ఎంచుకుని H1 నుంచి H6 వరకు ఒకదాన్ని ఎంచుకోండి లేదా ఖాళీ పేరాలో `#` నుంచి `######` వరకు టైప్ చేసిన తర్వాత స్పేస్ కీ నొక్కండి.

శీర్షిక ప్రత్యేక బ్లాక్ రకం కాదు; అది పేరాలో భద్రపరచబడే లక్షణం. శీర్షికను మళ్లీ నొక్కితే సాధారణ పేరాకు తిరిగి వస్తుంది; కాబట్టి వచన నిర్మాణాన్ని అలాగే ఉంచి స్థాయిని మాత్రమే మార్చవచ్చు.

సాధారణ గడుల్లోని అంతర్గత పేరాలను శీర్షికలుగా మార్చవచ్చు. హెడర్ గడులకు పేరా శీర్షిక ఆకృతి వర్తించదు; గడిని హెడర్‌గా మార్చినప్పుడు ఇప్పటికే ఉన్న శీర్షిక ఆకృతి కూడా తొలగుతుంది. అనేక పేరాలను ఎంచుకుంటే, అన్నింటి శీర్షిక స్థాయి ఒకేలా ఉన్నప్పుడే టూల్‌బార్ ఒక ఉమ్మడి క్రియాశీల విలువను చూపిస్తుంది.
