# పాదసూచిక

పాఠ్యంలోని సంఖ్యలు, పత్రం చివర జాబితా ద్వారా అదనపు వివరణలను అనుసంధానించండి.

టూల్‌బార్‌లోని పాదసూచిక బటన్‌తో విషయం నమోదు చేస్తే కర్సర్ ఉన్న చోట పాదసూచిక చేరుతుంది. పాఠ్యాన్ని ఎంచుకుని ఉంటే దానిని మార్చకుండా ఎంపిక చివర చేర్చబడుతుంది. సంఖ్యలు నిల్వ కావు; పత్రంలోని క్రమం ప్రకారం స్వయంచాలకంగా కేటాయించబడతాయి.

పాఠ్యంలోని సంఖ్యపై క్లిక్ చేసి లక్షణాల వరుసలో విషయాన్ని సవరించండి. తొలగింపు సాధనాన్ని వాడండి లేదా పాదసూచిక పక్కన Backspace లేదా Delete రెండుసార్లు నొక్కి మొదట ఎంచుకుని, ఆపై తొలగించండి. దిగువ జాబితా చదవడానికి మాత్రమే; పాదసూచికలు లేకపోతే అది కనిపించదు.

ముందస్తు వీక్షణలో, viewer అనుసంధానించిన ప్రచురిత పేజీలలో సంఖ్యపై మౌస్ ఉంచినా, క్లిక్ చేసినా, తాకినా విషయం కనిపిస్తుంది. ఒకే పంక్తి సాధారణ పాఠ్యం మాత్రమే అనుమతించబడుతుంది; అది ప్రధాన పాఠ్యం ప్రాథమిక పరిమాణంలో 0.875 రెట్లు ఉండే శాన్స్ సెరిఫ్ ఫాంట్‌లో కనిపిస్తుంది. HTML అక్షరాలుగానే కనిపిస్తుంది.
