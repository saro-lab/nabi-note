# టెక్స్ట్ రంగు

ఎంచుకున్న వచనానికి అనుమతించిన రంగు పేరును వర్తింపజేయండి. నిల్వ విలువ CSS రంగు స్ట్రింగ్ కాదు; అది అనుమతించిన పేరు, నిజమైన రంగును `--nabi-tc-<name>` CSS వేరియబుల్ నిర్ణయిస్తుంది. దీంతో అదే పత్రం లేత, ముదురు థీమ్‌లలో చదవదగినదిగా ఉంటుంది.

<WingDemo path="/wing/inline/text-color" />

```ts
const selected = wings().use('tc', {
  values: ['green', 'coral', 'blue'],
}).build()
```

`values`ను వదిలేస్తే డిఫాల్ట్ పాలెట్ `green`, `coral`, `violet`, `amber`, `blue`. జాబితాను తగ్గిస్తే ఇతర రంగులను ఆదేశం, పత్రం లోడ్ రెండూ తిరస్కరిస్తాయి.

## CSS శైలులు

పత్రం రంగు పేరును మాత్రమే నిల్వ చేస్తుంది. CSS వేరియబుల్స్‌తో ఎడిటర్, ప్రచురిత వీక్షణకు నిజమైన రంగును సెట్ చేయండి.

```css
.nabi-content { --nabi-tc-blue: #2563eb; }
```

నేపథ్య రంగుతో కాంట్రాస్ట్‌ను తనిఖీ చేయండి. ముదురు థీమ్‌లో అదే రంగు పేరుకు వేరే విలువ ఉండవచ్చు.

```css
.dark .article-body {
  --nabi-tc-blue: #93c5fd;
  --nabi-tc-green: #86efac;
}
```
