# ఇటాలిక్

ఎంచుకున్న వచనాన్ని వాలుగా చూపిస్తుంది. రచనల పేర్లు లేదా ఇతర భాషల పదాలను ప్రధాన వచనం నుంచి స్వల్పంగా వేరుగా చూపించడానికి ఇది ఉపయోగపడుతుంది. ఇప్పటికే వాలుగా ఉన్న భాగంలో మళ్లీ నొక్కితే ఆ ఆకృతి తొలగిపోతుంది.
