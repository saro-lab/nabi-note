# NABI NOTE কী?

NABI NOTE ব্রাউজারে চলা একটি **ওপেন-সোর্স WYSIWYG এডিটর**।

---

## নথির আসল রূপ নাবিট্রি

নথি বহনকারী পাত্রটি HTML স্ট্রিং নয়, বরং **নাবিট্রি** — ফরম্যাট আর
অ্যাট্রিবিউট তথ্য ধরে রাখা সাধারণ JS অবজেক্টের একটি অ্যারে। HTML থাকে কেবল
ট্রি যাতায়াতের দুই প্রান্তে।

<FlowChain :steps="stepsIn" caption="ইনপুট — বাইরে থেকে আসা HTML setHtml() দিয়ে নাবিট্রি হওয়ার পরই পর্দায় বসে।" />

<FlowChain :steps="stepsOut" caption="আউটপুট — একটি নাবিট্রি থেকে তিনটি জিনিস বেরোয়। পর্দার DOM যেমন আছে তেমনই বের করে দেওয়া হয় না।" />

| ফাংশন | কী |
|---|---|
| `getHtml()` | **সংরক্ষণ·প্রকাশের HTML।** সম্পাদক-নির্দিষ্ট কোনো চিহ্ন এতে নেই |
| `getJson()` | **নাবিট্রি।** অভ্যন্তরীণ কী (`_id`) ছেঁকে বাদ দিয়ে বেরোয় |
| `getEditorHtml()` | এখনকার সম্পাদক-পর্দার HTML। `data-key` লাগানো থাকে বলে এটি বের করার মান নয় |

**সংরক্ষণের মান আগের দুটোর একটি।** `getEditorHtml()` হলো সার্ভারে সম্পাদক
আগে থেকে এঁকে রাখার জায়গা। বিস্তারিত রূপ আছে [{{ t('menu_intro_usage') }}](./intro/usage)-এ।

তিনটিই **একই নাবিট্রি থেকে সেই মুহূর্তে হিসেব করা হয়** — কোথাও HTML স্ট্রিং
হিসেবে সংরক্ষিত থাকে না। তাই `onChange`-এ পাওয়া `getHtml()`-এর মান আবার
`setHtml()` দিয়ে পড়ালেও একই নাবিট্রি বেরোয়।

::: tip আউটপুটে DOM লাগে না
`createNabiWith()` · `getJson()` · `getHtml()` · `getEditorHtml()` — এসব
বিশুদ্ধ হিসাব। মানে সংরক্ষিত নাবিট্রি যেমন আছে তেমনই দিয়ে সার্ভারে (Node.js)
পাঠানোর HTML জোড়া যায় — ব্রাউজার বা নকল DOM কিছুই লাগে না। DOM লাগে কেবল
**ইনপুটে** (`setHtml()`) আর পর্দায় জোড়া `mount*`-এ।

```ts
import { createNabiWith, defaultWings } from 'nabi-note'

const { nabi } = createNabiWith(defaultWings, { doc: সংরক্ষিত_নাবিট্রি })
const html = nabi.getHtml()
```
:::

আসা HTML (হাতে লেখা হোক, পেস্ট করা হোক, বা সংরক্ষণ করে ফিরিয়ে আনা হোক)
`setHtml()`-এর ভিতর দিয়ে যাওয়ার সময় নিবন্ধিত wing-এর অচেনা ট্যাগ·অ্যাট্রিবিউট
সব ছেঁকে বাদ পড়ে। ট্রি নিজেও `cocoon` দিয়ে আরেকবার গোছানো হয়, যাতে ব্লক
পরিষ্কারভাবে নেস্ট হয়, অভ্যন্তরীণ কী অদ্বিতীয় থাকে, আর শেষ প্রান্তের ব্লক
খালি না থাকে।

::: tip সংরক্ষিত HTML আবার আঁকার সময়
`getHtml()` যা ছেঁকে বাদ দেয় তা হলো **নিবন্ধিত নয় এমন মার্কআপ**। সংরক্ষণ করে
বের করা HTML সম্পাদক নয়, **সাধারণ কোনো পাতায়** যেমন আছে তেমনই আঁকতে হলে সেই
পাতার নিজের sanitize তখনও দরকার — সম্পাদকের ফিল্টার সম্পাদকের নিজের জন্য,
যেকোনো HTML নিরাপদে আঁকা যাবে তার নিশ্চয়তা নয়।
:::

## ফরম্যাট মানেই wing

অন্য এডিটরে যাকে "প্লাগইন" বলা হয়, সেই একককে এখানে **wing** বলা হয়। কোর
সরাসরি চেনে কেবল অনুচ্ছেদ (`p`), লাইন (`br`), আর সাধারণ লেখা — শিরোনাম·
তালিকা·টেবিল·গাঢ় সবই wing। কোডেও একই নাম ব্যবহার করা হয় — টাইপটি `Wing`।

**সব wing-ই সম্পূর্ণ প্রস্তুত কনস্ট্যান্ট।** সরাসরি অ্যারেতে দিলেই হয়।
অপশন লাগে এমন মাত্র দুটোরই ফ্যাক্টরি ফাংশন আলাদা আছে —
`makeImageWing({ allowLocalUrls })` আর `makeUploadWing({ allowLocalUrls })`।
কোড রং বসানোর মতো শুধু জোড়ার কাজটুকু বদলাতে চাইলে কনস্ট্যান্ট ছড়িয়ে লেখা হয়:
`{ ...codeWing, attach: makeCodeAttach({ highlight }) }`।

```ts
import { createNabiWith, parseNodes, boldWing } from 'nabi-note'

const bare = createNabiWith([], { parseHtml: parseNodes }).nabi
bare.setHtml('<p><b>গাঢ়</b> <i>তির্যক</i></p>')
bare.getHtml()
// '<p>গাঢ় তির্যক</p>'                    — কোনো wing-ই নেই
const bold = createNabiWith([boldWing], { parseHtml: parseNodes }).nabi
bold.setHtml('<p><b>গাঢ়</b> <i>তির্যক</i></p>')
bold.getHtml()
// '<p><b>গাঢ়</b> তির্যক</p>'              — কেবল গাঢ়ই টিকে থাকে
```

নিবন্ধিত নয় এমন মার্কআপের খোলস খসে গিয়ে **সাধারণ লেখায় নেমে আসে।** "এই
এডিটর দিয়ে কী লেখা যায়" প্রশ্নের উত্তরটাই নিবন্ধিত wing-এর তালিকা।

## সম্পাদনা একটিমাত্র দরজা দিয়ে বেরোয়

নথি বদলানোর **সব** পথ `applyCommand()`-এর ভেতর দিয়ে যায়। টুলবার বোতাম,
স্বয়ংক্রিয় রূপান্তর, পেস্ট, undo — সবই তা-ই। আসল ট্রি হাতে বদলানোর কোনো
পথ শুরু থেকেই নেই।

```ts
nabi.applyCommand('toggleMark', { w: 'b' })     // গাঢ় — কোরের মার্ক টগল
nabi.applyCommand('setHeading', { value: 2 })   // শিরোনাম স্তর ২ — wing-এর বসানো কমান্ড
nabi.undo()
nabi.redo()
```

কমান্ড **উত্তর `boolean` হিসেবে ফিরিয়ে দেয়।** ছোঁড়ে না, আর কিছু না বদলালে
`false` ফিরিয়ে দেয়, undo-এর জায়গাও কোনো সংকেতও রেখে যায় না।

wing কমান্ড বসায় একটিমাত্র ঘোষণায় (`commands`)। **ডিফল্ট wing-ও অন্য কারও
বানানো wing-এর মতো একই দরজা ব্যবহার করে** — "কেবল ডিফল্ট wing-এর জন্য
সংক্ষিপ্ত পথ" বলে কিছু নেই।

## স্তর নিচ থেকে উপরে সাজানো

/>

এই ক্রম কোনো কথা নয়, একটি **পরীক্ষা**। নিচের স্তর উপরের স্তর import করলে
জাল ভেঙে পড়ে। ভাই wing একে অপরকে ডাকাও আটকানো — একসঙ্গে ব্যবহৃত কোড নেমে যায়
`wing` স্তরে।

নতুন ফিচার মানেই wing। কোরের ফাইল বদলাতে হবে বলে মনে হলে সেটি প্রায়ই
**চুক্তি (`Wing` টাইপ) অপর্যাপ্ত** হওয়ার লক্ষণ।

## পরিভাষা

এই সাইট আর রিপোজিটরি যেসব বাকি শব্দ ব্যবহার করে। অন্য এডিটরের সঙ্গে নাম মিলে
গেলেও অর্থ আলাদা হতে পারে — তাই এখানে লেখা অর্থেই কেবল ব্যবহার করা হয়।

### নথি তৈরি করে যা

| শব্দ | অর্থ |
|---|---|
| **মার্ক (mark)** | অক্ষরে বসানো ফরম্যাট — `<b>` · `<i>` · `<a>`। বাক্যের ভিতরে, টেবিলের ঘরে, শিরোনামের ভিতরে যেকোনো জায়গায় থাকতে পারে |
| **ব্লক (block)** | অনুচ্ছেদের জায়গা নেওয়া গুচ্ছ — অনুচ্ছেদ·শিরোনাম·তালিকা·টেবিল·ছবি |
| **অনুচ্ছেদ-অ্যাট্রিবিউট (paragraph attribute)** | নতুন ট্যাগ না বানিয়ে অনুচ্ছেদের ধর্মটুকু বদলে দেওয়া চিহ্ন — শিরোনামের স্তর·সারিবদ্ধতা·ড্রপ ক্যাপ |
| **র‍্যাপার অনুচ্ছেদ** | টেবিল·তালিকা·ছবির মতো অনুচ্ছেদের জায়গা নেওয়া জিনিসকে এক স্তর মুড়ে রাখা অনুচ্ছেদ। সারিবদ্ধতা এই অনুচ্ছেদই বহন করে, আর ক্যারেট বস্তুটির আগে-পরে দাঁড়ানোর জায়গা পায় |
| **মালিকানা (claim)** | কোন মার্কআপ কোন wing-এর — এই বিচারটুকু। কেউ দাবি না করলে খোলস খসে যায় |
| **অংশ (parts)** | একটি wing সঙ্গে নিয়ে আসা বোতাম-বিহীন কাঠামো — টেবিলের সারি·ঘর, ভাঁজের সারাংশ-লাইন |

### কেবল সম্পাদনার পর্দায় থাকা শব্দ

| শব্দ | অর্থ |
|---|---|
| **ক্যারেট (caret)** | অক্ষর বসার জায়গা দেখায় এমন মিটমিট করা দণ্ড |
| **কনটেক্সট সারি (context row)** | ক্যারেট এখন যেখানে আছে সেখানেই যা করা যায় তা ওঠে এমন সারি — টেবিলের সারি·কলাম কমান্ড, কোডের ভাষার ঘর, লিঙ্কের ঠিকানা·নামের ঘর, শিরোনামের H1~H6 |
| **এসকেপ কী (escape key)** | মার্কের ভিতরে এই কী চাপলে পরের অক্ষর সেই মার্কের বাইরে বসে — wing এটি `escapeKeys` দিয়ে ঘোষণা করে |
| **প্লেসহোল্ডার (placeholder)** | আপলোড চলাকালীন কেবল দাঁড়িয়ে থাকা অস্থায়ী জায়গা। সংরক্ষিত মানে কখনোই মেশে না |

### বানানোর পক্ষে ব্যবহৃত শব্দ

| শব্দ | অর্থ |
|---|---|
| **cocoon** | নাবিট্রি গোছানোর একটি নর্মালাইজেশন ধাপ। **প্রতিটি কমান্ডের পরেই ফেরে** বলে কোনো কমান্ডই নিয়ম ভাঙা নথি রেখে যেতে পারে না |
| **জোড়ার কাজ (attach)** | wing পর্দায় হাত দিতে চাইলে ঘোষণা করা হুক — টেবিলের ঘর টেনে বদলানো, কোড রং বসানো, চেকবক্স টগল — সবই এটি। `mountSurface` নিবন্ধিত wing-এর এটি একসঙ্গে জুড়ে দেয় |
| **স্বয়ংক্রিয় রূপান্তর (input rule)** | কেবল লেখার মধ্য দিয়েই ঘটে যাওয়া রূপান্তর — হাইফেন আর স্পেস তালিকায়, `#` আর স্পেস শিরোনামে |

## সীমাবদ্ধতা

React বা Vue import না করে বিশুদ্ধ DOM API-ই ব্যবহার করা হয়। কারণ একই
পাতায় ভিন্ন ভিন্ন ফ্রেমওয়ার্ক আর সংস্করণের সমন্বয়ে এটি একসঙ্গে ব্যবহৃত হয়।

কোড ব্লকের রং বসানোর জন্য **প্যাকেজের ভিতরেই একটি হালকা টোকেনাইজার আছে** —
C-ঘরানা·পাইথন·JSON·CSS·মার্কআপ·SQL·শেল চেনে। আরও নিখুঁত রং বসাতে চাইলে
Prism·highlight.js·Shiki-র মতো কিছু `makeCodeAttach({ highlight })` দিয়ে
জুড়ে দিলে সেটিই রং বসাবে।
