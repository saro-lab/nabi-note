# ব্লক আর অনুচ্ছেদ-অ্যাট্রিবিউট বানানো

জায়গা নেওয়া জিনিস তিন ধরনের।

| `place` | কী | উদাহরণ |
|---|---|---|
| `'void'` | **ভিতরে কিছু ধরে না এমন বস্তু**। ক্যারেট ভিতরে ঢুকতে পারে না | ডিভাইডার·ছবি·YouTube |
| `'container'` | **ভিতরে লেখা আছে এমন বস্তু** | উদ্ধৃতি·ভাঁজ·টেবিল·তালিকা·কোড |
| `'attr'` | অনুচ্ছেদ নিজের গায়ে বসা একটি মান। কোনো নোড বানায় না | শিরোনাম·সারিবদ্ধতা·ড্রপ ক্যাপ |

---

## বস্তু র‍্যাপার অনুচ্ছেদের ভিতরে থাকে

নথি হলো **ব্লকের একটি অ্যারে**, আর সর্বোচ্চ স্তরে দাঁড়াতে পারে কেবল
অনুচ্ছেদ (`p`)। বস্তু সরাসরি সর্বোচ্চ স্তরে দাঁড়ায় না, বরং **নিজেকেই
ধরে রাখা** একটি অনুচ্ছেদ পরে দাঁড়ায়।

```json
[{ "w": "p", "ch": [{ "w": "hr", "ch": [] }] }]
```

এই অনুচ্ছেদটিই **র‍্যাপার অনুচ্ছেদ**, আর পর্দায় `<div data-nabi-p>` হয়ে
আঁকা হয়।

এমনটা করার কারণ দুটো। বস্তুর আগে-পরে ক্যারেট দাঁড়ানোর জায়গা সবসময় থাকে
(একটি অনুচ্ছেদ সবসময় সেখানে থাকে বলে), আর **সারিবদ্ধতার মতো অনুচ্ছেদ-
অ্যাট্রিবিউট বস্তু নিজেই পেয়ে যায়** — "মাঝে-সারিবদ্ধ ছবি" মানেই "মাঝে-
সারিবদ্ধ অনুচ্ছেদের ভিতরের ছবি"।

---

## ভিতরে কিছু ধরে না এমন বস্তু বানানো

```ts
import { boxObject, createNabiWith, insertLump, type Command, type Wing } from 'nabi-note'
import 'nabi-note/nabi.css'

const insertStar: Command = (doc, sel, _args, env) => {
  const r = insertLump(doc, sel.focus, { w: 'star', ch: [] }, env)
  return { doc: r.doc, selection: { anchor: r.caret, focus: r.caret } }
}

const starWing: Wing = {
  ...boxObject({
    w: 'star',
    toHtml: (_node, _children, ctx) => ctx.element('hr', '', { 'data-nabi-star': '' }),
  }),
  commands: { insertStar },
  button: {
    group: 'insert',
    label: { bn: 'তারা', en: 'Star' },
    action: { kind: 'command', command: 'insertStar' },
  },
}
```

`insertLump` নিজেই র‍্যাপার অনুচ্ছেদ পরিয়ে দেয়।

```
<div data-nabi-p><hr data-nabi-star/></div>
```

খালি অনুচ্ছেদের উপর থেকে ডাকলে **সেই অনুচ্ছেদটিকেই বদলে নেয়** — প্রতিবার
বসালে খালি লাইন একটা একটা করে জমে না। আর সেই অনুচ্ছেদে যে সারিবদ্ধতা আগে
থেকে ছিল তা টিকে থাকে।

`boxObject` যা ভরে দেয় তা দুটো — `place: 'void'` আর **অ্যাট্রিবিউট
যাচাইকারী**।

```ts
boxObject({
  w: 'stamp',
  attrs: { c: (v) => (v === 'red' || v === 'blue' ? v : null) },   // তালিকার বাইরের মান বাদ যায়
  requires: ['c'],                                                 // না থাকলে এই বস্তু দাঁড়ায় না
  toHtml: /* … */,
})
```

`attrs`-এ না লেখা অ্যাট্রিবিউট **অচেনা ঘর বলে গোটাই বাদ পড়ে।** চুক্তির
বাইরের মান সংরক্ষিত মানে চুপিসারে বসার কোনো জায়গা নেই।

## ভিতরে লেখা থাকা বস্তু বানানো

`place: 'container'`-এর সঙ্গে `holds` অবশ্যই লিখতে হয় — না লিখলে নিবন্ধন
ভেঙে পড়ে।

```ts
import { createNabiWith, toggleWrap, type Command, type Wing } from 'nabi-note'

const toggleNote: Command = (doc, sel, _args, env) => {
  const r = toggleWrap(doc, sel, 'note', env)
  return { doc: r.doc, selection: { anchor: r.caret, focus: r.caret } }
}

const noteWing: Wing = {
  w: 'note',
  place: 'container',
  holds: 'blocks',                  // ভিতরে অনুচ্ছেদ থাকে ('inline' হলে কেবল লেখা)
  allows: ['p'],                    // এর ভিতরে ঢুকতে পারে এমন জিনিস
  toHtml: (_node, children, ctx) => ctx.element('aside', children(), { 'data-nabi-note': '' }),
  claim: (el, inner) => (el.tag === 'aside' ? [{ w: 'note', ch: inner(true) }] : null),
  commands: { toggleNote },
  inputRules: [{ trigger: 'space', pattern: /^!$/, run: () => ({ name: 'toggleNote' }) }],
  button: {
    group: 'container',
    label: { bn: 'নোট', en: 'Note' },
    action: { kind: 'command', command: 'toggleNote' },
  },
}
```

`toggleWrap` একটি **টগল**। নির্বাচনের আওতায় পড়া সর্বোচ্চ-স্তরের ব্লকগুলোকে
এই পাত্রে মুড়ে দেয়, আর সবগুলো আগে থেকে মোড়া থাকলে ভিতরটা যথাস্থানে খুলে
দেয়।

```
মোড়ার আগে   [p"প্রথম লাইন", p"দ্বিতীয়"]
মোড়ার পরে    [p[ note[ p"প্রথম লাইন", p"দ্বিতীয়" ] ]]
আবার চাপলে   [p"প্রথম লাইন", p"দ্বিতীয়"]
```

### `holds`

| | ভিতরে যা থাকে | উদাহরণ |
|---|---|---|
| `'blocks'` | অনুচ্ছেদ আর অন্য বস্তু | উদ্ধৃতি·ভাঁজ·টেবিলের ঘর |
| `'inline'` | কেবল লেখা আর মার্ক | ভাঁজের সারাংশ-লাইন·কোড |

### `allows`

লিখলে **তার বাইরের কিছু ঢুকতে পারে না।** কোর নিজে থেকেই একটি গোছানো-যন্ত্র
জুড়ে দেয়, পেস্ট হোক বা সংরক্ষিত মান, তালিকার বাইরের যা কিছু তার খোলস খসিয়ে
ভিতরের লেখাটুকু অনুচ্ছেদ হিসেবে নামিয়ে দেয়।

না লিখলে সবই গ্রহণযোগ্য। `allows`-এ অচেনা নাম লিখলে **নিবন্ধনের মুহূর্তেই
ভেঙে পড়ে।**

## `parts` — বোতাম-বিহীন ভিতরের কাঠামো

টেবিলের সারি·ঘর, ভাঁজের সারাংশ-লাইনের মতো **একা দাঁড়াতে পারে না, টুলবার
বোতামও নেই** এমন কাঠামো অংশ হিসেবে ঘোষণা করা হয়।

```ts
const detailsWing: Wing = {
  w: 'details',
  place: 'container',
  holds: 'blocks',
  boolAttrs: ['o'],                                   // মান কেবল 1 — খোলা কি না
  parts: { summary: { holds: 'inline' } },            // সারাংশ-লাইন
  toHtml: /* … */,
  partHtml: { summary: /* … */ },                     // প্রতিটি অংশের নিজের জোড়া লাগানো থাকতেই হয়
  repair: repairDetails,
}
```

নিয়ম চারটি।

- অংশ থাকে **কেবল কন্টেইনারেই।** অন্য `place`-এ লিখলে নিবন্ধন ভেঙে পড়ে।
- প্রতিটি অংশের `partHtml` থাকতেই হয়। না থাকলে নিবন্ধন ভেঙে পড়ে।
- অংশের নাম wing-এর নাম বা অন্য অংশের নামের সঙ্গে মিলতে পারে না।
- অংশ গোছাতে হলে `partRepair`-এ অংশের নাম দিয়ে লিখতে হয়।

`StructureDecl` তিনটি নেয় — `holds` · `singleParagraph` · `boolAttrs`।

### `singleParagraph`

ভিতরটা **একটিমাত্র অনুচ্ছেদে বাঁধা**। টেবিলের ঘর এমনই — ঘরের ভিতরে
<kbd>Enter</kbd> চাপলেও অনুচ্ছেদ দুই ভাগ হয় না, দুটো ঘর জুড়ে নির্বাচন করে
মুছলেও ঘর একসঙ্গে মিশে যায় না। গ্রিড রক্ষা করে এই একটি ঘরই।

### `boolAttrs`

মান কেবল `1`-ই হয় এমন অ্যাট্রিবিউট — ভাঁজের `o` (খোলা), করণীয় তালিকার `ck`
(টিক), অনুচ্ছেদের `dc` (ড্রপ ক্যাপ)। বন্ধ অবস্থা `0` নয় — **ঘরটাই আদৌ
থাকে না।**

## `repair` — সংরক্ষিত মানের প্রবেশদ্বারের শেষ দরজা

`repair` **JSON নথি হয়ে ওঠার ঠিক আগে** এই নোডটি একবার গুছিয়ে দেয়।

```ts
repair: (node) => {
  if (!isValid(node)) return null    // null — এই নোড খোলসসহ সরে যায়
  return fixedNode                   // যেমন ছিল তেমনই রাখলেও চলে (একই অবজেক্ট ফিরিয়ে দিলে কিছুই বদলায় না)
}
```

হাতে ঠিক করা সংরক্ষিত মান, অন্য সংস্করণ থেকে আসা নথি, অন্যের বানানো JSON —
সবই এই দরজা দিয়ে যায়। এখানে পার হওয়াটাই কেবল নথি হয়ে ওঠে, তাই **নিজের
নোডের রূপের নিশ্চয়তা wing নিজেই দিতে পারে এমন একমাত্র জায়গা** এটি।

`allows` আর `repair` দুটোই লিখলে `allows`-এর গোছানো **আগে** চলে আর তার
ফল `repair`-এ যায়।

## `requiresAnyOf` — জোড় লাগলেই দাঁড়ায় এমন wing

```ts
requiresAnyOf: ['img', 'a']
```

এদের একটিও সঙ্গে নিবন্ধিত না থাকলে **নিবন্ধনের মুহূর্তেই ভেঙে পড়ে।**
আপলোড wing এটি ব্যবহার করে — আপলোড হওয়া জিনিস ছবি বা লিঙ্ক হিসেবে দাঁড় করাতে
হয়, দুটোর একটাও না থাকলে আপলোড করে কিছুই করা যায় না।

## অনুচ্ছেদ-অ্যাট্রিবিউট (`place: 'attr'`)

অনুচ্ছেদ-অ্যাট্রিবিউট কোনো নোড বানায় না। অনুচ্ছেদের `a`-তে কেবল একটি মান
বসায়।

```json
{ "w": "p", "a": { "h": 2, "a": "c" }, "ch": ["মাঝে-সারিবদ্ধ শিরোনাম ২"] }
```

::: warning ঘর তিনটিতেই আটকানো
`attrKey` অবশ্যই **`h` (শিরোনাম) · `a` (সারিবদ্ধতা) · `dc` (ড্রপ ক্যাপ)**
তিনটির একটি হতে হবে, অন্য নাম লিখলে নিবন্ধন ভেঙে পড়ে। এই সংস্করণে **নতুন
অনুচ্ছেদ-অ্যাট্রিবিউট বানানো যায় না** — অনুচ্ছেদের অ্যাট্রিবিউট-ঘর কোরের
চেনা তিনটিতেই বন্ধ।

একই কারণে এই তিনটি ইতিমধ্যে `headingWing`·`alignWing`·`dropCapWing` দখল
করে রেখেছে, তাই `place: 'attr'` নতুন wing লেখার জায়গা কার্যত নেই। প্রতিটি
অনুচ্ছেদে মান বসাতে চাইলে এখন কন্টেইনার দিয়ে মোড়ার পথই বাছুন।
:::

মান নিয়ে কাজ করার ঘর দুটি।

| | |
|---|---|
| `attrValues` | গ্রহণযোগ্য মানের তালিকা (শিরোনাম হলে `[1,2,3,4,5,6]`) |
| `currentValue` | এই অনুচ্ছেদ এখন যে মান ধরে আছে। টুলবার·কনটেক্সট সারি এই উত্তর দিয়ে চাপা ঘর রাঙায় |

## প্রকাশিত নথি-সহায়ক

এই সংস্করণ বাইরে দিয়েছে এমন সম্পাদনা-সহায়ক চারটি।

| | কী করে |
|---|---|
| `insertLump(doc, caret, lump, env, wrap?)` | একটি বস্তু র‍্যাপার অনুচ্ছেদসহ দাঁড় করায় |
| `removeLump(doc, topIndex, env)` | সর্বোচ্চ-স্তরের একটি র‍্যাপার অনুচ্ছেদ গোটাই সরিয়ে দেয় |
| `toggleWrap(doc, sel, containerW, env)` | আওতায় পড়া ব্লকগুলো পাত্রে মোড়ে বা খোলে |
| `topNodeAt(doc, path)` | এই পথ যে সর্বোচ্চ-স্তরের নোডের ভিতরে তা ফিরিয়ে দেয় |

চারটিই `{ doc, caret }` ফিরিয়ে দেয়, তাই কমান্ডের উত্তরের রূপে একবার সরিয়ে
নিতে হয়।

```ts
return { doc: r.doc, selection: { anchor: r.caret, focus: r.caret } }
```

::: tip আরও সূক্ষ্ম সম্পাদনা লাগলে
অক্ষর-স্তরে কাটা-জোড়ার ভিতরের সহায়ক (মার্ক বসানো, অনুচ্ছেদ-অ্যাট্রিবিউট
লেখার মতো) এখনও প্রকাশিত API নয়। ততদিন `doc` অ্যারে নিজে হাতে নতুন করে
