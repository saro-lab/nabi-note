# সারিবদ্ধতা

## বিবরণ

`alignWing` (id `align`) **একাই** বাঁয়ে·মাঝে·ডানে তিনটে ধরে রাখে। টুলবারের
কাছে এটি একটি কনস্ট্যান্ট — একসঙ্গে বাঁধা কোনো `align()` ফ্যাক্টরি নয়, বরং
প্রতিটি মানের জন্য আলাদা বোতাম। ব্লকে `data-nabi-align` অ্যাট্রিবিউট বসায়।

- ট্যাগ যেমন আছে তেমনই থাকে, কেবল অ্যাট্রিবিউট বসে — এটি একটি **ব্লক
  অ্যাট্রিবিউট**। `<p data-nabi-align="center">`-এর মতো অনুচ্ছেদ নিজে
  বদলায় না।
- **অনুচ্ছেদ আর শিরোনাম দুটোতেই কাজ করে।** `<h2 data-nabi-align="c">`-ও
  চলে — শিরোনামও তো একটি সাধারণ লাইনই। চারটি অনুচ্ছেদ-অ্যাট্রিবিউটের মধ্যে
  কেবল সারিবদ্ধতাই এমন, আকার·ফন্ট·ড্রপ ক্যাপ এখনও কেবল অনুচ্ছেদেই সীমাবদ্ধ।
- একবারে একটি মানই বসতে পারে — বাঁয়ে-সারিবদ্ধ বসানো অবস্থায় মাঝে চাপলে বাঁয়ে
  খসে গিয়ে মাঝে বসে। যে মান বসানো আছে সেটিতেই আবার চাপলে অ্যাট্রিবিউটটাই
  গোটা খসে যায় (ডিফল্ট সারিবদ্ধতায় ফিরে আসে)।
- **Enter সারিবদ্ধতা দুই দিকেই যেমন আছে তেমনই বহন করে।** অনুচ্ছেদ ভাগ হলে
  দুই অনুচ্ছেদই একই সারিবদ্ধতা নিয়ে বেরোয় — শিরোনাম (`h`) খালি দিকে খসে যায়
  আর ড্রপ ক্যাপ (`dc`) কেবল এক দিকে যায়, তার মতো সারিবদ্ধতার কোনো ব্যতিক্রম
  নেই।
- তিনটি একই wing-এর **তিনটি বোতাম** (`buttons`) — আলাদা করে বন্ধ-চালু করা
  যায় না, `alignWing` একটিমাত্রই wings অ্যারেতে দিতে হয়।
- **টেবিল·ছবি·YouTube-এর জায়গাও এই wing-ই ঠিক করে।** বস্তু তাকে ধরে রাখা
  র‍্যাপার অনুচ্ছেদের ভিতরে থাকে, আর সারিবদ্ধতা বহন করে সেই অনুচ্ছেদই — তাই
  "মাঝে-সারিবদ্ধ ছবি" মানেই "মাঝে-সারিবদ্ধ অনুচ্ছেদের ভিতরের ছবি"। তাই
  ছবি·টেবিলের কনটেক্সট সারিতে সারিবদ্ধতার ঘরই থাকে না, আর বস্তুর উপর ক্যারেট
  থাকলেও একমাত্র সারিবদ্ধতাই টুলবার থেকে লুকায় না।

## ব্যবহারের উদাহরণ

```ts
import { createNabiWith, mountSurface, mountToolbar, alignWing } from 'nabi-note'
import 'nabi-note/nabi.css'

const surface = document.querySelector<HTMLElement>('#editor')!

const { nabi, registry } = createNabiWith([alignWing])

mountSurface({ nabi, registry, root: surface })
mountToolbar({ nabi, registry, surface, root: document.querySelector<HTMLElement>('#toolbar')! })

```
