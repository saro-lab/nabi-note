# ভাসমান অঞ্চল

ছোট বিবরণ, ছবি বা ছোট টেবিল বাঁ বা ডানে রাখুন, যাতে মূল লেখা তার পাশ দিয়ে প্রবাহিত হয়। একই সম্পাদকে অঞ্চলের বিষয়বস্তু সরাসরি বদলানো যায়। ড্যাশযুক্ত সীমানা শুধু সম্পাদনার সময় দেখায়; পূর্বরূপ ও প্রকাশিত দৃশ্যে শুধু বিষয়বস্তু ও বিন্যাস থাকে।

নিচের উদাহরণে অঞ্চলের ভেতরে কার্সর রেখে বৈশিষ্ট্য সরঞ্জাম দিয়ে পাশ ও সর্বোচ্চ প্রস্থ বদলান। পূর্বরূপে ড্যাশযুক্ত সীমানা ছাড়াই মূল লেখার প্রবাহ দেখতে পাবেন।

```ts
const selected = wings().allBasic().build()
```

ভাসমান অঞ্চল মৌলিক wing-এর অন্তর্ভুক্ত। শুধু দরকারি wing দিয়ে তৈরি করলে `wings().use('float')` ব্যবহার করুন বা সরাসরি `floatWing` নিবন্ধন করুন। অঞ্চলে ব্যবহৃত ছবি, টেবিল, তালিকা ইত্যাদির wing-ও নিবন্ধন করতে হবে।

## তৈরি ও অবস্থান নির্ধারণ

মূল লেখায় কার্সর রেখে **ভাসমান অঞ্চল** বোতাম চাপলে খালি অঞ্চল তৈরি হয়। মূল সেটিং হলো ডান পাশ এবং সর্বোচ্চ 40% প্রস্থ। কয়েকটি অনুচ্ছেদ বেছে চাপলে নির্বাচনে ছোঁয়া পুরো অনুচ্ছেদগুলো একটি অঞ্চলে যুক্ত হয়। বিদ্যমান ভাসমান অঞ্চলকে আবার মোড়ানো বা তার ভেতরে আরেকটি ভাসমান অঞ্চল তৈরি করা যায় না।

```ts
nabi.applyCommand('insertFloat', { side: 'right', w: 40 })
```

অঞ্চলের ভেতরে কার্সর থাকলে বৈশিষ্ট্য সরঞ্জাম দিয়ে বাঁ বা ডান পাশ এবং সর্বোচ্চ প্রস্থ বদলান। সর্বোচ্চ প্রস্থ হিসেবে 20%, 30%, 40% বা 50% বাছুন। এটি পুরো পর্দার নয়, মূল লেখার প্রস্থের অনুপাতে; বিষয়বস্তু ছোট হলে অঞ্চল আরও সরু হতে পারে।

```ts
nabi.applyCommand('setFloatSide', { side: 'left' })
nabi.applyCommand('setFloatWidth', { w: 30 })
```

লেখা, ছবি বা টেবিল পেস্ট করা, ব্লক বদলানো এবং আপলোড অঞ্চলের ভেতরেই থাকে। ভেতরের টেবিল মুছলে শুধু টেবিলটি যায়। অঞ্চলের ভেতর ও বাইরে একসঙ্গে বাছা থাকলে ভেতরের ব্লক যোগ বা রূপান্তর করা যায় না।

প্রস্থের মানের পাশের **ভাসমান অঞ্চল খুলুন** বোতাম বিষয়বস্তু না মুছে মূল লেখায় ফিরিয়ে দেয়। তৈরি, অবস্থান বদলানো ও অঞ্চল খোলা—সবই পূর্বাবস্থায় ফেরানো এবং পুনরায় করা যায়।

```ts
nabi.applyCommand('unwrapFloat')
```

## মূল লেখার সঙ্গে প্রবাহ

পরের অনুচ্ছেদগুলো অঞ্চলের পাশ দিয়ে যায় এবং অঞ্চল শেষ হলে মূল লেখার পুরো প্রস্থে ফিরে আসে। পরের শিরোনাম, টেবিল, কোড, বিভাজক বা নতুন ভাসমান অঞ্চল আগের অঞ্চলের নিচে শুরু হয়।

মূল লেখার প্রস্থ `36rem`-এর কম হলে অঞ্চল ও মূল লেখা এক কলামে থাকে। মুদ্রণের সময়ও এক কলাম হয়, তবে সংরক্ষিত পাশ ও সর্বোচ্চ প্রস্থ বজায় থাকে। নথি তুলনার দৃশ্যে প্রতিটি অঞ্চলের পাশ ও সর্বোচ্চ প্রস্থ থাকে, তবে পরিবর্তন সহজে পড়ার জন্য পরের ব্লক আলাদা করে নিচে দেখায়।

## সংরক্ষণ ও লোড

JSON-এ `float` নোডের `a.side`, `a.w` এবং ভেতরের ব্লক একসঙ্গে সংরক্ষিত হয়। HTML-এ সাধারণ অবজেক্ট অনুচ্ছেদের ভেতরের `div`-এ `data-nabi-float` ও `data-nabi-float-width` বৈশিষ্ট্য ব্যবহৃত হয়।

```html
<div data-nabi-p>
  <div data-nabi-float="right" data-nabi-float-width="40">
    <p>মূল লেখার পাশে রাখার জন্য একটি বিবরণ।</p>
  </div>
</div>
<p>এই অনুচ্ছেদটি অঞ্চলের পাশ দিয়ে এগিয়ে যায়।</p>
```

Markdown-এ রপ্তানি করলে অঞ্চল HTML হিসেবে থাকে। ইচ্ছেমতো CSS `float` স্টাইল আমদানি হয় না, তাই সংরক্ষণ ও পুনরুদ্ধারে NABI NOTE-এর তৈরি JSON বা HTML ব্যবহার করুন। পাশ ও প্রস্থ বজায় রাখতে সম্পাদক, SSR, পূর্বরূপ এবং প্রকাশিত দৃশ্যে একই wing ও CSS যুক্ত করুন।

## CSS স্টাইল

অঞ্চলের ভেতরের রং ও ফাঁক `[data-nabi-float]` নির্বাচক দিয়ে সাজাতে পারেন। বাইরের অনুচ্ছেদ অবস্থান ও সর্বোচ্চ প্রস্থ নিয়ন্ত্রণ করে, তাই `float`, `display` বা প্রস্থ সরাসরি বদলাবেন না।

```css
.brand-note .nabi-content [data-nabi-float] {
  background: var(--nabi-soft);
  border-radius: var(--nabi-radius);
  padding: .75rem;
}
```
