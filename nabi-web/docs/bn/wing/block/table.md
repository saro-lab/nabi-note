# টেবিল

## বিবরণ

`tableWings` (নাম `table`, শর্টকাট `T`) `table > tr > td` কাঠামোর মালিক।

সারি (`tr`) আর ঘর (`td`) আলাদা করে নিবন্ধন করা হয় না — টেবিল wing `parts`
দিয়ে সঙ্গেই নিয়ে আসে বলে, টেবিল বাদ দিলে সারি·ঘরও একসঙ্গে বাদ পড়ে।

```ts
parts: {
  tr: { holds: 'blocks' },
  td: { holds: 'blocks', singleParagraph: true, boolAttrs: ['th'] },
}
```

ঘর `singleParagraph` হওয়াটাই গ্রিড রক্ষা করে — ঘরের ভিতরে <kbd>Enter</kbd>
চাপলেও অনুচ্ছেদ দুই ভাগ হয় না, দুটো ঘর জুড়ে নির্বাচন করে মুছলেও ঘর একসঙ্গে
মিশে যায় না।

বোতাম চাপলে টগল নয়, সারি×কলাম মাপের একটি গ্রিড (সর্বোচ্চ 8×8) ওঠে, আর বেছে
নেওয়া মাপের টেবিল ক্যারেটের জায়গায় বসে যায় আর ক্যারেট প্রথম ঘরে সরে আসে।

ক্যারেট টেবিলের ভিতরে থাকলে তবেই কনটেক্সট সারিতে কমান্ড ওঠে।

| ধরন | ঘর |
|---|---|
| সারি | উপরে সারি যোগ · নিচে সারি যোগ · সারি মুছুন |
| কলাম | বাঁয়ে কলাম যোগ · ডানে কলাম যোগ · কলাম মুছুন |
| মার্জ | মার্জ (একটিমাত্র টগল) |
| শিরোনাম | এই সারিকে শিরোনাম করুন · এই কলামকে শিরোনাম করুন (`<th>` হয়ে যায়) |
| সাজানো | সাজানো চালু/বন্ধ (দেখার পক্ষে কলাম সাজানো) |
| মুছুন | টেবিল মুছুন |

**মার্জ একটিমাত্র টগল** — দিক অনুযায়ী আলাদা বোতাম নয়। একাধিক ঘর বেছে চাপলে
একসঙ্গে জোড়া লাগে, জোড়া লাগা ঘরে ক্যারেট রেখে আবার চাপলে খুলে যায়।

**টেবিলের বাক্স বাঁয়ে·মাঝে·ডানে বসানোর ঘর এই সারিতে নেই।** টেবিলের জায়গা
টেবিল নয়, তাকে ধরে রাখা র‍্যাপার অনুচ্ছেদ বহন করে, তাই টুলবারের সারিবদ্ধতা
বোতামই সেই কাজ করে।

::: warning সাজানোর চিহ্ন আর মার্জ
সাজানো কেবল **একটিমাত্র চিহ্ন**। মার্জ করা টেবিলেও সম্পাদক এই চিহ্ন বসাতে
দেয়, আর মার্জ করলেই বসানো চিহ্ন খুলেও যায় না।

তবে **দেখার পক্ষ তা প্রত্যাখ্যান করে** — `attachTableSort` মার্জ করা ঘর
দেখা যাচ্ছে এমন টেবিলে আদৌ জোড়ে না। জোড়া লাগা সারি একসঙ্গে বাঁধা বলে
আবার সাজালে গ্রিড ভেঙে যায়। তাই মার্জ করা টেবিলে চিহ্ন থাকলেও কিছুই ঘটে
না।
:::

## প্রস্থ ঠিক করে বিষয়বস্তু

টেবিলে প্রস্থের কোনো সেটিং নেই। টেবিল **বিষয়বস্তু যতটুকু চায় ততটুকুই**
চওড়া হয়, আর জায়গার চেয়ে চওড়া হয়ে গেলে সেখানেই **পাশে স্ক্রল** করে — পাতা
ঠেলে সরে যায় না। মুড়ে রাখা কোনো `<div>`-ও নেই। সংরক্ষিত মানে বেরোয় কেবল
একটি `<table>`, আর তার গায়ে লাগে শুধু সারিবদ্ধতা (`data-nabi-align`) আর
সাজানোর চিহ্নটুকু।

## চলাচল ও নির্বাচন

`Tab`/`Shift+Tab` দিয়ে ঘরে ঘরে সরা যায় (টেবিলের শেষ প্রান্তে গেলে সেখানেই
থেমে থাকে)। ঘর কেবল ইনলাইনই ধরে রাখে, তাই Enter ঘরটিকে ভাঙে না, **সেই
ঘরের ভিতরেই লাইন বদলায়** — ভাঙতে গেলে গ্রিড ধরতে পারে না এমন ব্লক বানাতে
হতো বলেই। অ্যারো কী পর্দা ধরে নয়, গ্রিড ধরে নড়ে।

মাউস দিয়ে একাধিক ঘর জুড়ে টেনে নির্বাচন করা যায়। এই টেনে-নির্বাচনও wing
নিজেই `attach` দিয়ে ধরে রাখে — **আলাদা করে mount করার কিছু নেই**,
`mountSurface` একসঙ্গেই জুড়ে দেয়।

## ব্যবহারের উদাহরণ

```ts
import { createNabiWith, mountSurface, mountToolbar, mountContextToolbar, tableWings } from 'nabi-note'
import 'nabi-note/nabi.css'

const surface = document.querySelector<HTMLElement>('#editor')!

const { nabi, registry } = createNabiWith([...tableWings])

mountSurface({ nabi, registry, root: surface })
mountToolbar({ nabi, registry, surface, root: document.querySelector<HTMLElement>('#toolbar')! })
mountContextToolbar({ nabi, registry, surface, root: document.querySelector<HTMLElement>('#context')! })

```
