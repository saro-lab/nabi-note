# বুলেট তালিকা

## বিবরণ

`bulletListWing` (নাম `ul`, শর্টকাট `L`) `<ul>`-এর মালিক। আইটেম `parts`-এর
মাধ্যমে সঙ্গেই আসে বলে `li` আলাদা করে নিবন্ধন করতে হয় না — এটি অ্যারে নয়,
একটি রেকর্ড।

```ts
parts: { li: { holds: 'blocks' } }
```

বোতাম চাপলে ক্যারেট যে ব্লকে আছে (বা নির্বাচনের আওতায় পড়া ব্লকগুলো) সেটিকে
তালিকায় মুড়ে দেয়, আর আবার চাপলে খুলে গিয়ে অনুচ্ছেদে ফিরে আসে। অন্য তালিকা বোতাম
চাপলে সেই ধারায় পাল্টে যায়।

লাইনের শুরুতে একটি হাইফেন লিখে স্পেস চাপলেও (`- `) একই ফল। **খালি লাইন থাকার
দরকার নেই** — যা মাপা হয় তা শুধু ক্যারেটের আগের লাইন-শুরুটুকু, তাই `- পরের লেখা`
তেও স্পেস চাপলে ধরা পড়ে আর পরের লেখা আইটেমের ভিতরেই থেকে যায়। তবে এটি ধরা পড়ে
কেবল অনুচ্ছেদের **প্রথম লাইনে**।

- `Tab` ঠিক উপরের সহোদর আইটেমের অধীনে এক ধাপ ভিতরে সরায়। প্রথম আইটেমের কোনো
  জায়গা নেই বলে কিছুই ঘটে না — তালিকার ভিতরে `Tab` স্পেস বসায় না।
- `Shift+Tab` মূলের পরের সহোদর হিসেবে বাইরে আনে — শীর্ষস্তরে দাঁড়িয়ে বাইরে আনলে
  তালিকা থেকে বেরিয়ে অনুচ্ছেদ হয়ে যায়। একাধিক আইটেম জুড়ে নির্বাচন করা থাকলে
  আওতায় পড়া সবগুলোই একসঙ্গে নড়ে।
- **খালি আইটেমে Enter চাপলে সেটি বাইরে আনা।** শীর্ষস্তরে থাকলে তালিকা সেখানেই
  শেষ হয় আর ক্যারেট তার নিচের নতুন অনুচ্ছেদে গিয়ে বসে। তালিকা শেষ করার পথ এটিই।
- **আইটেমের একদম শুরুতে Backspace চাপলে আগের আইটেমের সঙ্গে মিশে যায়।** মেশানোর
  মতো আগের আইটেম না থাকলে বাইরে আনায় নেমে আসে। আইটেমের একদম শেষে Delete চাপলে
  উল্টো — পরের আইটেমকে টেনে আনে।
- আইটেমের ভিতরটা ব্লক বলে একটি অনুচ্ছেদ এক স্তর ভেতরে বসে। মার্ক (গাঢ় ইত্যাদি)
  আর অন্য ইনলাইন wing সেই অনুচ্ছেদের ভিতরে যথারীতি ব্যবহার করা যায়।
- ট্যাগের গায়ে থাকা `type`-এর মতো অ্যাট্রিবিউট টিকে থাকে না। তালিকার ভিতরে
  আইটেম নয় এমন কিছু এলে বাদ না দিয়ে একটি আইটেমে মুড়ে নেওয়া হয়।
- চেকলিস্টের সঙ্গে ট্যাগ (`<ul>`) ভাগাভাগি করলেও এরা ভিন্ন wing — চিহ্ন-অ্যাট্রিবিউট
  দিয়ে আলাদা হয় (`data-nabi-list="task"` থাকলে সেটি চেকলিস্ট)।

## নেস্টিং সত্যিকারের মার্কআপ

কাঠামো সংরক্ষিত মানে ঠিক তেমনই থেকে যায়। তবে **আইটেম লেখা নয়, ব্লক ধরে রাখে**
বলে লেখা একটি অনুচ্ছেদ পরে যায় আর নেস্ট করা তালিকা একটি র‍্যাপার অনুচ্ছেদের
ভিতরে বসে।

```html
<li><p>ক</p><div data-nabi-p><ul><li><p>খ</p></li></ul></div></li>
```

## ব্যবহারের উদাহরণ

```ts
import { createNabiWith, mountSurface, mountToolbar, bulletListWing } from 'nabi-note'
import 'nabi-note/nabi.css'

const surface = document.querySelector<HTMLElement>('#editor')!

const { nabi, registry } = createNabiWith([bulletListWing])

mountSurface({ nabi, registry, root: surface })
mountToolbar({ nabi, registry, surface, root: document.querySelector<HTMLElement>('#toolbar')! })

// nabi.onChange(() => user_callback(nabi.getHtml()))
```

`li` যেহেতু `parts`-এর মাধ্যমে আপনা থেকেই সঙ্গে আসে, তাই সেটি অ্যারেতে সরাসরি
দেওয়া হয় না।
