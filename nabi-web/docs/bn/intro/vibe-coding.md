# AI ভাইব কোডিং

**`llms.txt`** হলো একটা নিয়ম, যা দিয়ে ওয়েবসাইট AI এজেন্ট(LLM)-কে নিজের বিষয়বস্তু
হাতে ধরিয়ে দেয়। HTML-এর বদলে, এজেন্ট সরাসরি পড়তে পারে এমন মার্কডাউনে প্রজেক্টের
গঠন আর ব্যবহারের নিয়ম লেখা থাকে। পুরো নিয়ম আছে [llmstxt.org](https://llmstxt.org/)-এ।

এই সাইটও সেই দরজা খুলে রেখেছে। ঠিকানা মুখস্থ করার দরকার নেই — নিচের উদাহরণের মতো
**এজেন্টকে ঠিকানাটা দিয়ে দিলেই** বাকিটা এজেন্ট নিজেই অনুসরণ করে।

```
https://nabi.saro.me/llms.txt
```

Cursor, Claude Code, OpenAI Codex, Windsurf ইত্যাদি llms.txt স্ট্যান্ডার্ড সমর্থন করে।

## প্রথমবার বসানোর সময়

যে সাইট এখনো nabi-note ব্যবহার করে না, সেখানে প্রথম নিয়ে আসার সময় — কী কী চালু
রাখতে চান, লাইট/ডার্ক মোড আছে কিনা, আর কোন পথে চালাবেন সেটা একবারে বলে দিলে বাকিটা
এজেন্ট নিজেই জুড়ে নেবে। **নিচের তিনটার মধ্যে শুধু শেষ বাক্যটাই বদলায়**, বাকি বাক্যগুলো
একই থাকে।

### npm + সার্ভার রেন্ডারিং (SSR) — প্রতিটা রিকোয়েস্টে সার্ভারে (Node) এঁকে পাঠানোর ক্ষেত্রে

নিজের হাতে বানানো Node ব্যাকএন্ড হোক, বা Next.js·Nuxt·SvelteKit-এর মতো SSR ফ্রেমওয়ার্ক —
দুটোই এখানে পড়ে। দুটোতেই প্রতিটা রিকোয়েস্টে Node-এর উপর নথি এঁকে পাঠানো হয়, এটাই এক।

```
আমাদের সাইটে নতুন এডিটর হিসেবে nabi-note আনতে চাই। ম্যানুয়াল হিসেবে
https://nabi.saro.me/llms.txt দেখো। আমাদের সাইটে লাইট/ডার্ক মোড আছে, এডিটরও
সেটার সঙ্গে মিলিয়ে নিও। ডিফল্টে যত wing আসে সবগুলো চালু করে দিও।

আমরা Nuxt দিয়ে সার্ভার রেন্ডারিং করি, আর কেউ পাতায় ঢোকার সঙ্গে সঙ্গেই লেখা
দেখা যাক এটা চাই। npm দিয়ে ইনস্টল করে SSR আর hydrate দিয়ে জুড়ে দিও।
```

### npm + শুধু ব্রাউজারে জোড়া (CSR) — বান্ডলার আছে কিন্তু সার্ভার রেন্ডারিং লাগবে না

```
আমাদের সাইটে নতুন এডিটর হিসেবে nabi-note আনতে চাই। ম্যানুয়াল হিসেবে
https://nabi.saro.me/llms.txt দেখো। আমাদের সাইটে লাইট/ডার্ক মোড আছে, এডিটরও
সেটার সঙ্গে মিলিয়ে নিও। ডিফল্টে যত wing আসে সবগুলো চালু করে দিও।

এটা Vite দিয়ে বানানো ফ্রন্টএন্ড, সার্ভার রেন্ডারিং লাগবে না। npm দিয়ে ইনস্টল
করে শুধু ব্রাউজারেই জুড়ে দিও।
```

### CDN — বিল্ড টুল ছাড়া স্ট্যাটিক পাতা

```
আমাদের সাইটে নতুন এডিটর হিসেবে nabi-note আনতে চাই। ম্যানুয়াল হিসেবে
https://nabi.saro.me/llms.txt দেখো। আমাদের সাইটে লাইট/ডার্ক মোড আছে, এডিটরও
সেটার সঙ্গে মিলিয়ে নিও। ডিফল্টে যত wing আসে সবগুলো চালু করে দিও।

এই পাতায় কোনো বিল্ড টুল নেই, এটা স্ট্যাটিক HTML। `<script>` ট্যাগ দিয়ে জুড়ে দিও।
```

::: tip লাইট·ডার্ক নিয়ে আলাদা করে বলার কিছু নেই
`nabi.css`-এর মধ্যে লাইট ডিফল্ট, `.dark` override, আর স্পষ্ট `.light` override —
তিনটাই আগে থেকে আছে। পাতার `dark`/`light` ক্লাস যেমন আছে থাকতে দিলে এডিটর নিজেই
সেটা অনুসরণ করবে। ব্র্যান্ডের রং বদলাতে চাইলে এজেন্টকে `llms/styling.md`-ও পড়াতে বলুন।
:::

তিনটা উদাহরণের শেষ বাক্যটাই আলাদা — এজেন্ট এই তিনটা মতো করে `llms/ssr.md`
(সাথে `llms/quickstart-npm.md`) · `llms/quickstart-npm.md` · `llms/quickstart-cdn.md`
খুঁজে পড়ে সেই পথে জুড়ে দেয়।

## ফিচার বদলানো, যোগ করা, বা বাদ দেওয়ার সময়

nabi-note একবার বসে গেলে, তাতে কিছু বদলাতে বা যোগ করতে চাইলে — **সরাসরি বানাতে
বলার আগে প্রথমে খোঁজ করে একটা প্ল্যান বানাতে বলা** নিরাপদ, বিশেষ করে যেটার সঙ্গে
ব্যাকএন্ড জড়িত, সেখানে আগে থেকে কী তৈরি রাখতে হবে জানা দরকার।

### উদাহরণ — আগে খোঁজ আর প্ল্যান

```
আপলোড ফিচার যোগ করতে চাই। https://nabi.saro.me/llms/wings.md আর
https://nabi.saro.me/llms/api-reference.md দেখে, upload wing চালু করতে
আমাদের ব্যাকএন্ডে কী লাগবে (ফাইল নেওয়ার ঠিকানা, কোন এক্সটেনশন·কত সাইজ পর্যন্ত
চলবে, ব্যর্থ হলে জবাব কেমন হবে) সেটা আগে খুঁজে বের করো। এখনই বানিয়ে ফেলো না —
কী তৈরি রাখতে হবে সেটার একটা প্ল্যান দেখাও।
```

এজেন্ট `llms/wings.md`-এ দেখবে `upload` একটা টুল(tool) wing যা `Uploader` নেয়,
আর `llms/api-reference.md`-এ `mountUpload`·`Uploader`·`allowLocalUrls`-এর আসল
সিগনেচার মিলিয়ে নিয়ে, ব্যাকএন্ডে কী খুলতে হবে আর ফ্রন্টএন্ড নিজে কী ঠিক করবে —
এই দুটো আলাদা করে একটা প্ল্যানে সাজিয়ে দেখাবে। প্ল্যানটা দেখে ঠিক মনে হলে তারপর
বানাতে বলুন।

### সহজ উদাহরণ — সরাসরি বলে দেওয়া যায় এমন

প্ল্যান লাগবে না এমন ছোট বদলের জন্য সরাসরি বলে দেওয়াই যায়।

```
https://nabi.saro.me/llms/styling.md দেখে শুধু accent রং আর ডার্ক থিমের
ব্যাকগ্রাউন্ড আমাদের ব্র্যান্ডের রঙে বদলে দিও।
```

::: tip চুক্তি ভাঙা wing নিবন্ধনের সময়েই ছুঁড়ে ফেলা হয়
এজেন্টকে নতুন wing বানাতে বললে, তাকে [`llms/custom-wing.md`](https://nabi.saro.me/llms/custom-wing.md)
-ও পড়াবেন। সংরক্ষিত শব্দ নামে ব্যবহার করা, বা নোড আঁকার wing-এ `toHtml` না থাকা —
এই সাধারণ ভুলগুলো পরে গিয়ে ধরা পড়ে না, **নিবন্ধনের মুহূর্তেই** ছুঁড়ে ফেলা হয়।
সেই নথির "নিবন্ধনের সেই জায়গাতেই মরে" অংশে কী কী ধরা পড়ে তার তালিকা আছে।
:::

::: tip একবার বসিয়ে দিলে, একটা লাইন রেখে দিন
প্রথমবার জুড়ে দেওয়ার পর, বারবার ঠিকানা মনে করিয়ে দেওয়ার দরকার নেই। প্রজেক্টের
নিয়ম ফাইলে (`CLAUDE.md`, `.cursorrules` ইত্যাদি) এভাবে একটা লাইন লিখে রাখলে,
"nabi-note দিয়ে ~করে দিও" বললেই এজেন্ট নিজে ঠিকানা খুঁজে নেবে।

```md
এই প্রজেক্টে এডিটর হিসেবে `nabi-note` ব্যবহার হয়। এই সংক্রান্ত কাজ করার আগে
https://nabi.saro.me/llms.txt দেখে নিন।
```
:::
