# การจัดแนว

จัดแนวย่อหน้าปัจจุบัน หรือย่อหน้าที่ครอบคลุมช่วงที่เลือก ให้ชิดซ้าย กึ่งกลาง หรือชิดขวา วัตถุที่อยู่ในย่อหน้า เช่น รูปภาพ วิดีโอ และตาราง จะถูกจัดแนวโดยอิงย่อหน้าที่ครอบวัตถุนั้น

การจัดแนวจะบันทึกเป็นคุณสมบัติของย่อหน้า ไม่ใช่รูปแบบอักขระ บล็อกโค้ดจะไม่อยู่ในการจัดแนว เพราะการเยื้องมีความหมายในตัวเอง

ภายในเซลล์ตาราง การจัดแนวใช้กับย่อหน้าหรือรูปภาพภายในที่เคอร์เซอร์อยู่ เมื่อลากเลือกหลายเซลล์ จะใช้กับทุกย่อหน้าและรูปภาพที่จัดแนวได้ในเซลล์เหล่านั้น หากส่วนที่เลือกมีการจัดแนวต่างกัน จะไม่มีปุ่มจัดแนวใดแสดงว่าเลือกอยู่

หากต้องการจัดแนวตัวตาราง ให้กด **เลือกทั้งตาราง** ในเครื่องมือตามบริบท หรือวางเคอร์เซอร์ก่อนหรือหลังตารางในย่อหน้าที่ครอบตาราง แล้วใช้ปุ่มจัดแนวบนแถบเครื่องมือหลัก ตำแหน่งซ้ายหรือขวาของพื้นที่ลอยต้องเปลี่ยนในเครื่องมือตามบริบทของพื้นที่นั้นแทนปุ่มจัดแนว

const selected = wings().use('align').build()

เมื่อต้องการใช้คำสั่งกับส่วนที่เลือกปัจจุบัน ให้ใช้ `l` สำหรับซ้าย `c` สำหรับกลาง และ `r` สำหรับขวา

```ts
nabi.applyCommand('setAlign', { value: 'c' })
```
