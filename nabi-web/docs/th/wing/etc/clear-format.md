# ล้างการจัดรูปแบบ

ล้างการจัดรูปแบบอักขระในช่วงที่เลือกพร้อมกัน เครื่องหมายพื้นฐานที่ลงทะเบียนไว้ เช่น ตัวหนา สี และแบบอักษร รวมถึงคุณสมบัติย่อหน้า เช่น หัวเรื่อง การจัดแนว และอักษรตัวแรกขนาดใหญ่ จะถูกรวมอยู่ด้วย การกด Esc สองครั้งอย่างรวดเร็วก็ทำงานเดียวกันได้

การทำเช่นนี้จะไม่เปลี่ยนโครงสร้างเอกสาร เช่น รายการ ตาราง คำพูดอ้างอิง หรือรูปภาพ ให้เป็นข้อความธรรมดา การจัดแนวภายนอกของรูปภาพและวิดีโอ รวมถึงลิงก์ไฟล์แนบที่สร้างจากการอัปโหลด จะคงเดิม

<WingDemo path="/wing/etc/clear-format" />

```ts
const selected = wings()
  .use('b')
  .use('i')
  .use('clearFormat')
  .build()
```

ต้องเลือก wing ของรูปแบบที่ต้องการล้างไว้ด้วย จึงจะล้างรูปแบบนั้นได้
