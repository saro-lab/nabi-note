# อักษรตัวแรกขนาดใหญ่

วางอักษรตัวแรกของย่อหน้าให้มีขนาดใหญ่ แล้วให้บรรทัดที่เหลือไหลอยู่ข้าง ๆ นี่คือการจัดรูปแบบระดับย่อหน้า จึงไม่ใช้กับคำที่เลือกเพียงบางส่วน

มุมมองที่เผยแพร่และมุมมองแก้ไขจะมีรูปลักษณ์เดียวกัน ขณะแก้ไข อักษรตัวแรกจะถูกห่อด้วยองค์ประกอบจริง เพื่อไม่ให้ตำแหน่งเคอร์เซอร์และการลบคลาดเคลื่อน องค์ประกอบนี้ไม่รวมอยู่ในเนื้อหาเอกสารที่บันทึกไว้

## สไตล์ CSS

มุมมองที่เผยแพร่และมุมมองแก้ไขใช้ตัวเลือกคนละตัวสำหรับอักษรตัวแรก มุมมองที่เผยแพร่ใช้ `[data-nabi-dropcap="1"]::first-letter` ส่วนมุมมองแก้ไขใช้องค์ประกอบจริง `[data-nabi-dropcap-letter]` เมื่อเปลี่ยนค่าที่มองเห็นได้ เช่น สี แบบอักษร หรือขนาด ต้องเขียนทั้งสองตัวเลือกคู่กัน เพื่อให้ระหว่างแก้ไขและเมื่อเผยแพร่มีรูปลักษณ์เหมือนกัน

```css
.article-body:not(.nabi-editing) [data-nabi-dropcap="1"]::first-letter,
.nabi-content.nabi-editing [data-nabi-dropcap-letter] {
  color: var(--nabi-accent);
  font-family: var(--nabi-font-serif);
}
```

หากเปลี่ยนขนาดและความสูงบรรทัด ให้ใช้ค่าเดียวกันกับทั้งสองตัวเลือก

```css
.article-body:not(.nabi-editing) [data-nabi-dropcap="1"]::first-letter,
.nabi-content.nabi-editing [data-nabi-dropcap-letter] {
  font-size: 5.5em;
  line-height: .85;
}
```

อักษรตัวแรกขนาดใหญ่จะคำนวณการไหลของบรรทัดรอบอักษรตัวแรก ดังนั้นการเปลี่ยนเพียงด้านเดียวหรือทำให้ค่ามีขนาดใหญ่เกินไปอาจทำให้รูปลักษณ์ WYSIWYG เสียได้ ยังควรหลีกเลี่ยงการเพิ่มกฎ `::first-letter` ใหม่ให้กับตัวแก้ไข ในตัวแก้ไขให้จัดสไตล์เฉพาะ `[data-nabi-dropcap-letter]` ที่มีอยู่แล้ว
