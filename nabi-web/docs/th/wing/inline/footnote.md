# เชิงอรรถ

เชื่อมคำอธิบายเพิ่มเติมด้วยหมายเลขในเนื้อหาและรายการท้ายเอกสาร

ป้อนข้อความผ่านปุ่มเชิงอรรถบนแถบเครื่องมือเพื่อแทรกเชิงอรรถตรงเคอร์เซอร์ หากเลือกข้อความไว้ เชิงอรรถจะแทรกที่ท้ายส่วนที่เลือกโดยไม่แทนที่ข้อความ หมายเลขจะไม่ถูกบันทึก แต่จะกำหนดอัตโนมัติตามลำดับในเอกสาร

คลิกหมายเลขในเนื้อหาเพื่อแก้ไขข้อความในแถวคุณสมบัติ ใช้เครื่องมือลบ หรือกด Backspace หรือ Delete สองครั้งข้างเชิงอรรถเพื่อเลือกแล้วลบ รายการด้านล่างเป็นแบบอ่านอย่างเดียวและจะหายไปเมื่อไม่มีเชิงอรรถ

ในตัวอย่างและหน้าที่เผยแพร่ซึ่งเชื่อมต่อ viewer แล้ว ให้วางเมาส์เหนือหมายเลข คลิก หรือแตะเพื่ออ่านเนื้อหา รองรับข้อความธรรมดาเพียงบรรทัดเดียว โดยแสดงด้วยฟอนต์ไร้เชิงขนาด 0.875 เท่าของขนาดพื้นฐานของเนื้อหา HTML จะแสดงเป็นข้อความตามตัวอักษร
