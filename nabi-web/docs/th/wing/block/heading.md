# หัวเรื่อง

เปลี่ยนย่อหน้าเป็นหัวเรื่องและกำหนดระดับ เปิดหัวเรื่องจากแถบเครื่องมือแล้วเลือกตั้งแต่ H1 ถึง H6 หรือพิมพ์ `#` ถึง `######` แล้วกด Space ในย่อหน้าว่าง

หัวเรื่องไม่ใช่ชนิดบล็อกแยกต่างหาก แต่เป็นคุณสมบัติที่เก็บไว้ในย่อหน้า กดหัวเรื่องอีกครั้งเพื่อกลับเป็นย่อหน้าปกติ จึงเปลี่ยนเฉพาะระดับได้โดยรักษาโครงสร้างเนื้อหาไว้
