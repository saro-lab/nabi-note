# รายการลำดับเลข

สร้างรายการลำดับเลขสำหรับรายการที่ลำดับมีความสำคัญ พิมพ์ตัวเลขและจุด เช่น `1.` ในย่อหน้าว่างแล้วกด Space หรือเปลี่ยนย่อหน้าที่เลือกจากแถบเครื่องมือ

หมายเลขที่แสดงคำนวณจากตำแหน่งของรายการ จึงต่อเนื่องโดยอัตโนมัติแม้เพิ่มหรือเยื้องรายการ ไม่มีฟังก์ชันเก็บหมายเลขเริ่มต้นที่ป้อนเพื่อเริ่มนับจากหมายเลขใดก็ได้

Enter สร้างรายการถัดไป ส่วน Shift+Enter ขึ้นบรรทัดใหม่ภายในรายการปัจจุบันเท่านั้น Tab และ Shift+Tab ใช้เพิ่มและลดระยะเยื้อง แม้ในเซลล์ตาราง การเยื้องรายการก็มีลำดับก่อนการย้ายเซลล์
