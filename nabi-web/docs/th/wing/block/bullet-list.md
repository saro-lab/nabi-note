# รายการหัวข้อย่อย

เป็นรายการที่แสดงหลายรายการโดยไม่เรียงลำดับ ในย่อหน้าว่าง ให้พิมพ์ `-` แล้วกด Space หรือเปลี่ยนจากแถบเครื่องมือ คุณยังรวมย่อหน้าที่เลือกเป็นรายการได้ในครั้งเดียว

ภายในรายการ กด Tab เพื่อเยื้องเข้า 1 ระดับ และกด Shift+Tab เพื่อเยื้องออก Enter จะสร้างรายการถัดไป และถ้ากด Enter อีกครั้งบนรายการว่าง รายการจะสิ้นสุดลง
