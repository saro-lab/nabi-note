# เส้นคั่น

คือเส้นแนวนอนที่แบ่งลำดับของเอกสาร พิมพ์เครื่องหมายขีดกลางอย่างน้อยสามตัวในย่อหน้าว่างแล้วกด Enter หรือแทรกจากแถบเครื่องมือ

เส้นคั่นเป็นบล็อกอิสระที่ไม่มีข้อความ จึงไม่เก็บรูปแบบอย่างหัวเรื่องหรือสี ใช้เพื่อแบ่งย่อหน้าก่อนหน้าและถัดไปเท่านั้น
