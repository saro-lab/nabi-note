# รายการตรวจสอบ

เป็นรายการที่มีสถานะการเสร็จสิ้น พิมพ์ `[ ]` หรือ `[x]` แล้วกด Space ในย่อหน้าว่าง หรือสร้างจากแถบเครื่องมือ แล้วคลิกช่องทำเครื่องหมายเพื่อเปลี่ยนสถานะ

สถานะที่ทำเครื่องหมายจะถูกเก็บไว้ในเอกสารเป็นคุณสมบัติของรายการ เมื่อแยกรายการ สถานะจะตามรายการที่ยังมีข้อความ ไม่ใช่รายการก่อนหน้าที่ว่าง จึงไม่สลับสถานะแม้จะแยกงานที่เสร็จแล้วเป็นสองรายการ
