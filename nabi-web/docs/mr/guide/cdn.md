# CDN वापरणे

पॅकेज स्थापित करणे कठीण असलेल्या स्थिर पानावर तुम्ही CDN वरून NABI NOTE चे ब्राउझर बंडल आणि CSS लोड करू शकता. खालील उदाहरण बिल्डच्या वेळी पॅकेजची आवृत्ती आपोआप वाचून पत्ते तयार करते आणि ग्लोबल `NabiNote` ऑब्जेक्टने संपादक जोडते.

## NABI NOTE मध्ये तपासण्याच्या गोष्टी

- डिप्लॉयमेंट कोडमध्ये CSS आणि ब्राउझर JavaScript साठी तीच निश्चित आवृत्ती वापरा. `latest` सारखा आवृत्ती नसलेला पत्ता नवीन आवृत्ती प्रसिद्ध झाल्यावर वर्तन बदलू शकतो.
- ब्राउझर बंडल मूळ API `window.NabiNote` म्हणून देते. `nabi-note/ssr`, `nabi-note/viewer` आणि `nabi-note/diff` साठी स्वतंत्र ग्लोबल बंडल नाहीत.
- उदाहरणातील फाइल जतन करणे आणि स्थानिक इतिहास वापरकर्त्याच्या ब्राउझरमध्ये चालतात. सर्व्हर जतन किंवा खाते समक्रमण हवे असल्यास `getJson()` चा निकाल अनुप्रयोग API कडे पाठवा.
- अपलोड जोडताना फक्त `upload` wing नव्हे, तर प्रत्यक्ष पाठवण्याचे फंक्शन आणि आवश्यक image किंवा link wings जोडा. फाइल पडताळणीची जबाबदारी अपलोड सर्व्हरची आहे.
- ब्राउझर बंडल HTML parser आतून जोडते. त्यामुळे `setHtml()`, HTML फाइल उघडणे किंवा HTML चिकटवणे यासाठी स्वतंत्र parser पर्याय किंवा खाजगी API लागत नाही.

CDN फक्त लोड करण्याच्या पद्धतीत वेगळे आहे. जतनाचा फॉरमॅट आणि इनपुट पडताळणी npm ने स्थापित केल्याप्रमाणेच आहेत, म्हणून [मूलभूत वापर](/mr/guide/getting-started) देखील पहा.
