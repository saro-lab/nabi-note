# शीर्षक

परिच्छेदाचे शीर्षकात रूपांतर करून त्याची पातळीही ठरवा. साधनपट्टीत शीर्षक सुरू करून H1 ते H6 यांपैकी निवडा किंवा रिकाम्या परिच्छेदात `#` ते `######` नंतर Space दाबा.

शीर्षक हा स्वतंत्र ब्लॉक प्रकार नसून परिच्छेदावर साठवला जाणारा गुणधर्म आहे. शीर्षक पुन्हा निवडल्यास तो सामान्य परिच्छेद होतो, त्यामुळे मुख्य मजकुराची रचना कायम ठेवून फक्त पातळी बदलता येते.
