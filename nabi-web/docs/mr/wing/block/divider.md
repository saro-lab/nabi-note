# विभाजक

दस्तऐवजाचा प्रवाह विभागणारी ही आडवी रेषा आहे. रिकाम्या परिच्छेदात तीन किंवा अधिक हायफन लिहून Enter दाबा किंवा साधनपट्टीतून घाला.

विभाजक हा मजकूर नसलेला स्वतंत्र ब्लॉक असल्यामुळे त्यात शीर्षक किंवा रंग यांसारखे स्वरूप ठेवता येत नाही. तो फक्त त्याच्या आधीचे आणि नंतरचे परिच्छेद वेगळे करण्यासाठी वापरा.
