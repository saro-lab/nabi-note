# क्रमांकित सूची

क्रम महत्त्वाचा असलेले घटक क्रमांक सूचीत मांडते. रिकाम्या परिच्छेदात `1.` प्रमाणे अंकानंतर पूर्णविराम लिहून Space दाबा किंवा निवडलेले परिच्छेद साधनपट्टीतून बदला.

दिसणारे क्रमांक घटकाच्या स्थानावरून मोजले जातात. त्यामुळे घटक जोडले किंवा आत सरकवले तरी क्रमांक आपोआप पुढे सुरू राहतात. दिलेला प्रारंभ क्रमांक जतन करून हवा त्या क्रमांकापासून मोजण्याची सुविधा उपलब्ध नाही.
