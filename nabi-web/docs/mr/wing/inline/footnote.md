# तळटीप

मजकुरातील क्रमांक आणि दस्तऐवजाच्या शेवटची यादी यांद्वारे अतिरिक्त स्पष्टीकरण जोडा.

टूलबारमधील तळटीप बटणाने मजकूर दिल्यास कर्सरच्या जागी तळटीप जोडली जाते. मजकूर निवडलेला असल्यास तो न बदलता निवडीच्या शेवटी तळटीप घातली जाते. क्रमांक साठवले जात नाहीत; ते दस्तऐवजातील क्रमाने आपोआप दिले जातात.

मजकुरातील क्रमांकावर क्लिक करून गुणधर्मांच्या ओळीत मजकूर बदला. हटवण्याचे साधन वापरा किंवा तळटिपेशेजारी Backspace किंवा Delete दोनदा दाबून आधी निवडा आणि मग हटवा. खालची यादी फक्त वाचण्यासाठी असते आणि तळटीप नसल्यास दिसत नाही.

पूर्वावलोकनात आणि viewer जोडलेल्या प्रकाशित पानांवर क्रमांकावर माउस नेऊन, क्लिक करून किंवा टॅप करून मजकूर वाचता येतो. फक्त एका ओळीचा साधा मजकूर स्वीकारला जातो आणि तो मुख्य मजकुराच्या मूळ आकाराच्या 0.875 पट आकारात सॅन्स सेरिफ फॉन्टमध्ये दिसतो. HTML अक्षरशः मजकूर म्हणून दिसते.
