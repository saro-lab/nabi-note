# عنوان

یک بند را به عنوان تبدیل کنید و سطح آن را برگزینید. عنوان را در نوار ابزار فعال کنید و از H1 تا H6 را انتخاب کنید، یا در بند خالی `#` تا `######` و سپس Space را بنویسید.

عنوان نوع بلوک جداگانه‌ای نیست؛ به‌صورت یک ویژگی روی بند ذخیره می‌شود. زدن دوبارهٔ عنوان، آن را به بند معمولی بازمی‌گرداند؛ پس می‌توانید فقط سطح را عوض کنید و ساختار بدنه را دست‌نخورده نگه دارید.
