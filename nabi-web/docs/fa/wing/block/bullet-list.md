# فهرست نشانه‌دار

فهرست نشانه‌دار چند مورد را بی‌آن‌که ترتیبی داشته باشند نشان می‌دهد. در یک بند خالی `-` و سپس Space را بنویسید یا از نوار ابزار به آن بروید. بندهای انتخاب‌شده را هم می‌توان یک‌باره در فهرست گروه‌بندی کرد.

درون فهرست، Tab یک سطح تورفتگی می‌دهد و Shift+Tab آن را بیرون می‌آورد. Enter مورد بعدی را می‌سازد و زدن دوبارهٔ Enter روی مورد خالی، فهرست را پایان می‌دهد.
