# تصویر

نشانی تصویر را وارد کنید و عرض و هم‌ترازی آن را تنظیم کنید. به‌طور پیش‌فرض نشانی‌ها به `http:`، `https:` یا مسیرهای همان سایت محدودند و تصویر تازه با عرض ۶۰٪ در مرکز آغاز می‌شود.

عرض تنها در گام‌های ثابت ذخیره می‌شود و هم‌ترازی روی پاراگرافِ دربرگیرندهٔ تصویر ذخیره می‌شود. برای استفاده از پیش‌نمایش‌های `blob:` یا `data:image/...`، باید در wing تصویر و پیکربندی ویرایشگر صریحاً نشانی‌های محلی را مجاز کنید. نشانی‌های دادهٔ SVG مجاز نیستند.

<WingDemo path="/wing/block/image" />

```ts
const selected = wings().use('img', {
  allowLocalUrls: false,
}).build()
```

این wing یک نشانی را در سند وارد می‌کند؛ فایل‌ها را بارگذاری نمی‌کند. برای فرستادن فایل به سرور، [wing بارگذاری](/fa/wing/etc/upload) را متصل کنید.

## اتصال انتخابگر تصویر

با `panels.img` در `mountToolbar()` می‌توانید پنجرهٔ پیش‌فرض ورود URL دکمهٔ تصویر را با انتخابگر تصویر سرویس خود جایگزین کنید. کلیدها نام اسلات‌های نوار ابزار هستند؛ ابزارهایی که مشخص نشده‌اند پنجرهٔ پیش‌فرض خود را نگه می‌دارند.

```ts
import { mountToolbar } from 'nabi-note'

const toolbar = mountToolbar({
  nabi,
  registry,
  root: toolbarRoot,
  surface: content,
  panels: {
    img: ({ root, signal, run }) =>
      mountMyImagePicker(root, {
        signal,
        onSelect: (url: string) => run('insertImage', { src: url }),
      }),
  },
})
```

`mountMyImagePicker` تابعی است که در سرویس خود پیاده‌سازی می‌کنید. این تابع رابط دلخواه شما را به‌صورت همگام در `root` دریافتی می‌سازد و یک تابع پاک‌سازی برمی‌گرداند. `signal` را به کارهای ناهمگام مانند دریافت فهرست تصاویر یا بارگذاری فایل متصل کنید و URL تصویر انتخاب‌شده را به `onSelect` بدهید. این API فایل‌ها را منتقل نمی‌کند و قوانین فعلی URL تصاویر همچنان برقرار است.

با بستن پنجره یا برداشتن نوار ابزار، `signal` لغو و تابع پاک‌سازی اجرا می‌شود. `run()` پنجره را می‌بندد و فرمان را یک بار بر انتخاب ذخیره‌شده هنگام باز شدن اعمال می‌کند. اگر پنجره از قبل بسته شده باشد یا محتوای سند پس از باز شدن تغییر کرده باشد، بدون اجرای فرمان `false` برمی‌گرداند.

## سبک‌های CSS

تصاویر را با `.nabi-content img` سبک‌دهی کنید. عرض و هم‌ترازی ذخیره‌شده را دست‌نخورده نگه دارید و فقط جزئیات ظاهری مانند کادر یا سایه را تغییر دهید.

```css
.article-body img {
  border-radius: 12px;
  box-shadow: 0 8px 24px rgb(0 0 0 / 12%);
}

.dark .article-body img { box-shadow: 0 8px 24px rgb(0 0 0 / 35%); }
```

قواعد پیش‌فرض `max-inline-size`، `block-size`، عرض و هم‌ترازی را نگه دارید. اندازهٔ تصویر در سند ذخیره می‌شود؛ پس اجبارِ عرض ثابت در CSS می‌تواند با عرض انتخاب‌شده توسط نویسنده تداخل داشته باشد.
