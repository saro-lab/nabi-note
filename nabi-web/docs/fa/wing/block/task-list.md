# فهرست کارها

فهرستی با وضعیت انجام‌شدن. در یک بند خالی `[ ]` یا `[x]` و سپس Space را بنویسید یا آن را از نوار ابزار بسازید، سپس برای تغییر وضعیت روی خانهٔ انتخاب بزنید.

وضعیت تیک‌خورده همراه هر مورد در سند ذخیره می‌شود. وقتی موردی شکافته می‌شود، وضعیت با موردی می‌ماند که متن را نگه داشته است، نه مورد خالی پیش از آن؛ بنابراین شکافتن یک کار انجام‌شده ناخواسته وضعیتش را برعکس نمی‌کند.
