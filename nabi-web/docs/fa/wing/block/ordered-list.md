# فهرست شماره‌دار

مواردی را که ترتیبشان مهم است به فهرست شماره‌دار تبدیل کنید. در یک بند خالی، عدد و نقطه‌ای مانند `1.` را بنویسید و سپس Space را بزنید، یا بندهای انتخاب‌شده را از نوار ابزار تبدیل کنید.

شماره‌های نمایش‌داده‌شده از جایگاه موردها محاسبه می‌شوند؛ بنابراین با افزودن یا تورفتگی موردها خودکار ادامه می‌یابند. ذخیرهٔ یک شمارهٔ آغاز سفارشی و شمردن از آن فراهم نشده است.
