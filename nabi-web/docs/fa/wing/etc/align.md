# هم‌ترازی

پاراگراف کنونی یا پاراگراف‌های بازهٔ انتخاب‌شده را در چپ، مرکز یا راست هم‌تراز کنید. شیءهای درون پاراگراف، مانند تصویر، ویدیو و جدول، از راه پاراگرافِ دربرگیرنده‌شان هم‌تراز می‌شوند.

هم‌ترازی به‌عنوان ویژگی پاراگراف ذخیره می‌شود، نه قالب‌بندی متن. بلوک‌های کد از هم‌ترازی کنار گذاشته شده‌اند، زیرا تورفتگی در آن‌ها معنا دارد.

داخل سلول، تراز روی پاراگراف یا تصویر داخلی در محل مکان‌نما اعمال می‌شود. انتخاب چند سلول با کشیدن، تراز را روی همهٔ پاراگراف‌ها و تصاویر قابل تراز در آن‌ها اعمال می‌کند. اگر انتخاب شامل ترازهای متفاوت باشد، هیچ دکمهٔ ترازی انتخاب‌شده نمایش داده نمی‌شود.

برای تراز کردن خود جدول، **انتخاب جدول** را در ابزارهای زمینه‌ای آن بزنید یا مکان‌نما را پیش یا پس از جدول در پاراگراف دربرگیرندهٔ آن بگذارید، سپس از دکمه‌های تراز نوار ابزار اصلی استفاده کنید. جای‌گیری چپ یا راست ناحیهٔ شناور را از ابزارهای زمینه‌ای خودش تغییر دهید، نه دکمه‌های تراز.

برای اعمال فرمان روی انتخاب فعلی، از `l` برای چپ، `c` برای وسط و `r` برای راست استفاده کنید.

```ts
nabi.applyCommand('setAlign', { value: 'c' })
```
