# پاک‌کردن قالب‌بندی

قالب‌بندی متن را یک‌باره از بازهٔ انتخاب‌شده بردارید. نشان‌های پیش‌فرض ثبت‌شده مانند ضخیم، رنگ و قلم، به‌همراه ویژگی‌های پاراگراف مانند عنوان، هم‌ترازی و حرف آغازین بزرگ دربرگرفته می‌شوند. دو بار فشردن سریع Esc همین کار را انجام می‌دهد.

این کار ساختارهای سند مانند فهرست، جدول، نقل‌قول یا تصویر را به متن ساده تبدیل نمی‌کند. هم‌ترازی بیرونی تصویرها و ویدیوها و پیوندهای پیوستِ ایجادشده با بارگذاری همان‌گونه باقی می‌مانند.

<WingDemo path="/wing/etc/clear-format" />

```ts
const selected = wings()
  .use('b')
  .use('i')
  .use('clearFormat')
  .build()
```

wingهای قالب‌بندی که می‌خواهید پاک شوند نیز باید انتخاب شده باشند؛ وگرنه قالب‌بندی‌شان برداشته نمی‌شود.
