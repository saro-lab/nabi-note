# icon

`nabi-butterfly.svg`가 원본 파일이다.

- 좌표는 32×32 격자를 사용한다. 색상은 `currentColor` 하나만 사용하므로, 적용하는 곳에서
  색이 정해진다.
- 날개는 네 개이며, **몸통은 따로 그리지 않는다**. 날개 사이의 틈이 몸통처럼 보이도록 했다.
- 아래 날개를 먼저 그리고 위 날개를 겹친다. 같은 쪽 날개도 명도를 다르게 적용해(1 / .78,
  반대쪽 .55 / .40) 겹치는 부분에 층이 드러나게 했다.
- 모서리는 같은 색 선(`stroke-linejoin: round`)으로 다듬었다. 선이 두꺼워지면 몸통 사이의
  틈이 좁아지므로, 안쪽 모서리는 선 굵기의 절반만큼 미리 벌려 두었다.

## 파생 파일

| 파일 | 용도 |
|---|---|
| `nabi-web/docs/public/nabi-note.svg` | 파비콘 — 색상과 여백을 적용했으며 라이트/다크 모드를 자동으로 지원한다 |
| `nabi-web/docs/public/apple-touch-icon.png` | iOS 홈 화면 180×180 |
| `nabi-web/docs/public/og.png` | 공유 카드 1200×630 |
| `nabi-web/docs/.vitepress/ui/Mark.vue` | 헤더 로고 (사이트 색을 따라간다) |

수정할 때는 원본 파일을 고친 뒤 파생 파일을 다시 생성한다. 파생 파일을 직접 수정하지 않는다.
생성 방법은 `render.mjs`의 주석을 참고한다.
